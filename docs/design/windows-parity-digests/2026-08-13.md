## Feature ideas

### User-facing

- **Anchor a line while output streams** (High) — pin the line you are reading
  and let a build or test run scroll underneath it, instead of chasing the tail
  or scroll-locking the whole pane.
- **Follow the Windows light/dark setting, instantly** (High) — the terminal
  flips with the rest of the desktop at sunset without a restart or a config
  edit, which is what every native Windows app already does.
- **Collapse repeated output** (High) — a hundred identical warning lines fold
  into one row with a count and a click to expand, so a real error is not
  buried by a loop.
- **Quick-look the path under the cursor** (Medium) — hover a file path or URL
  and get a small preview of what is there, without opening a viewer pane and
  losing your place.
- **A timestamp gutter you can toggle** (Medium) — turn on a time column for a
  pane and see when each line was printed; invaluable when a step "hung" and
  you want to know for how long.
- **Drop a pane onto an edge to split** (Medium) — drag a pane and release it
  against the top, bottom or side of another to make the split, instead of
  choosing a direction from a menu and rearranging afterwards.

### Stability and performance

- **Remote panes that reconnect visibly after sleep** (High) — close the lid,
  open it, and the remote pane says it is reconnecting and then does, rather
  than sitting dead until you notice and reopen it by hand.
- **Never a blank window over RDP** (Medium) — a renderer that falls back
  cleanly when the GPU path is unavailable, so a remote-desktop session gets a
  slower terminal rather than an empty one.
