giant task; as eight dependency-ordered pieces it closed in a day. The same
move worked for the T89 test-harness pile earlier. The lesson generalizes:
when a task survives several days at the top of the queue unclaimed, the task
is the defect — split it.

divergence inventory exists now; actually scheduling merge-back work is the

## Feature ideas

### User-facing

- **A real settings window** (High) — every option lives in a hand-edited
  text file today. A native Windows settings dialog with search, grouped
  options, and instant apply would make the terminal configurable by people
  who never open a config file.
- **WSL distros as first-class shells** (High) — auto-detect every installed
  WSL distro and list each one in the new-pane choices alongside PowerShell
  and cmd, no config needed. Drop a Windows file onto a WSL pane and the path
  arrives translated.
- **"A pane is waiting on you" alert** (High) — detect when a hidden pane has
  stopped at a password or yes/no prompt and surface it (tab badge + toast),
  instead of you finding it stalled an hour later. (Different from the earlier
  finished-command notification on the ledger: this fires when a command is
  *stuck*, not done.)
- **Theme browser with live preview** (Medium) — Ghostty ships hundreds of
  themes; flipping through them in a picker that restyles the open pane as
  you arrow through beats editing a name in a file and relaunching.
- **Acrylic window background** (Medium) — optional Windows-native
  translucency (acrylic/mica) behind the terminal, the polish feature people
  screenshot.

### Stability and workflow

- **Record a pane as a shareable replay** (Medium) — capture a session to a
  single self-contained file that plays back with timing, for bug reports and
  demos; scrubbing beats screenshots of scrollback.
- **Screen-reader support** (Medium) — expose pane text and focus changes
  through UI Automation so Narrator and NVDA can read the terminal; today a
  blind user gets nothing.
