## Commentary

### Yesterday

**The biggest single day since the board existed: sixteen tasks closed between
the morning restart and dawn today.** Most of it was one campaign — the hunt
for the memory corruption that has been crashing test runs for a week (T443).
The whole toolchain around it got rebuilt: the crash catcher no longer reports
a dying program as a clean run, the soak now loads the box with real compiles
(the condition every actual sighting had), and the memory watchpoint arms fast
enough to cover a whole run. Then the ghost went quiet: twenty-eight
consecutive clean runs under the exact conditions that used to kill it. Rather
than burn more days chasing silence, the hunt is parked as an **armed watch** —
the instruments stay in the code, and the next occurrence will name its culprit
on the spot instead of starting another week of guessing.

**A whole class of invisible breakage is now impossible.** The floor gained a
lane that compiles the shared engine — and the C API the Mac app is built on —
for a Windows target on every run (T475/T323). It found two real defects the
same day it landed, both hiding behind how the tests happened to be compiled
(T477). Separately, work left uncommitted by a dead session can no longer sit
invisible: the loop now snapshots any dirty files when a turn starts and
refuses to finish until they are committed, reverted, or filed (T847) — that
rule exists because the big documentation reorganisation sat unpushed for two
days with nothing obliged to notice.

**Two things you can see got fixed**: a collapsed banner now repaints properly
when you expand it again (T833), and the "stunted banner column" you reported
turned out to be the test's screenshot tearing, not the banner — the app was
always drawing it right (T835).

**And the day's best find is a real bug you could hit tomorrow.** Restoring
sessions into an already-running window has its test fixture back (T486), and
building that fixture uncovered **T851**: start a second copy of Ghoztty while
one is running — say the Desktop portable while the installed one is open —
and the new copy silently steals every window of the first, leaving the copy
you were typing in frozen. Promoted straight into the milestone.

### Today's focus

### Reflection

**This week's recurring theme is instruments that lie, and it is nearly worked
off.** Four separate closures were about measurement, not the app: a crash
catcher that said "clean" over a panic, a screenshot pipeline that tears
mid-frame, a CPU sampler that over-reported under contention, an acceptance
script that failed without saying why. Each one had, at some point, sent a turn
chasing a defect that did not exist — or trusting a green that meant nothing.
The pattern to keep: when a test result is surprising, suspect the camera
before the subject.

**The decisions board hit zero open for the first time ever.** Yesterday's
directive — decisions are for experience gaps only, mechanism calls get made
and recorded rather than queued — cleared twenty-plus standing items in one
pass. The test of the new regime is whether the board stays near-empty while
still catching the genuinely ambiguous Mac-to-Windows translation calls.

**What still stands between here and merging into main has not moved.** Daily
intake lag is zero for the seventh straight day — new Mac work reaches this
queue within hours — but the two historical backlogs (126 unmapped Mac commits,
81 shared-core commits, T684/T716) remain unowned, and the Mac seat is now
seventeen days absent with fifty-seven tasks waiting on it. The merge-back
distance is now almost entirely that frozen history, not the daily flow.

## Feature ideas

### User-facing

- **A drop-down terminal on a global hotkey** (High) — press one key in any
  app and Ghoztty slides down from the top edge, ready to type; press it again
  and it slides away. The fastest possible "I just need a shell for ten
  seconds" on Windows.
- **Paste guard for multi-line text** (High) — pasting three lines into a
  shell runs three commands, including the ones you did not read. A quiet
  preview when the clipboard holds multiple lines — here is what is about to
  run — turns the classic paste accident into a non-event.
- **Pictures in the terminal** (High) — support the inline-graphics protocol
  so a CLI can print a chart, an image preview, or a screenshot straight into
  scrollback, the way Ghostty already can elsewhere. CLIs increasingly emit
  graphics; today Windows users see escape garbage.
- **A "new build is ready" toast** (Medium) — when a newer Ghoztty has been
  delivered, offer one click to restart now with every pane restored, instead
  of the app quietly running yesterday's build until the next reboot.
- **Search everything you ever ran** (Medium) — a history browser across all
  panes and all days, each command with the directory it ran in and whether it
  succeeded. (Distinct from the earlier "search open panes" idea — this is
  persistent history, not live scrollback.)

### Stability and workflow

- **Safe mode after a crash loop** (Medium) — if the app dies twice at
  startup, the third launch offers to come up plain: default config, no
  session restore. A bad config or corrupt session file should never be able
  to lock you out of your own terminal.
- **Locked side-by-side scrolling** (Medium) — pin two panes together so they
  scroll as one, for eyeballing two log files or two diffs against each other.
