## Commentary

### Yesterday

**The test suite stopped borrowing your desktop.** Fifty-odd acceptance scripts
used to open real Ghoztty windows on the desktop you were sitting at — windows
appearing and vanishing under your hands while the loop tested itself. Four
tasks closed yesterday moved essentially the whole suite onto a background
desktop: the session and agent scripts, the persistent-session scripts, eighteen
CLI and IPC scripts, and the last nine stragglers. The suite now runs invisibly.
That is the single biggest quality-of-life change of the day, and it is one you
notice by *not* noticing it.

**Updating got harder to get wrong.** Three separate ways the update path could
mislead you were closed. A download that gets cut off mid-transfer is now
refused instead of quietly staged as if it were whole. The portable ZIP stopped
shipping instructions that told people to click a button that does not exist in
that build. And two test harnesses that had been aiming the update applier at
the repo's own build — meaning a test could walk off with the binary it was
handed — were pointed somewhere safe.

**Overnight, three things you would see.** A relaunched pane says "session
restarted" again at every window size (it had been disappearing at narrow
widths). The debug chrome tint no longer flattens the tab strip above it. And a
remote window's connection state now shows up in `+list --json`, so a script — or
an agent — can tell a live remote window from one that has dropped, instead of
guessing. On top of that, a relay window that loses its connection now re-dials
rather than going permanently dead.

**Nothing shipped, and the reason is on your side of the fence.** The end-of-day
publish fired correctly at 23:19, worked out that it owed you `win-v1.36.1`, and
then stopped: Docker Desktop was not running, and the MSI is packaged inside the
msitools container. It logged the skip, left the watermark alone so a later push
could still publish, and got out of the way. So the terminal you are reading this
in does **not** carry yesterday's work. Starting Docker Desktop is the one thing
that turns that around — the publish is otherwise fully automatic now.

### Reflection

**The theme of the last week is that the machinery finally checks itself.** Look
at what closed: a guard that verifies its own watch list, a digest that reports
its own absence, a commit that cannot be titled after somebody else's work, an
audit that catches a test proving nothing. None of these are features. All of
them exist because something quietly lied once and cost a day. The pattern has
become explicit policy — a new gate ships with the demonstration that it can
fail — and it is working, but it is worth naming the cost: a growing share of
each turn is spent on the loop's own hygiene rather than on the terminal.

**The queue is telling us something.** Zero startable P0/P1s on this seat is not
an accident; it is convergence. M1 sits at 244 of 306. What stands between here
and the cutover is now almost entirely *not code*: one user action (T1179), one
Mac-seat build (T87), and 93 unmerged `origin/main` commits. That is a good
problem, but it means the loop is about to spend its days on P2 polish while the
actual gate sits idle. Worth considering: should the loop start pulling
cutover-adjacent work forward — dry-running the merge, pre-resolving conflicts
against `origin/main` — so that when T1179 clears, the cutover is an hour and not
a week?

**A process gap, honestly stated.** Yesterday's digest had only a Commentary
section — no Task triage, no Feature ideas. Steps 0.6 and 0.7 were skipped
silently, and nothing noticed, in exactly the way step 0.5 used to be skipped
before T1223 gave it a light. The health check answers `digest=present` the
moment a file exists, regardless of what is in it. That is the same class of
half-measure the reflection above is congratulating itself about. Filed as a
task today.

## Feature ideas

### User-facing

- **Pipe anything into a viewer pane** — *High.* `mytool --json | ghoztty +view`
  opens whatever a command just printed as a rendered document — markdown,
  JSON, a diff — beside the pane that produced it. Today you have to write the
  output to a file first and then open that file, which nobody does mid-flow.
- **Filter a pane while it is still streaming** — *High.* Type a pattern and the
  pane hides every line that does not match, live, as output keeps arriving —
  then clear it and the full output is still there. Searching scrollback finds a
  line; this makes a firehose readable while it is running.
- **Lock a pane so stray keys cannot reach it** — *High.* One toggle makes a pane
  read-only: the production SSH session you keep beside your editor stops
  accepting the command you meant to type somewhere else. Distinct from warning
  about destructive commands — this prevents the wrong-window mistake entirely.
- **A tray of every link and path a pane printed** — *Medium.* A small panel
  listing the URLs and file paths that scrolled by this session, newest first,
  clickable. The build output that printed a coverage-report URL four minutes ago
  is still one click away instead of gone.
- **Hovering a pane focuses it** — *Medium.* An opt-in setting so moving the
  mouse over a split gives it keyboard focus, no click needed. A small thing that
  makes a four-pane layout feel much faster to work in.
- **Hide the tab strip when there is only one tab** — *Medium.* A single-tab
  window spends a row of pixels telling you something you can already see. Give
  the row back and let it reappear the moment a second tab exists.

### Technical / performance

- **Which pane is eating my CPU** — *Medium.* A readout on the tab or in the
  palette showing each pane's child-process CPU and memory, so the pane that has
  been pegging a core for twenty minutes identifies itself instead of being found
  by closing things until the fan stops.
- **Quieter on battery** — *Medium.* Drop render cadence and background polling
  when the laptop is unplugged and Ghoztty is not focused. A terminal left open
  all day should not be a line item in your battery report.
