# D22 - Should a signed-in machine serve its sessions by default, or only after an explicit 'Share this machine' opt-in?

## Why this needs a call

One-process consolidation (T546) makes the local session store reachable over the relay, so whatever flips serving on now exposes the user's real local terminals, not just relay-created sessions. That raises the stakes of the default: convenience of a literally-true install story versus a machine starting to serve shells as a side effect of signing in.

## Resolution

Chosen: Default-on once signed in
