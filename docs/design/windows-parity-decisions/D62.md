# D62 - Should ghoztty:// registration be gated to the canonical install directory, the way the PATH self-heal is?

## Why this needs a call

PathInstaller gates on the install directory because it writes to a SHARED value (the user PATH) that a dev build has no business editing. A URL scheme is not shared in that sense: the debug and release builds register different names, so the only real exposure is a release build launched from somewhere unusual, which on this box is a deliberate act.
