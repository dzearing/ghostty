# D45 - Should the win32 feedback composer's input be a capsule, when the design system says an input field is 4 DIP?

## Why this needs a call

Mac's composer is a capsule and says so in its own source; the win32 design system's radius table says an input field is 4 DIP and ends with 'Nothing else'. Both are standing rules here, and this control is the first place they contradict each other. Nothing in the code or the tracker settles it, so it was resolved by assumption and is filed for a call.
