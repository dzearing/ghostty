# D85 - Should your terminal keep being swapped every morning, or update itself the way the product does?

## Why this needs a call

You install Ghoztty from the website and get a real release. A few minutes later a background job on this box quietly replaces that exe with a build straight out of the repo. Until today that build called itself 1.4.0 and could not find updates at all - so the terminal you installed this morning was, by lunchtime, a different thing that no longer knew the website existed. The product now HAS its own updater, which is the path a real user walks, and the two mechanisms are now doing the same job in different ways. Which one should own your terminal?
