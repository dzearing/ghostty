# D40 - Should agent-held layout blobs carry a per-pane screen snapshot so cross-machine Restore All gets the fast re-attach?

## Why this needs a call

T413 asked whether the deliberate strip in layout_blobs.serializeWindow should be undone so blob-sourced panes get the WP-D3 delta attach. Investigating it showed the premise had aged: T106 and the agent's own grid snapshot already make a blob-sourced pane exact on screen, and the only thing the agent's snapshot lacks is scrollback. That moves the remaining work off the topology mirror and onto the agent, which is a different task - so this is a call about where the fix belongs, made without the user in the room.
