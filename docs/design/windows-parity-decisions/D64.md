# D64 - Should a scripted delivery keep a dated backup of the two .pdb files it replaces?

## Why this needs a call

The .bak-* convention predates any script and was applied by hand to whatever the session felt like copying, which is how the Desktop portable accumulated 62 backup files. Scripting it forces the question to be answered once, and the two .pdb files are 85 MB and 11 MB of the ~130 MB a full backup costs - the overwhelming majority of the pile, and the part least likely to be needed.

## Resolution

Chosen: Back up only what you run (Recommended)

Resolved by Claude (user delegated technical calls, 2026-08-14). Back up what you run: the executables give the one-command rollback, the two pdb files are 96 of the 130 MB and reproducible from the commit the exe reports. -BackupAll remains for full fidelity when wanted.
