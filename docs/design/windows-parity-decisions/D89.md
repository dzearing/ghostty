# D89 - Windows now deletes the download on some machines, not just warns about it. Buy a signing certificate?

## Why this needs a call

On 2026-09-03 you installed Ghoztty on a second machine and Windows Defender did not show a warning you could click through - it quarantined ghoztty.exe and ghoztty.com and took them away, calling them Trojan:Script/Wacatac.C!ml. D87 weighed this question when the worst case was a scary dialog with a Run anyway button; the worst case is now a machine where the program has been deleted and the person has no idea why. The same files scan clean here with current definitions and cloud protection on, and the release is built in public by GitHub Actions, so the evidence points at a machine-learning guess about an unsigned, brand-new program rather than anything in the bytes. That guess is exactly what a signature is for. This is the same choice as before with materially worse consequences attached, which is why it comes back to you rather than being settled here.
