# D37 - How should the app learn whether a cross-machine pane's shell is busy, when the close confirmation has to decide instantly?

## Why this needs a call

T41 skips the close confirmation for an idle shell by walking THIS box's process table, which a cross-machine pane's shell is not in. The materials for the real answer live on the agent, but Surface.close is a synchronous GUI-thread path that shows a modal dialog, so the shape of the answer matters as much as the answer: it can either be pushed ahead of time and read instantly, or fetched on demand and waited for.
