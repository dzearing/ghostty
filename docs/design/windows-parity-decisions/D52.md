# D52 - Should --keys-file= be exempt from the new trailing-newline peel?

## Why this needs a call

Main a7f7476e1 made a trailing newline on a TEXT argument mean submit. This branch also has --keys-file=, which main does not, and whose entire contract is that nothing interprets the bytes. The two rules collide on a generated prompt file that happens to end in a newline.
