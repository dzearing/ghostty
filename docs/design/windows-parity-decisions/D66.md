# D66 - Should the tab strip's hit regions ride +list --json, or a debug-only verb?

## Why this needs a call

T231 asked for the strip's hit regions to be published so acceptance scripts stop re-deriving tab_strip_layout in PowerShell. Its own sketch offered either +list --json or a debug-only verb, and left the call open. What decided it: the harness must measure what ships (T350), and the data is genuinely useful to any caller that wants to point at a tab, not only to tests.

## Resolution

Chosen: Publish in +list --json, always on (Recommended)

Resolved by Claude (user delegated technical calls, 2026-08-14). The harness must measure what ships (the T350 rule), the field is additive so no existing consumer breaks, and it is useful to any real caller positioning against a tab. The Mac half is filed as T735, keeping symmetry.
