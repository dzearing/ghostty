# D49 - Should a P0 with no order: be pulled to the front of the queue, or does order: deliberately outrank priority:?

## Why this needs a call

The queue sorts by order: first and treats a missing order as 'sorts last'. Every one of the ten open P0s had order: null, so the whole P0 band sat behind an ordered band whose head was a P2 thumbnail carousel. The loop has been handing out P2 polish while a P0 that restores your windows as dead pictures waited - which means the priority field was decorative rather than wrong.

## Resolution

Chosen: Make next sort by priority: first and use order: only to break ties
