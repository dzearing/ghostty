# D32 - How should Windows releases start actually publishing - cherry-pick the workflow onto main, hand-publish now, or wait for the merge-back?

## Why this needs a call

The newest Windows release is the hand-published win-v1.4.1 from 2026-07-19 while macOS is at v1.31.0. Every link on the page answers 200, which is why nobody noticed; they answer with a three-week-old build. Choosing between these changes what a Windows visitor downloads today, and the wrong pick either strands them on July or ships them a build missing every parity feature on this branch.
