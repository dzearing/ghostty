# D82 - When you start a Ghoztty that is older than the one already running, should it ask you first?

## Why this needs a call

This box keeps Ghoztty in three places. When they are all the same build - the normal state - none of this is visible. When one falls behind and you start it, the app you get is the newer one that was already running, and until now the only sign was a balloon after the fact. Letting the older copy run as its own app is the one option that cannot be made safe: the terminal sessions and the saved window layout are deliberately shared so they survive an update, so two apps would reopen the same windows twice and overwrite each other. What is left is whether the swap happens silently or you are told before it happens.

## Resolution

Chosen: Ask which one you meant, and let you take the window or back out (Recommended)
