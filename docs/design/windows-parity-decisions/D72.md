# D72 - Where should the shipped Windows build get its Google OAuth client id?

## Why this needs a call

Relay sign-in needs a Google OAuth client id, which is public but has to be registered in the Google Cloud console and is not in this repo (docs/design/relay-oidc-setup.md step 10 says to stash it in a password manager). The Windows delivery scripts pass no -Dgoogle-client-id, so every shipped build resolves none and sign-in cannot start at all. Only you have the credential, so where it comes from is your call.

## Resolution

Chosen: Drop the id in a git-ignored google-client-id.txt at the repo root (Recommended)

Resolved by Claude (2026-08-14): mechanism settled as the git-ignored google-client-id.txt at the repo root, matching how the Mac seat has always done it. ONE ACTION NEEDED FROM YOU: copy the client id (relay-oidc-setup.md step 10 stashed it in your password manager) into that file on this box - until then delivered Windows builds keep saying sign-in is unavailable, by design rather than by dead button.
