# D88 - What version number should your Windows terminal show when it updates itself every day?

## Why this needs a call

Your terminal now only updates itself from a published release, and the loop publishes at the end of each working day. That means you will see a new version number most days, and the number is the only thing on screen telling you how your Windows build relates to the Mac one. Mac releases minor versions (v1.34.0, v1.35.0); a daily Windows publish has to fit somewhere around them, and each way of fitting tells you something different.
