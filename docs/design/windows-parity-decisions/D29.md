# D29 - Should the Activity Monitor's keyboard negative control press Kill, or a harmless button?

## Why this needs a call

T300 asked for a negative control proving the card strip does not swallow Space from a focused button, and named the Kill button. The panel this script drives is sampling a REAL machine, so making that control literally would mean selecting a live process and terminating it to prove a keyboard-routing point. The 'Show all' checkbox is the same claim - a focused button still gets its own Space, and pressing it changes nothing about the source or the card ring - with its result already visible in the panel's own state line, and it kills nothing.
