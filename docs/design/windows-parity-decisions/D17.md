# D17 - Should ghoztty.com be a subsystem-patched twin of ghoztty.exe, or a small relay shim?

## Why this needs a call

PowerShell decides whether to wait for and wire redirection to a child from the PE subsystem field alone, so the only child-side fix for silent 0-byte redirects is a console-subsystem entry point named ghoztty.com (PATHEXT resolves .COM first). Two ways to build that binary existed; Defender eliminated one empirically.
