# D69 - Should the pane-content capture be a shipped CLI verb, or stay a debug-only test seam?

## Why this needs a call

T275 asked for this call explicitly. The mechanism has exactly one consumer today - the win32 acceptance suite, which cannot otherwise assert anything about the OpenGL glass off the background desktop - and the cost of the two options is not symmetric: a debug seam can become a verb later, while a shipped verb cannot be taken back.
