# D18 - Should live orphaned agent sessions ever age out, or stay pinned forever?

## Why this needs a call

T411 proved live pinned orphans accumulate invisibly (4 live sessions, layout held 3, one orphaned since 2026-08-02). The pin exists so sessions survive their viewer; whether an unattached one may EVER expire is a product-promise question only the user can settle, including the default N.

## Resolution

Chosen: Config knobs are difficult to find and nobody will ever use it. "Age out" is ambiguous. Is it live? but not doing anything? If an agent sessions ever age out,  wouldn't we want to bubble this to the user in some kind of notification that lets them resolve this rather than assuming something?
