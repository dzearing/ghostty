# D30 - How should Windows mark a read-only pane: a corner badge on the pane, or a glyph in the tab title?

## Why this needs a call

The core's .readonly action is a documented no-op on win32, so nothing on screen says a pane stopped accepting keys. T28's original note suggested a tab-title glyph; T445's own write-up argues for the corner badge instead. A tab covers a whole split tree, so a tab glyph cannot answer 'which pane', and read-only is a per-pane mode - so the cheaper affordance answers a different question than the one the user is asking.
