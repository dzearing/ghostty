# D24 - Which chrome affordance should surface a pane's working directory on Windows?

## Why this needs a call

The pane cwd is cached and reaches +list, but nothing in the win32 chrome renders it; the Mac shows it as the titlebar proxy icon. A visible-chrome choice the user may want to overturn, so it gets a receipt rather than a silent pick.
