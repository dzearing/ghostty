# D76 - Should the Agent Integrations window let you keep using the terminal while it is open?

## Why this needs a call

The Mac shows Agent Integrations as a small always-openable window you can leave up while you work. Windows convention for a settings surface opened from a menu is a dialog that holds focus until you close it. Both are buildable; they feel different to use, and the translation is not obvious.
