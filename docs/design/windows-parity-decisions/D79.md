# D79 - When Ghoztty is already running and you start it again, should the second copy join the first instead of becoming a separate app?

## Why this needs a call

On a Mac the app bundle can only run once, so this never comes up: clicking Ghoztty again just brings your windows forward. On Windows there is no such rule, and a real setup on this box has two copies installed - the one in the Start menu and a portable one on the Desktop. They quietly share the same terminals and the same saved window layout. Until this task they also fought over them: starting the second copy took the first copy terminals away and froze them. That is fixed, but the wider question stays open and the user can feel the answer either way.
