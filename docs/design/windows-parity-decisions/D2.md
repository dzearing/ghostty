# D2 - When a restored pane has its own banner, should the session-interrupted notice keep a banner copy at all?

## Why this needs a call

T423 made the in-stream notice survive the ConPTY repaint, so the banner copy is no longer the only carrier and dropping it is safe. But the user has read and reacted to that notice (they filed T424 about its wording), so making it invisible by default trades one complaint for another. Precedence keeps both properties at the cost of a flag.
