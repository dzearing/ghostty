# D14 - Should reset-context's verdict coverage be its own acceptance script, or sections in the existing one?

## Why this needs a call

T482 asked for a NEW script covering the helper's three verdicts. The existing T133 script already boots an isolated instance, drives the same deployed cache copy, and had two of the three verdicts covered; the missing one (a repainting pane) needed one more proxy. Writing a second script would have meant duplicating the isolation, proxy and pane-cleanup scaffolding and keeping two files in agreement about the helper's log format.

## Resolution

Chosen: Split out reset-context-verify.ps1 as T482 proposed (Recommended)
