# D65 - Should the audit also convert the two BENIGN foreground reads, or only the four that no-op?

## Why this needs a call

The audit found nine activation reads. Four silently no-op off the input desktop and are unambiguously in scope. Two more read foreground with INVERTED polarity - they flash the taskbar when the window is NOT in front - so off-desktop they always fire rather than never firing. That is harmless (no taskbar exists there), so fixing them is not a defect fix; it is a consistency call about whether the app is allowed more than one way to ask this question.

## Resolution

Chosen: Convert all six (Recommended)

Resolved by Claude (user delegated technical calls, 2026-08-14). Consistency: exactly one reading of activation in the app, so the next author copying a neighbour copies the correct shape. The two benign sites are behavior-identical on the input desktop and the bell path is covered by the floor lanes.
