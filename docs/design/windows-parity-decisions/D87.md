# D87 - Should a Windows download stop warning immediately, or warn for a few more weeks while trust builds?

## Why this needs a call

Windows shows a full-screen 'Windows protected your PC' warning for downloads it does not recognize, and Ghoztty triggers it today. A certificate is what stops it, but the two kinds on sale buy different experiences. With EV the warning is gone the first time anyone downloads: install a build, get a normal installer with Ghoztty named as the publisher. With OV the publisher is named but Windows keeps warning until enough people have downloaded that build - for a project this new, likely weeks - so an early user still meets the wall and the fix looks like it did not work. macOS already ships signed and notarized, so whichever way this goes decides whether the two platforms feel the same on first run. The money and the identity paperwork are yours either way, which is why this is a question rather than a call.
