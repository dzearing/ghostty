# D20 - Over the merged row's tabs, should the top resize edge be the full system frame or should the tab own its full height?

## Why this needs a call

Two same-day measurements of Windows Terminal disagreed because they probed different windows. The parent-window probe says HTTOP over tabs; the child that actually covers the tab run answers HTCLIENT from row 0, and input routes to the child. The task's own criterion is empirical parity, so the child-window measurement decides - but the earlier session had already validated and nearly shipped the opposite conclusion, so the reversal deserves a receipt.

## Resolution

Chosen: Tab owns its full height, frame only in corners + empty band (Recommended)
