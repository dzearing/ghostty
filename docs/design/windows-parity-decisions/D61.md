# D61 - Should a ghoztty:// link start Ghoztty when no instance is running?

## Why this needs a call

Windows lets us decline the launch that macOS cannot: the shell runs our registered command and we choose what it does. Focus-only is the whole security envelope of the scheme, so starting a terminal from an untrusted link is the one thing it must not do - but it does mean a cold click is a dead click, and that is a user-visible difference between the platforms.
