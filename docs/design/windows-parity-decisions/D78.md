# D78 - After a reboot, should a pane still show what the lost session left on screen?

## Why this needs a call

A reboot kills the process in every pane. On the Mac the pane comes back showing the text that process had left on screen, with a notice above it saying the session was lost. On Windows the same reboot brings the pane back showing nothing but the notice and an empty prompt - the old text is dropped on purpose, on the argument that a brand-new shell showing an old screen is a lie about what the pane is. Both are defensible and the user is the one who has to live with the result, so which one Windows ships is a call about what a reboot should feel like, not about how it is built.

## Resolution

Chosen: Bring back what was on screen (Recommended)
