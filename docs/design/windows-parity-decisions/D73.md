# D73 - T745 was not a Ghoztty defect - fix the hook that pre-truncates the banner text, or leave it?

## Why this needs a call

The reported screenshot was reproduced exactly and the renderer turned out to be handed a string that was already cut off: the ellipsis is the literal '...' the banner hook appends after trimming the auto-seeded prompt to 97 characters. So the defect is real and user-visible, but its cause sits in ~/.claude/scripts/ghoztty-banner.sh, which is user config and not part of this repo. The judgement call is whether a parity task may be closed by a fix made outside the repo.
