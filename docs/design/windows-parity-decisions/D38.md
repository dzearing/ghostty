# D38 - Should a cross-machine Restore All dial its windows all at once, now that the dialing is off the GUI thread?

## Why this needs a call

T339's brief says the dials 'should perhaps be concurrent' once they are off the GUI thread. The freeze - the filed defect - is fixed by the move alone; concurrency is a separate latency win with its own failure modes, and there is no real relay on this box to measure either against, only a loopback fixture.
