# D36 - Should the Windows connection pill stay a status-only chip, or carry the machine name the way the Mac one does?

## Why this needs a call

Mac's titlebar affordance is really two controls - a capsule naming the machine (clickable, opens the Activity Monitor) and a status capsule that is invisible while connected. Windows has neither today, and the caption band has limited horizontal room it shares with the tab run. Building both at once meant inventing a machine display name (relay machines are identified by a device ID, not a name a person would recognise) inside a task whose subject is the connection STATUS, so the two halves were split.
