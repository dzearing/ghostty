# D92 - Should a session you already have a window open on still appear in the chooser's list?

## Why this needs a call

The user's answer on D91 said the list represents the processes still alive, and added: if we do not have a ghoztty window for something still running, we should list it. Removing the finished sessions is unambiguous and has landed. The other half is readable two ways: as a description of what the list is FOR, or as a rule that a session you already have a window on should drop out of it. Today those sessions are listed with an 'open' mark and picking one jumps to the window that holds it, which is why the assumed option keeps that behavior.

## Resolution

Chosen: Keep it listed, marked 'open', and jump to its window when you pick it (Recommended)
