# D41 - Should a cross-lineage layout blob be labelled, or should each viewer learn to read the other lineage's shape?

## Why this needs a call

T337 was filed as a decision with three options, listing a lineage-tagged envelope first. The blobs that already sit in running agents carry no tag and never can - an agent outlives the app that wrote its blobs by design - so a tag would describe only future blobs while every existing one stayed undecodable. A reader that tolerates the other shape is needed either way, which is what tipped the call away from the envelope.

## Resolution

Chosen: Translate on read (Recommended)
