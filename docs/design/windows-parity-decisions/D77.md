# D77 - Where should the 'Share this machine' checkbox sit now that the machine's name fills the top band's left side?

## Why this needs a call

Mac's update puts the selected machine's name at the top-left of the chooser, where Windows has kept its Windows-only 'Share this machine' checkbox. Both cannot lead the band, and Mac offers no precedent for the checkbox because it does not have one.
