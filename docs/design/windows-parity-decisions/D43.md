# D43 - Which text control should the win32 viewer feedback composer be built on?

## Why this needs a call

Mac models an image chip as an NSTextAttachment: one atomic character inside a rich text view. A win32 EDIT cannot carry attachments at all, so the composer needs a different foundation, and the choice decides how IME, accessibility, undo, clipboard image paste and the quote accent bar all behave. It is a one-way door: chips, quote styling and the report writer are all built on top of whatever is picked.
