# D93 - When a remote window's connection drops, should its titlebar chip still show which machine it is?

## Why this needs a call

On a Mac these are two separate chips side by side, so the machine name never goes away - the status simply appears next to it. Windows has one chip in a much busier titlebar (the tab strip shares that row), so it can only say one thing at a time. Either the chip keeps saying WHICH machine and loses room to say what is happening to it, or it says what is happening and you hover to remember which machine that was. With three remote windows open and two of them dropping, the two answers feel quite different.

## Resolution

Chosen: Always show the name, with the status after it
