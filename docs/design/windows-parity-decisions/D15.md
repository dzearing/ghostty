# D15 - When a launch command and a session restore both apply, should Ghoztty do both, or should the command win?

## Why this needs a call

T406 asked to answer this from the Mac side first. The Mac side cannot answer it: it has the SAME defect (AppDelegate opens the initial window only when there is no pending restore, and the shared core rule hands initial-command to whichever surface is app.first - on a restoring launch, a restored pane). So there was no precedent to cite and the call had to be made here. I picked 'do both' because it is the only option that drops nothing the user asked for: the command was typed just now, and the windows are real work they left behind.
