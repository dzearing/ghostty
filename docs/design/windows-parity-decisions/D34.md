# D34 - Should a low-contrast split-divider-color be silently lifted to the 3:1 chrome floor, or left alone with a warning?

## Why this needs a call

split-divider-color is an unconstrained user color and nothing checked it against the pane background, so #0a0a0a on a black terminal painted an invisible divider whose hover shade was invisible too - the control and its feedback both disappeared. The design system requires 3:1 for meaningful boundaries and a divider is one. Mac honors the raw value, so any floor here is a deliberate divergence and needed a recorded call rather than a silent one.

## Resolution

Chosen: Lift it at paint time (Recommended)
