# D35 - Should acceptance scripts be allowed to run on the user's own desktop when a defect only reproduces there?

## Why this needs a call

T277 fixed the product half of float-on-top and the remaining failure only shows on the background test desktop, where an EXTERNAL process cannot pin the window either. The next measurement the task calls for is 'does this reproduce on the interactive desktop', which means putting test windows on the desktop the user is actually working in. Nothing in go.md says whether that is allowed, and the answer decides whether a whole class of on-box defect is reachable here at all.
