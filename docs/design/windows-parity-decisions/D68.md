# D68 - Should the asserted-nothing rule be enforced on every script's FINAL verdict now, or ratcheted?

## Why this needs a call

The invariant is a runtime property (did this run score any assertion), so it is fully enforced only for a script whose verdict goes through the shared scorer. Converting the whole suite in one turn means ~170 mechanical edits to the harness that is supposed to catch regressions, each needing a live run to prove it still measures what it did. The four scripts that could ACTUALLY reach a green verdict having asserted nothing were provable statically and are fixed.
