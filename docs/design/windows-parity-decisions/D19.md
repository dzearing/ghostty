# D19 - What should +new-window do when --target already exists but create-only flags were passed?

## Why this needs a call

The idempotent rule is Mac-parity and deliberate, but a success reply that hides a dropped --command burned the upgrade-relaunch path (T132) and is invisible to every script. Something had to make the drop observable without breaking idempotent callers.

## Resolution

Chosen: Report the drop (outcome + stderr note), stay idempotent (Recommended)
