# D63 - Should the build move a running artifact aside, or stop the process that is holding it?

## Why this needs a call

Windows will not let a running image be replaced, and ghoztty-agent.exe outliving the app is deliberate - so any dev-loop build on a box that ran a session test hit this. The fix had to choose between making the build destructive and leaving a file behind. Renaming a running image is permitted by Windows and is what every updater does, so the non-destructive option is also the one with no capability creep; the cost is a leftover file with a bounded lifetime.
