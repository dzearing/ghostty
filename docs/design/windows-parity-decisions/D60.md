# D60 - Which shared src/ subtrees should the parity gate watch?

## Why this needs a call

Widening the watch list is the whole point of T685, but there are two ways to widen and they fail differently. An allowlist is quiet today and blind to whatever main adds next; subtracting from src/ is complete by construction and noisier. Measured on this repo: since June, main has 152 commits touching src/, 87 of them touching NO macos/ path at all - so the blind spot is real and large, and 81 of those are cited nowhere. The noise objection turns out to be bounded, because the daily intake range is the watermark and it evaluates 0-2 commits a day.

## Resolution

Chosen: Watch all of src/, minus the frontends that owe Windows nothing (Recommended)
