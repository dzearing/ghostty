# D84 - A user-visible fix lands at 08:00 and the terminal you work in does not get it until 5am tomorrow - how should the installed release refresh?

## Why this needs a call

The installed release at %LOCALAPPDATA%\Programs\Ghoztty is the copy on PATH and the one you type in all day. It refreshes once per day, on the first push after 5am, because refreshing it restarts the app - and an agent update would end the loop outright. The Desktop portable and the network share refresh at every task boundary, so they are hours ahead of the copy that matters. The effect you see is a shipped feature that looks missing: this has now happened twice with the address bar specifically, on 2026-08-07 and again today.

## Resolution

Chosen: Tell you a newer build is waiting, and let you take it when you choose (Recommended)
