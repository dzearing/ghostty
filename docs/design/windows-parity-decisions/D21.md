# D21 - Should the restart notice name the foreground command, the resolved shell, or both?

## Why this needs a call

The agent records no command label for a plain shell pane, so the restart notice can never name what was running. The cheap fix (record the resolved shell) produces a technically-true but useless line; the user's actual report was about the program running inside the shell. Which of the three the notice should print is a product call.

## Resolution

Chosen: Name the live foreground command only (Recommended)
