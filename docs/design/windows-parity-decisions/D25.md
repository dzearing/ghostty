# D25 - How often should a document/web pane's carousel preview refresh?

## Why this needs a call

The Mac takes its viewer thumbnails with a call that hands back a bitmap directly, so refreshing seven times a second is nearly free there. Windows has no such call: the only way to get a web pane's pixels is to ask the browser to ENCODE a full-size image and then decode it back, which is a real cost on the thread that also handles typing. So the Mac's number cannot simply be copied, and picking a different one is a judgement about what a preview is for.
