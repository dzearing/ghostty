# D16 - Should the loop's automatic liveness pulse be the session transcript's mtime, or a Claude Code hook that beats the heartbeat?

## Why this needs a call

T253's sketch listed the hook as the cheapest source but left the choice open. The transcript needs zero configuration and cannot be forgotten, which is the whole point of the task - the failing signal was one that depended on being remembered. The fallback when the transcript cannot be resolved is precisely the old behaviour.

## Resolution

Chosen: Transcript mtime (Recommended)
