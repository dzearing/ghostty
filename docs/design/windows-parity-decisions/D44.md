# D44 - How should the win32 feedback composer capture a screenshot?

## Why this needs a call

Mac uses screencapture -i -o, an interactive whole-screen region grab, and its comment is explicit that the -c flag is forbidden because it would clobber the clipboard of the user. The obvious Windows equivalents do exactly that forbidden thing, so this is not a translation, it is a choice about what a screenshot in a feedback report even means.

## Resolution

Chosen: Ghoztty-drawn region selector over a screen snapshot (Recommended)
