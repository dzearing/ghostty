# D47 - Where should a feedback report's git branch/commit be resolved: on the send, or on the worktree probe?

## Why this needs a call

T636's task file says to run the two rev-parse calls on the probe's worker. Doing that makes branch/commit as old as the pane: the probe answers 'which repo is this content in', which does not change when you switch branches, so its 15s TTL never expires for a stationary pane. A feedback report exists to be replayed against the exact revision the user saw.

## Resolution

Chosen: Resolve at send time, on the send's own worker (Recommended)
