# T1166 - A script's suite-timeout declaration can stop parsing without anyone being told

## Summary

soak.ps1 lost its 2400s declaration to a CRLF rewrite (ce943e238) and was silently back to being killed at 600s and scored a stall - the exact defect T1125 fixed. T1137 made the regex CRLF-tolerant, but the shape of the failure stands: a declaration that does not parse is indistinguishable from no declaration at all. The runner should say so - a script whose text contains 'suite-timeout-sec' and whose declaration did not parse gets a named warning in the run header and in 'list', instead of quietly inheriting the global cap.
