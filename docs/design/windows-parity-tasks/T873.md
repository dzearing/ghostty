# T873 - Upstream the jq-free ghoztty-banner.sh to main and collapse the Windows vendored fork

## In plain terms

The banner helper script Ghoztty installs for coding agents used to need a
unix tool (`jq`) that neither a clean Mac nor a clean Windows machine has —
the Mac app literally nags the user to `brew install jq`. Windows fixed that
(T866) by teaching the `ghoztty` CLI itself to do the JSON work and rewriting
the script on top of it, but had to keep that rewrite as a local fork. This
task lands the same rewrite on main so the Mac gets the fix too — no more
brew nag — and the fork disappears.

## Summary

T866 vendored tip-of-main's `macos/Resources/Ghoztty/` assets into the win32
build (`src/apprt/win32/assets/ghoztty/`, pristine mirror under `upstream/`)
and forked ONE file: `hooks/ghoztty-banner.sh`, whose jq plumbing now runs on
the shared CLI's new `+json` verb (`src/cli/json.zig`: `get`/`merge`/
`encode`; mkdir-lock interop with the old script's mutex; BOM-tolerant parse;
self-healing merge). The verb is in the shared `Action` enum, so a Mac build
of the same source already has it — the only missing piece is the script
change on main.

Work, from the Mac seat (needs a Mac to validate the Mac runtime flavors):

- Port the fork's diff onto `macos/Resources/Ghoztty/hooks/ghoztty-banner.sh`
  on main: `jfield`/`read_field` -> `ghoztty +json get`, `jq_merge` ->
  `+json merge` (drop the in-script mkdir/mktemp dance — the verb owns it),
  envelope emission -> `+json encode` + fixed printf shapes, the no-jq gate
  -> the once-per-pane `+json` capability probe, and `resolve_pane`'s cached
  `+list` validation -> plain `+list --tty` when `$GHOZTTY_PANE_ID` is
  absent. The Windows fork is the reference: diff it against
  `upstream/hooks/ghoztty-banner.sh` in this repo.
- Drop the Mac setup flow's jq nag (the "install jq with brew" path) — the
  dependency is gone.
- Validate on a Mac with jq shadowed off PATH: SessionStart + UserPromptSubmit
  through a real pane, both runtime envelopes (the Windows harness
  `test\win32\hook-json.ps1` section C is the shape to mirror).
- Then, on the win seat (small follow-up inside this task or a note back):
  re-vendor so `hooks/` and `upstream/` are byte-identical again and the
  fork tripwires in `GhosttyAssets.zig` flip from "fork is jq-free" to
  "fork is gone" (or simply keep asserting jq-absence, which then holds for
  the mirror too).

- [ ] The brew-jq nag is gone from the Mac setup flow.
