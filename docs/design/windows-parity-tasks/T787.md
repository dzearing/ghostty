# T787 - pane-banner T377 wrapped-line ink probe fails under a T204_NEUTERED build

## Summary

With T204_NEUTERED = true (the negative-control build), pane-banner.ps1's T377 probe reported 'the wrapped line really fills the content column (rightmost ink 196, column ends 687)' - FAIL - while the same probe reads 674 on the shipped build. The neuter only moves GLYPHS to the leading edge of their button box (icon_button.glyphTarget) and, since T282, only changes which buttons light a fill; neither should touch wrapped banner TEXT. So either the neuter has a wider blast radius than it claims, or the probe is timing-sensitive and this was a flake. Reproduce by flipping the flag, rebuilding -Dapp-runtime=win32 -Doptimize=Debug and re-running the script; if it is real, the neuter's documented list of what it breaks is wrong, and if it is a flake the probe needs a settle or a retry. Found while landing T282, which is what made the neutered run observable at all.
