# T540 - viewer-panes.ps1: split off a web viewer falls back to the WRONG terminal's cwd in the full-suite run (last-focused-core-surface drift)

## Summary

Found during T394 (2026-08-06) and **confirmed pre-existing**: the same
assertion fails on an unmodified-HEAD baseline build run from a worktree, so
it is not a T394 regression.

`viewer-panes.ps1` section 11 (T395's negative control) asserts that a
terminal split off a WEB viewer — which contributes no cwd — falls back to
the last focused core surface's cwd, which the section arranges to be
`t395base` (a terminal deliberately placed in a fixture dir). In the FULL
suite run the fallback instead resolves to the run's *first* control
window's terminal (cwd = the caller's repo root, `D:\git\ghoztty\`), so the
assertion fails every full run:

```
FAIL  a web viewer contributes no cwd, so the fallback stands (got 'D:\git\ghoztty\')
```

Reproduced in ISOLATION (fresh app, base split in other-dir, web-viewer
split, split off the viewer) the fallback is CORRECT — `wvterm` lands in the
base terminal's dir. So the defect is specific to the full-suite state:
after ~10 sections of windows/tabs/panes, the app's "last focused core
surface" is not the terminal that was split most recently. Either (a) the
product's focused-surface bookkeeping drifts when many windows exist and
focus lands on viewers between splits, or (b) the test's assumption about
which surface holds app-level focus at that point is wrong.

## In plain terms

When you split a terminal off a web-page pane, the new terminal is supposed
to start in the same folder as the terminal you were last using. In one
test sequence it instead starts in the folder of a terminal from a
different, older window. Users would see an occasional split open in the
wrong directory when several windows are open.

## Where

- `test/win32/viewer-panes.ps1` section 11 (`t395web` / `t395webterm`).
- Product side: whatever tracks "most recently focused core surface" used by
  `Window.newSplitAt`'s cwd fallback (T395 machinery).

## Validation criteria
