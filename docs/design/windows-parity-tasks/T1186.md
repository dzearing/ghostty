# T1186 - The retired agent installer is still live on the website and the relay until someone publishes

## In plain terms

The second Windows installer is gone from the source, but the page people
actually visit has not been updated yet. Until it is, a new user still sees two
downloads and can still install half a product. Nothing they see changes until
someone publishes.

## Summary

T1175 removed the standalone Remote Agent installer from the repo. Two
deployments carry that to the live surfaces, and neither runs from this seat's
normal task boundary:

1. **gh-pages** - `relay/deploy/ghpages/` is the in-repo mirror of
   https://dzearing.github.io/ghoztty/ . Section F of
   `test\win32\website-windows-download.ps1` compares the two and is RED right
   now, correctly, because the mirror moved and the deployed page did not. That
   red IS the outstanding work; it clears itself on the push.
2. **the relay VM** - `relay/deploy/publish-agent.sh` uploads the
   `install.ps1` signpost and the new landing page to
   `/var/www/ghoztty-dl/` and `/var/www/ghoztty-www/`. Until it runs, the
   hosted one-liner still installs the old standalone agent and
   `/dl/ghoztty-agent.msi` still answers 200. Needs ssh to the VM as a
   sudo-capable user.

Also worth doing in the same pass: the stale `Ghoztty-Agent-*.msi` files and
the `ghoztty-agent.msi` alias already sitting in `/var/www/ghoztty-dl/`. The
publish script no longer writes them and no longer prunes them, so they stay
served forever unless someone removes them by hand. Leave
`ghoztty-agent.exe` and `version.json` in place - the `--relay` agent's
self-updater still reads them until T550.
