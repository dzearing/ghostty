# T413 - Cross-machine Restore All still uses the full-ring replay: layout blobs carry no WP-D3 snapshot

## Summary

T109 gave the LOCAL session-layout manifest a per-pane screen snapshot, so a
same-machine re-attach paints our own repaint and asks the agent for a delta.
"Restore All" (T321/T334/T336) rebuilds a topology from the AGENT-held layout
blobs instead, and `layout_blobs.serializeWindow` deliberately STRIPS the
snapshot fields - so every blob-sourced pane still takes the pre-T109 full-ring
replay, with the mixed-geometry loss T109 exists to remove.

## Details

The strip is a considered decision, not an oversight, and any fix has to beat
the reasons for it:

- A blob is re-serialized and pushed to the agent on **every layout mutation**,
  and `blobHash` skipping the unchanged ones is what keeps that mirror cheap. A
  snapshot changes on every capture, so every window would re-upload forever.
- A blob is ~1 KB of topology. A 600-row VT repaint is two orders of magnitude
  larger, per pane, held on the agent's disk.

So this is not "un-strip it". The shapes worth weighing:

1. **A separate, less chatty channel.** Push the snapshot on its own cadence
   (on detach / on a long idle, not on every mutation) under its own key, so the
   topology blob stays small and hash-stable. Costs a new agent-side store.
2. **A much smaller snapshot for the blob** - viewport only, no scrollback -
   accepting a smaller win for a much smaller blob.
3. **Close as won't-fix**, on the grounds that a cross-machine Restore All is
   already re-attaching over a network where a ring replay is the smaller of the
   costs. If so, say it in the design doc rather than leaving the asymmetry
   looking accidental.

Whichever way it goes, the local manifest path must not regress: it is not
pushed anywhere and should keep carrying the full snapshot.

## Validation

`test/win32/session-snapshot-reattach.ps1` is the shape to copy - its C section
reads the app's own `attach: session=... offset=N snapshot=M` line to tell the
delta path from the full-ring path, which is the only way to tell them apart
from outside. A cross-machine arm asserts the same line for a Restore All
against a relay/loopback agent.
