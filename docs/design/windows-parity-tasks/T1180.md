# T1180 - After the cutover, CI on main validates BOTH the macOS and the Windows build on every PR

## Summary

The cutover is only real if main proves both platforms. Once the windows branch is in main, the PR pipeline must build and test the macOS app and the win32 app on every pull request, and a release tag must produce both platforms artifacts from the one tag (release-windows.yml already carries the v* trigger for exactly this). Reconcile fork-ci.yml, test.yml, release.yml and release-windows.yml so there is one green definition of both-platforms-build and no workflow that only exists on one branch.
