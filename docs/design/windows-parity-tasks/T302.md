## The one method that does not work (and must not be retried)

T227 specified the Windows-side reference as *"a real Win11 master-detail dialog
(Settings, Task Manager) captured through `Get-TestWindowPixels`"*. **It does
not work, and it fails silently** - measured, not assumed:

- `PrintWindow(hwnd, dc, PW_RENDERFULLCONTENT)` on Task Manager's main window
  returns a **flat black** 1379x1134 bitmap: **1 distinct color** over a 7px
  sampling grid, an 8 KB PNG. The call reports success.
- The vertical-seam scan over that capture then found **zero** seams, which
  reads as "this app has no master-detail seam" rather than "there is no
  capture". Same failure shape as T214's `GhozttyTerminal` limit: *empty, not
  absent*, so an assertion would pass against nothing.
- Cause is architectural: Task Manager / Settings are WinUI/XAML and composite
  through DirectComposition, never painting into the window DC. The Win32 apps
  that DO capture are classic dialogs - i.e. exactly the ones that do not show
  the Win11 idiom.

So the doc splits the Windows reference deliberately: everything queryable is
**measured** (`SystemParametersInfoForDpi`, `GetSystemMetrics`, `uxtheme`, DWM
registry) and the Fluent language is **cited as documentation**, labeled as such
on every use. Follow-up filed: **T303** (make the silent flat capture loud).

Second lesson, cheap but real: **Task Manager launches elevated, so a
non-elevated session cannot close it again** - `Stop-Process`, `CloseMainWindow`
and `taskkill` all returned Access Denied, and the window was left on the user's
desktop. A reference fixture you cannot clean up is a bad fixture.

## The delta the doc hands T227

13 findings, each with the win32 file and line it was read from. The three that
dominate the surface:

1. **Hardcoded dark everywhere** - `COLOR_BG = RGB(32,32,32)` and friends plus a
   literal `DWMWA_USE_IMMERSIVE_DARK_MODE = 1`
   (`MachineChooser.zig:92-95,310`), duplicated verbatim in
   `HostSettingsDialog.zig:36-39`.
2. **Every wash, divider and hover blends toward `#FFFFFF` unconditionally**
   (`chooser_rows.zig:249-266`) - on a light background the column wash and the
   dividers vanish outright.
3. **The accent is a hardcoded `#3D8EF8`** (`chooser_rows.zig:232`) against the
   box's real `#680081`.

All three are *stated* in the doc but **owned by T203** (system accent +
light/dark), with T273/T274 as the same mechanism; T227 consumes that plumbing
rather than re-deriving it (the T206 rule). The rest - type ramp off on every
role, no avatar/monogram, row radius and icon column off the scale, five
off-scale spacings, no focus indicator on the owner-drawn list, no contrast
floor on `secondary_gray` - are T227's own.
