# T1150 - The fork-identity overlay resolves three fewer files than it did, and nobody noticed for a day

## In plain terms

When this fork takes changes from the upstream Ghostty project, a script
re-applies everything that makes this build Ghoztty rather than Ghostty. A test
measures how much of that the script can do by itself. That number has dropped
by three files, which means three things a human now has to fix by hand at the
next upstream pull — and nothing said so until somebody looked.

## Summary

`test\win32\fork-identity.ps1` section C4 is RED on this branch:

```
FAIL C4 at least 28 of the U-files reproduce from the fork point reproduced=25 baseline=28
FORK-IDENTITY: 1 FAILURE(S) / 48 passed
```

Found 2026-08-23 while clearing guard-due for T1129 — the harness had been DUE
since **8aeb510de** (2026-08-22, *"The three merges this project kept calling
'merge back' now have three names"*), which edited both `scripts/fork-identity.ps1`
and `test/win32/fork-identity.ps1` and was committed without running it. Thirty
commits have landed on top since. This is precisely the hole T783's guard-due
gate exists to close, and it worked — the gate reported it; what did not happen
is anyone acting on the report at the time.

C4 checks out the 52 U-files at the fork point (063ac3ecc), runs the overlay,
and compares against HEAD. 25 now reproduce where 28 did. Either a rule stopped
matching (the terminology rename is the obvious suspect) or three files' HEAD
form legitimately moved beyond what the overlay can derive — in which case the
overlay needs to learn them, not the baseline to be lowered. **Do not close this
by editing `$ReproBaseline`** unless the three files are named and each one's
reason is written down.

## Validation criteria

- [ ] The three files that stopped reproducing are named here, each with why.
- [ ] The overlay derives them again — or, if one genuinely cannot be derived,
      that is stated with its reason and the baseline moves in the same commit
      that explains it.
- [ ] `powershell -NoProfile -File test\win32\fork-identity.ps1` is ALL PASS,
      which re-stamps the guard.
