# T628 - a REMOTE machine on an incompatible protocol reads as merely unreachable

## Summary

Found while building T125. The skew handling landed for the LOCAL agent only.
Every other dial — the machine chooser's session roster, `+new-remote-window`,
the per-window reconnect ladder — still collapses `error.ProtocolIncompatible`
into "could not reach that machine", so a remote box running an incompatible
Ghoztty version is indistinguishable from one that is off.

## In plain terms

If a machine you connect to is running a version of Ghoztty that no longer
matches yours, Ghoztty tells you it could not reach the machine. So you check
whether the machine is awake, whether the network is up, whether the agent is
running — and all of those are fine. The real answer, that the two versions no
longer speak to each other, is the one thing it does not say. The connection
pill turns red and the reconnect ladder retries forever against something that
cannot succeed.

## Goals

- [ ] A remote dial that fails on an incompatible handshake says so, in the
      chooser and on the connection pill, rather than "unreachable".
- [ ] The reconnect ladder stops retrying a skew (retrying cannot fix it) while
      still retrying every transient failure exactly as it does now.
- [ ] Nothing on a remote machine is ever restarted from here — a remote agent
      is not ours to kill; the answer is to update one side.

## Details

`error.ProtocolIncompatible` and `tcp_dial.DialReport` already exist (T125); the
missing part is threading them through `relay_dial.zig` / `RemoteReconnect.zig`
/ `MachineChooser` and giving the pill a distinct state or message. Care: the
pill's three states are already load-bearing for WCAG 1.4.1 (they differ in
whether there is text, not only in hue) — a fourth must not break that.

## Validation criteria

- [ ] An acceptance script dials a local agent forced to a different
      `GHOZTTY_AGENT_PROTO_VERSION` over the remote path and asserts the message
      names a version mismatch, not unreachability.
- [ ] The reconnect ladder does not spin on it.
- [ ] Both zig test lanes, `test-agent`, and P1-P3 stay green.
