# T403 - No structural guard that every A-to-C reply frame type has a client dispatch arm (the T96 defect class)

## Summary

T96 was one missing `switch` arm. `Connection.handleControlInternal`
(`src/remote/connection.zig`) ends in `else => {}`, so a reply frame type with
no arm is **silently ignored** — the parked RPC never wakes, the caller burns
its whole timeout and then reports failure over an operation that in fact
succeeded. Ten reply types had arms; `close_session_result` did not, and nothing
anywhere said so.

The shape is the problem, not the instance:

- The `else => {}` is load-bearing and correct — pushes and future frame types
  must be ignorable — so it cannot simply be removed to get exhaustiveness.
- "Which frame types are RPC replies" is not declared anywhere. It lives in the
  comment column of `protocol.FrameType` (`// A→C  {…}  reply to X`) and in
  which `rpcCall` sites pass which `want`.
- So adding a new RPC means remembering, in a second file, to teach the reader
  about the reply — and forgetting is invisible until someone times a real
  round trip.

## Fix direction

Declare the reply set once, in `protocol.zig`, next to the frame types it
describes — e.g. `pub const rpc_reply_types = [_]FrameType{ .opened, .attached,
.cwd, .sessions, .relaunched, .set_layout_result, .layouts, .proc_snapshot,
.proc_kill_result, .proc_spawn_result, .close_session_result }` — then either:

- have `handleControlInternal` dispatch **from** that set (the arms that only
  call `deliverRpcReply` collapse into one), so a new reply type is wired the
  moment it is declared; or
- keep the arms and add a `none`-lane test that asserts every member of the set
  is delivered, driving each one through a mock agent and failing on the
  timeout — the exact oracle that caught T96.

Prefer the first: a test proves the arm exists today, but only the dispatch
source makes the next one impossible to forget.

## Validation

Delete any single arm (or add a new reply type without wiring it) and the lane
must go red — the T96 negative control, generalized. Today that edit is green
in every lane and only shows up as a 10-second stall on a real box.
