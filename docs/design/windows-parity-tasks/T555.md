# T555 - The win32 command palette has no 'Focus: <pane>' jump entries (Mac lists every surface with its cwd as the subtitle)

## Summary

Split out of T447 (2026-08-07). The Mac palette's `jumpOptions`
(`TerminalCommandPalette.swift` ~221-260) list every open surface across every
window as `Focus: <title>` with the pane's abbreviated cwd as a SUBTITLE, and
selecting one focuses that surface. The win32 palette
(`Surface.zig` `palette_entries` = `commands.registry`) has only static
commands — no per-surface jump entries and no subtitle rendering at all.

Two halves: (1) dynamic entries appended to the filtered list, one per live
pane, dispatching focus; (2) a second dimmed line (or trailing text) per row
so the cwd can ride along — reuse `tab_tooltip.tipText` for the abbreviated
path so the two surfaces agree.

## Validation criteria

- [ ] The palette lists a `Focus: <title>` entry per open pane, across
      windows, filtered like any other entry
- [ ] Each entry shows the pane's `~`-abbreviated cwd (same derivation as
      the T447 tab tooltip)
- [ ] Selecting one focuses that pane's window/tab/pane
- [ ] Covered by an on-box acceptance script; both zig lanes + test-agent +
      P1-P3 stay green
