# T555 - The win32 command palette has no 'Focus: <pane>' jump entries (Mac lists every surface with its cwd as the subtitle)

## Summary

Split out of T447 (2026-08-07). The Mac palette's `jumpOptions`
(`TerminalCommandPalette.swift` ~221-260) list every open surface across every
window as `Focus: <title>` with the pane's abbreviated cwd as a SUBTITLE, and
selecting one focuses that surface. The win32 palette
(`Surface.zig` `palette_entries` = `commands.registry`) has only static
commands — no per-surface jump entries and no subtitle rendering at all.

Two halves: (1) dynamic entries appended to the filtered list, one per live
pane, dispatching focus; (2) a second dimmed line (or trailing text) per row
so the cwd can ride along — reuse `tab_tooltip.tipText` for the abbreviated
path so the two surfaces agree.

## In plain terms

On the Mac, opening the command palette shows a "Focus: …" line for every
terminal pane in every window, so you can jump anywhere by typing a few
letters of its name or folder. On Windows the palette only listed fixed
commands — there was no way to reach another pane with the keyboard at all.
Now the Windows palette lists every open pane the same way, shows each
pane's folder in dim text beside it, lets you filter by that folder, and
Enter takes you there — even when the pane lives in another window or a
background tab.

## Goals

- [x] One `Focus: <title>` palette entry per live pane, across all windows
- [x] Each entry carries the pane's `~`-abbreviated folder as a dimmed
      subtitle, derived exactly like the tab tooltip
- [x] Typing filters on the title AND the folder
- [x] Enter focuses that pane — raising its window and switching to its tab
      when needed
