# T567 - Activity Monitor: the table's column headers are mouse-only - no keyboard way to re-sort

## In plain terms

You can sort the Activity Monitor's process list by clicking a column heading —
but only by clicking it. There is no keyboard way to change what the list is
sorted by, so someone working without a mouse is stuck with whatever the panel
opened on.

## Summary

Found while doing T289 (keyboard focus for the panel). T289 made the panel's
controls tabbable and gave the table a visible focus ring, but the table's
**header** is not a focus stop and has no keys: `onLeftDown` is the only path
into `toggleSort`. Design system §2.2's rule is about drawing a ring on
anything that can be tabbed to; the adjacent rule this trips is that an
operable control needs a keyboard route at all.

Shape of the fix (not decided, this is the sketch): while the TABLE holds
focus, Left/Right could move a header cursor and Space/Enter toggle its sort —
the arrow keys are free there today (the table only uses the vertical ones, and
the carousel's Left/Right belong to the carousel's own focus stop since T289).
The header cursor would need its own visible indicator, which is the same
`activity_layout.focusRing` the caret row now uses. The alternative — making
the header a seventh `Focusable` stop — costs a Tab press on every walk through
the panel for something used rarely.

## Where

- `src/apprt/win32/ActivityMonitor.zig` — `handleKey` (the `.table` arm),
  `onLeftDown`'s header branch, `paintTable`'s header band.
- `src/apprt/win32/activity_layout.zig` — `cellRect` / `columnAt` already give
  a header cell's rect, so the indicator has geometry to sit on.
