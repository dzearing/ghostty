# T1287 - A capture guard that is supposed to refuse a window painting nothing hands back a black picture instead

## Summary

The synchronous window capture prefills its bitmap with a sentinel colour and is documented to FAIL when the window leaves it untouched. Found while fixing T1283: a window purpose-built to answer WM_PRINTCLIENT with nothing (own class, null background brush, DefWindowProcW) captured as solid BLACK, not sentinel, so the guard never fired. Either something wipes the prefill before the window is asked to draw, or the sentinel is being overwritten by PrintWindow itself. Until this is settled, the guard's promise is unproven and the uniform heuristic cannot be handed off to it.
