# T982 - A floor run can die on a process-tree sample that came back empty

## Summary

scripts\floor-lane.ps1's Get-ProcessTree returns a PowerShell ArrayList, which unrolls to $null when the sample finds no processes; the very next line binds it to Get-SelfSpawnedTestPids -Tree, whose parameter refuses null, and the whole -Lane all run aborts mid-lane with a ParameterBindingValidationException instead of running the remaining lanes. Seen once on 2026-08-19 at the start of the lib lane. Fix is one @() at the call site (or a null-tolerant parameter), plus the same audit on the other helpers that take a tree.
