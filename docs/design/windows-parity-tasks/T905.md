# T905 - New persistent sessions spawn holder-backed, so a shell no longer dies with the agent process

## Summary

Increment 2 of the T705 split (design:
`docs/design/agent-nondestructive-handoff.md`). The agent's session spawn path
(`pty_child.zig`) gains a holder-backed `session.Child`: instead of creating
the ConPTY in-process, it spawns a T904 holder and pumps the session over the
holder's control pipe. Flag-gated while it stabilizes
(`GHOSTTY_AGENT_PTY_HOLDER=1`, then default-on).

Load-bearing details:

- The holder must ESCAPE the agent's kill-on-close job — the point is that it
  outlives the agent. `spawnEscapingJob` is the existing pattern; plain
  breakaway is refused from the pane-shell chain, not from the agent spawning
  a supervisor.
- `sessions.json` gains ADDITIVE per-session fields (holder pipe name, holder
  pid, holder stamp). An older agent reading the file ignores them; nothing
  existing changes meaning.
- The holder is not adopted by anyone yet (that is T906) — if the agent dies,
  the shell lives on and the next agent start finds it via T906. Until T906
  lands, an orphaned holder must at minimum be discoverable and killable
  (`+sessions` still lists the session; closing it reaches the holder).

## In plain terms

With this, newly opened terminal sessions get their own caretaker process, so
the session's shell keeps running even if the background manager crashes or is
replaced. This is the first point where "the manager died" stops meaning "your
sessions died" — picking the survivors back up is the next task.

## Goals

- [ ] Holder-backed `session.Child` behind a flag; byte-for-byte behavior
      parity with the direct ConPTY child (output, input, resize, signal,
      exit/tombstone path).
- [ ] Holder escapes the agent's job; agent kill leaves the shell running.
- [ ] `sessions.json` carries the additive holder fields.
- [ ] Existing session-persistence acceptance stays green with the flag ON.

## Validation criteria

- [ ] `test/win32/session-persistence.ps1` ALL PASS with holder-backed
      sessions enabled.
- [ ] Kill the (debug) agent with sessions open: the shell process survives
      (verified by pid liveness + typing into a re-attached pane after T906;
      until then, pid liveness + holder pipe answering).
- [ ] Both zig test lanes + `zig build test-agent` green.
- [ ] With the flag OFF, behavior is bit-identical to today (control arm).
