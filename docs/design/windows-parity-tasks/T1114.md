# T1114 - caption-bar.ps1 captures a flat colour only inside a full sweep - it is green run on its own

## In plain terms

The check on the title bar takes a picture of the window and looks at it. The picture comes back as one flat colour - not a picture at all - so the colour-based part of the check cannot run. Everything else it measures about the title bar passes.

## Summary

`test\win32\caption-bar.ps1` scored `1 FAILURE(S)` in the T1094 sweep with a diagnostic that does most of the triage itself:

```
Get-TestWindowPixels: the capture is UNIFORM - 3858x2118, one color over its whole
interior, still uniform after 11 attempt(s) across 2000ms. That is not a picture of
the window; it is what PrintWindow returns when there is nothing GDI-painted to copy
... The other cause is a window that had not painted yet, which is what the retries
above rule out.
```

The helper already rules out the not-yet-painted case with 11 retries over 2 seconds, and names the other known cause (a DirectComposition window that never paints into its DC). All 23 of the script's other assertions pass, including every hit test and both the press-lights-the-fill and release-cancels behaviours - so the caption bar itself is in good shape.

The 3858x2118 dimensions are full-screen sized, which is consistent with capturing a desktop that has nothing composited onto it. See [[T1100]].
