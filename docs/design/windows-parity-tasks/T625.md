# T625 - the Windows agent-restart dialog has no What's new accessory

## Summary

Split out of T125 on 2026-08-08. Mac's `LocalAgentManager.makeUpgradeAlert`
hangs a `WhatsNewNotesView` off the mandatory agent-restart confirmation, so the
user can see what the restart actually buys them before agreeing to lose their
sessions. The win32 dialog (`App.promptAndRefreshLocalAgent` ->
`ConfirmDialog.show`) has title + body + two buttons and no notes area at all.

## In plain terms

When Ghoztty on Windows asks permission to restart the background process that
holds your terminal sessions -- which closes them -- it tells you the cost and
nothing about the benefit. On a Mac the same dialog lists what the update
actually changed, so the answer is an informed one. Windows users are asked to
give up their sessions on trust.

## Goals

- [ ] `ConfirmDialog` grows an optional notes region (its own scroll area, so
      the notes never resize the dialog), or a sibling dialog reusing the same
      renderer.
- [ ] The agent-restart confirmation passes the AGENT-scoped notes,
      partitioned against the last-seen version, and shows nothing extra when
      there are none.
- [ ] The renderer is the one T624 built -- shared, not a second copy, so the
      window and the accessory cannot drift.

## Details

Depends on T624 for the store, the bundled notes and the tracking. The notes
here are AGENT-scoped only (`release-notes/agent/`), per `release-notes/README.md`:
the dialog asks the user to reset live sessions, so its notes must be the
reasons a user would restart the agent, never viewer/banner/UI items.

Existing win32 code: `src/apprt/win32/App.zig` `promptAndRefreshLocalAgent`,
`src/apprt/win32/ConfirmDialog.zig`, copy in `src/apprt/win32/agent_upgrade.zig`.
