# T838 - The T443 data-breakpoint instrument arms per integrity check, which is too slow to finish a lane - arm per page instead

## Summary

T443's corrupted value is now known to live at a heap address (Page.memory.ptr) that is stable for the life of the page, so crash-databreak.ps1 can arm once per page instead of once per verifyIntegrity call. The per-call shape cost 335,878 arm/disarm cycles at ~2ms each and timed out mid-lane without measuring anything.

## In plain terms

The tool built to catch the memory bug red-handed is currently so slow that it
never finishes a single test run — it stops and restarts its watch hundreds of
thousands of times. We now know exactly which four bytes get scribbled on, and
that address stays put for as long as the page it belongs to exists, so the
watch can be set once per page instead. That is the difference between a tool
that times out and a tool that can actually catch the culprit.

## Goals

- [ ] `crash-databreak.ps1` can arm on `&page.memory.ptr` for the lifetime of a
      page (armed at `Page.init`, disarmed at `Page.deinit`) instead of around
      every `verifyIntegrity` call
- [ ] A run reports arm/disarm counts in the hundreds or low thousands rather
      than 335k, and completes a full lane inside its timeout
- [ ] Only 4 hardware debug registers exist, so the design says explicitly which
      pages it watches and what it is blind to — a partial watch that reads as
      total coverage is the failure mode to avoid

## Details

Background and the disassembly that established the target: T443's
"THE DAMAGED VALUE IS THE FIELD, NOT A COPY" section (2026-08-14, turn 3).
`Page.memory` is field 0 of `Page`, so the load that produced the
half-clobbered base is `mov r9,[self]` — reading the heap field directly, with
no stack temporary in the path.

## Validation criteria

- [ ] An armed run against a real lane completes without hitting
      `-TimeoutSeconds`, with equal arm and disarm counts (the check that the
      armed window is the live one)
- [ ] The instrument is proven against a staged wild write to a page's
      `memory.ptr` high half, the way the per-call shape was proven in T458 —
      writer instruction, full stack, dump
- [ ] `test\win32\crash-databreak.ps1` stays ALL PASS
