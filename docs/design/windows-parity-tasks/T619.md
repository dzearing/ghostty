# T619 - Machine chooser rows carry no live CPU/mem (Mac's MachineChooserView probe)

## In plain terms

Ctrl+Shift+N lists the machines you can open a window on. Each row shows a
name and an address and nothing about the machine itself, so picking one is a
guess: you cannot tell which box is idle and which is pinned until you are
already on it. On the Mac the same list shows each machine's CPU and memory
live, in place of the IP:port.

## Summary

Mac's picker owns a `MachineMetricsProbe`
(`MachineChooserView.swift:45`, created at `:1711`) and puts each machine's
live reading on its row for the lifetime of the presentation — which is what
that class was originally written for; the Activity Monitor's card carousel
borrowed it afterwards. Windows' `MachineChooser` has no equivalent: its rows
carry the directory's `online` flag and nothing else.

Noted as a known gap while doing T298, and checked rather than assumed:
`chooser_rows.RowText` is `title` / `subtitle` / `status` / `glyph` and nothing
else (`chooser_rows.zig:43-49`), and every `Metrics` in `MachineChooser.zig` is
`rowMetrics`, i.e. row GEOMETRY.

## Why it is cheap now

T298 built the whole probe machine for the Activity Monitor:
`activity_probe.zig` owns the policy (which machines to probe, the refused-dial
backoff, the staleness rule, the `host:port` parse) and `ActivityMonitor`'s
`Probe`/`startProbeDial`/`onProbeMetrics`/`stopProbes` own the connections. This
task is that mechanism pointed at the chooser's row list.

Two things it must decide rather than copy:

- The chooser is **modal** and short-lived, so there is no visibility gate to
  honor — but there IS a "the dialog closed while N dials were in flight"
  teardown, and the chooser has no message-only window of its own. The
  `(slot, serial)` landing rule the panel uses is the pattern to follow.
- The chooser lists machines the panel never sees (an unenrolled `host:port`
  typed by hand), so the `Kind` decision has to come from the row, not from a
  directory entry.

## Validation criteria

- [ ] A chooser row for a reachable machine shows a live CPU/mem reading.
- [ ] A machine that refuses the dial shows its address, not a spinner that
      never resolves, and is not re-dialed in a tight loop.
- [ ] Closing the chooser with dials still in flight frees every connection —
      asserted on the socket count, as `activity-monitor-remote.ps1` H7 does.
- [ ] Both `zig build test` lanes plus `zig build test-agent` green; P1-P3 ALL
      PASS.
