# T1157 - The fork-identity check has been red since the merge-terminology commit and nobody was told

## In plain terms

When this project pulls changes down from the original Ghostty, a script
re-applies everything that makes this fork *this* fork — its name, its
branding, its Windows-only bits — over the incoming code, and a second script
checks that the re-application actually worked. That checker is currently
failing. Nothing is broken for anyone using the terminal today, but the next
time we take an upstream change there is no working check standing behind the
part of the merge nobody wants to resolve by hand.

## Summary

C4 of test\win32\fork-identity.ps1 scores 27 of a 28 floor, so the harness that verifies this fork's identity overlay is red. Filed from T1133, which is about exactly this class: the guard has been due since 8aeb510de touched scripts\fork-identity.ps1 and test\win32\fork-identity.ps1, and the go-loop hatched past it once.

## Evidence gathered while filing (T1133's turn, 2026-08-23)

```
FAIL C4 at least 28 of the U-files reproduce from the fork point
     reproduced=27 baseline=28
     reproduced exactly: 27 of 52
     residual (real work, not identity): 25 files
```

Everything else in the harness is green — sections A, B, D and E all pass,
C5 ("check is clean on the overlaid fork-point tree") and C6 ("check FAILS on
the same tree before the overlay") both pass — so the overlay itself is
demonstrably still doing its job. What moved is the FLOOR: `$ReproBaseline`
(`test\win32\fork-identity.ps1:73`) is a hand-set ratchet whose comment says
"Raise this when a rule earns it" and says nothing about what to do when a
U-file legitimately gains real work of ours and stops being identity-only.

Two U-files have been edited on this branch since the harness landed
(`a4291eff7..HEAD`) and are in today's residual list:

- `HACKING.md` (6 commits)
- `src/terminal/modes.zig` (1 commit, `7124457a7`)

So the likely answer is that the drop from 28 to 27 is legitimate drift and
not an overlay regression. **Do not just lower the number** — the whole point
of a ratchet is that moving it is a deliberate act with a reason attached.
Decide whether the floor should be derived (52 minus the measured
real-work set) rather than hand-set, so ordinary work on a U-file stops
reddening a gate that is not about that work.
