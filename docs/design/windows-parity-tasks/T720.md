# T720 - toggle_window_float_on_top still will not stick on a ghoztty window, though the quick terminal's setTopmost does

## Summary

Section E of `test/win32/overlay-zorder.ps1` has announced a SKIP since T277:

```
SKIP E: toggle_window_float_on_top left the window non-topmost - float-on-top
is broken (T277), so the "legitimate topmost owner" case cannot be set up
```

Its stated reason is that *the app cannot reach a legitimately-topmost state on
this desktop at all*. **T180 falsified that.** The new section H toggles the
QUICK TERMINAL and measures, on the same run and the same background desktop:

```
PASS  H: the quick terminal is topmost (positive control)
PASS  H: the quick terminal float propagates to its owned popup (positive control)
```

So a ghoztty window CAN hold `WS_EX_TOPMOST` here. Both paths call the same
`w32.setTopmost` (`App.zig` ~5425 for the action, `QuickTerminal.animateIn` for
the quick terminal), and only one of them sticks — which means the remaining
cause is specific to the float-on-top path, not to the harness, the desktop, or
`SetWindowPos`.

## In plain terms

"Float on Top" in the Window menu is supposed to pin a terminal above your other
apps. On this box it doesn't — the window comes straight back down. The quick
terminal pins itself just fine, so whatever is wrong is in that one menu action,
not in Windows.

## Where to look

- `src/apprt/win32/App.zig` ~5410-5435 — the action: early-returns when the bit
  already matches, then `w32.setTopmost`, then heals the owned popups.
- `src/apprt/win32/QuickTerminal.zig` 112-140 — the path that DOES stick, for
  comparison.
- `w32.healOverlayZOrder` demotes a stray-topmost popup, and Windows drags an
  owner out of the topmost band along with any owned window that is demoted —
  worth ruling in or out as the thing that undoes the float a moment later.
- Section E's own note says an INJECTED `HWND_TOPMOST` on a `GhozttyWindow` did
  not stick either, while the same injection on an overlay popup does (section
  B). That asymmetry is the sharpest clue and should be re-measured first.
