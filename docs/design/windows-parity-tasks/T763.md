# T763 - Establish whether macOS in-place recovery retries after its re-dial ladder gives up (T723's Mac half)

## Summary

T723 found and fixed the win32 hole: a recovery that could not re-dial simply returned, and the abort was terminal because a link already in reconnecting never produces a second down edge. Mac has a short ladder INSIDE the re-dial (attempts x 1.5s) plus warmUp() retrying in the background, which may or may not cover a wedge that outlasts it. Measure it the way T723 did - suspend the agent past the ladder, then kill it - and if the panes stay frozen, port the bounded backed-off retry and the give-up notice.
