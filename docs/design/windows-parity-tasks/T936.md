# T936 - Make the composer's image chips DOM nodes, with paste handled by the browser engine

## Summary

Image chips stop being hand-carried OLE/placeholder runs and become inline elements in the contenteditable, so deleting one is ordinary editing and clipboard image paste arrives as the page's own paste event instead of a Ctrl+V interception that has to swallow the WM_CHAR behind it. The attach paths that originate natively - the screenshot region selector and attachImage - post their PNG down the composer bridge. The thumbnail carousel keeps reading which image numbers are live from the document.

Split out of T830; read its `## Design` section first.
