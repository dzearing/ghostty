# T747 - Machine chooser 'Sign in with Google' button does nothing

## Summary

User report 2026-08-11: clicking the Sign in (with Google) button in the machine chooser's account row does not work - no browser opens / no sign-in flow starts. Expected: the relay-brokered OAuth flow launches the default browser with the PKCE authorization URL and completes sign-in. May be related to T746 (Ctrl+Shift+N chooser not opening) if the chooser itself is broken; verify independently. Relevant code: src/remote/relay_signin.zig, src/apprt/win32/RelayAccountRow.zig.

## Progress log

- 2026-08-12 05:44: Root cause found while working T746, from the user's own installed-release log (%LOCALAPPDATA%\ghoztty\ghoztty.log): every press of the Sign in button logs 'warning(win32): relay account: sign-in failed err=error.NoClientId' followed by 'relay account: sign_in failed'. The button is wired and the click IS arriving - the shipped build simply has no Google OAuth client id baked in (-Dgoogle-client-id is unset and GHOZTTY_GOOGLE_CLIENT_ID is not in the environment), so relay_signin aborts before opening a browser. Two things to fix rather than one: (a) the delivery/build must carry a client id, and (b) a missing client id must SAY so in the UI instead of failing silently - a dead button is the worst possible presentation of a build-configuration problem.
