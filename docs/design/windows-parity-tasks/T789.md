# T789 - pane-banner.ps1 has two sections both labelled 6g

## In plain terms

Two different blocks of the banner test are both called "section 6g", so a
note that says "the 6g assertions" points at two places. Nothing is broken for
a user; it wastes the time of whoever reads the test next.

## Summary

`test/win32/pane-banner.ps1` labels two separate blocks `6g`:

- line 618 — `6g. T209 / T204: the chevron is an ICON BUTTON, and hot-tracks`
- line 734 — `6g. T123: table columns size to the PANE, not a fixed 360pt cap`

The label is load-bearing prose: `BannerOverlay.T123_NEUTERED`'s doc comment
and the script's own header both cite "section 6g" as the claim list a
negative control adjudicates, and T283 had to disambiguate them by naming the
task instead ("the T123 table block in section 6g"). The comment at line 238
citing "6g's `banner chevron hover=` oracle" means the OTHER one.

## What to do

Renumber one of them and follow the references. `6h` is already T377's, so the
cheap move is to renumber forward from the chevron block (or split as `6g1` /
`6g2` if a full renumber ripples too far into task files and the log). Then
update every citation: `BannerOverlay.zig`'s `T123_NEUTERED` and
`T377_NEUTERED` comments, the script header, the line-238 stderr note, and
`CLAUDE.md`'s "section 6f2"/"section 6j" neighbours if the letters move.

- [ ] No two sections in `pane-banner.ps1` share a label
- [ ] Every in-repo citation of the renamed section points at the right block
