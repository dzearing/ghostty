# T810 - The Activity Monitor and Restore All still dial their own per-machine connections instead of borrowing the pool's

## Summary

T461 made one warm connection per machine the rule for the chooser's roster and Kill, but two other remote surfaces still open their own: ActivityMonitor.dialWorker dials the relay per panel (falling back to borrowing a WINDOW's connection via activity_borrow), and RestoreAllRelay gives every rebuilt window its own dial. Both pay the upgrade+auth cost the pool removes, and neither can host a subscription. Convert them onto App.machine_pool leases; the win32 detail to preserve is that a rebuilt remote WINDOW must still own its transport (it frees it on close), so Restore All's per-window dial is not simply a pool borrow.
