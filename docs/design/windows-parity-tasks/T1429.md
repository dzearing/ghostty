# T1429 - A machine restored after an unanswerable sign-out comes back under its hostname, not the name the user gave it

## Summary

Follow-up to T1425. The suspension record keeps the machine's relay-side DISPLAY name so it returns to the chooser as itself. When the sign-out was forced through against a relay that never answered, there is no display name to keep - whoami could not be asked - so the record stores none and the restore enrolls under this machine's hostname. A user who renamed their box in the machine chooser sees it come back under the old hostname instead, silently. The fix is to remember the name from a source that does not need the relay at sign-out time: the chooser already lists the account's devices, so the name for THIS machine's device id can be cached when it is seen and read back here.
