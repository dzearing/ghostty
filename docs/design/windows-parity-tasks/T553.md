# T553 - Mac +list --json: report session_id on agent-backed terminal panes (Mac half of T332)

## In plain terms

On Windows, `ghoztty +list --json` now tells you which background session each
pane is showing, so scripts can match panes to sessions. The Mac app doesn't
report that yet, so the same script gives poorer answers on a Mac. This brings
the Mac side up to match.

## Summary

T332 (win32) added an additive `session_id` field to `+list --json`'s
terminal-pane objects: present when the pane is bound to a session-persistence
agent session (the join key against `+sessions --json`), omitted for plain
panes and viewers. The shared serializer shape is pinned in
`src/apprt/ipc/list.zig` (`test "List: session_id is additive (T332)"`).

The Mac server's Swift encoder (`IPCMessage.swift`) does not emit it. Add the
same field with the same semantics: emit only when the surface has a live
agent session id, omit otherwise (additive — old CLIs parse with
ignore_unknown_fields).

## Validation criteria

- [ ] `+list --json` on macOS reports `session_id` for a session-persistence
      pane and omits it for a plain pane and a viewer
- [ ] The id matches the `+sessions --json` row that reports `attached`
- [ ] Field name and placement match the win32 wire shape (join scripts are
      cross-platform)
