# T340 - Mac seat: build + keybind-verify the T29 action-fallthrough fix

## Summary

**T29's fix is Swift-only and was written on the Windows box, which has no
Swift toolchain.** It compiles nowhere in this seat's floor, so it shipped on
a code read plus git archaeology and nothing else. This task is the runtime
half, and it belongs to the **Mac seat**.

The fix (`macos/Sources/Ghostty/Ghostty.App.swift`): `SHOW_CHILD_EXITED` is
its own case again, and `TOGGLE_TAB_OVERVIEW` / `TOGGLE_WINDOW_DECORATIONS` /
`SIZE_LIMIT` / `QUIT_TIMER` end in the restored `known but unimplemented ...
return false` body instead of falling through into it. Full root cause,
including the upstream commit that introduced the chain (`38e64c370`), is in
**T29**.

## Why it is worth running rather than assuming

The pre-fix path read a C union's `child_exited` member for actions whose
payload is `void`, i.e. **undefined bytes** (see T341). The visible symptom is
therefore nondeterministic: a "process exited" bar over a *live* surface,
only when the garbage `timetime_ms` happens to be nonzero. A build that comes
up clean once does not clear it — the interesting check is the one that used
to be able to misfire.

## Validation

On a Mac:

1. `zig build -Doptimize=Debug` + the macOS app builds (the Swift change is
   syntactic risk first: a `fallthrough` chain whose final arm now carries the
   body, so a mis-edit is a compile error, not a silent behavior change).
2. Bind and press `toggle_window_decorations`. Expect: nothing visible on
   macOS (it is unimplemented there) and **no child-exited bar** on the live
   surface. Confirm `known but unimplemented action action=<n>` in the log.
3. Same for `toggle_tab_overview`.
4. Open a window and confirm no child-exited bar appears at surface creation
   (`size_limit` is emitted on every surface init — `Surface.zig:1132`).
5. `quit-after-last-window-closed = true`: close the last window, app quits.
   This is handled by
   `AppDelegate.applicationShouldTerminateAfterLastWindowClosed`, not by the
   `quit_timer` action, so returning false must not change it.
6. Kill a shell (`exit 1`) and confirm the child-exited bar **still works** —
   the case it belongs to must not have been broken by splitting it out.
