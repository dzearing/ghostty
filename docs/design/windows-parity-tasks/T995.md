## In plain terms

A test script can decide to skip a whole section - the machine is missing
something, or an earlier step did not produce what the section needs. When that
happens, the single line the loop reads at the end has to say so, or a run that
quietly dropped a section looks exactly like a run that checked everything. The
handoff test had that hole: it could skip its "nothing was lost" section and the
final line never mentioned it. This closes the hole and turns the audit that
watches for it green again, so it can go on catching the next one.
