# T1176 - The one Windows MSI installs client and agent and launches Ghoztty when it finishes

## Summary

Installing should end with a running terminal, not a Start Menu entry the user has to find. The MSI must (a) verifiably lay down ghoztty.exe, ghoztty.com and ghoztty-agent.exe together, and (b) launch Ghoztty on completion of a successful install (and not on a silent/upgrade-in-place install driven by the updater). Add the acceptance coverage that proves both, so a build that drops the agent fails the release lane instead of shipping.
