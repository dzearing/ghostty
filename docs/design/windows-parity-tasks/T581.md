# T581 - win32's divider fallback is a fixed #808080 while Mac derives it from the background

## In plain terms

If you never set a divider color, the Mac picks one that suits your terminal's
background — a slightly darker version of it — while Windows always draws the
same mid gray. On most themes nobody notices; on a light theme the Windows gray
is a heavier line than the Mac's, and it is a different line for the same
settings.

## Summary

Found while doing **T251**. `Window.paintDividers` falls back to a hardcoded
`#808080` when `split-divider-color` is unset, while Mac's `splitDividerColor`
(`macos/Sources/Ghostty/Ghostty.Config.swift:535`) derives its default from the
terminal background: `darken(by: 0.08)` on a light background, `darken(by:
0.4)` on a dark one. Two seats, one config, two different lines.

This is cosmetic rather than a legibility hole — since T251 the win32 fallback
goes through the same 3:1 floor as a user color, so it can never vanish. What
it is NOT is parity.

Worth noting before porting Mac's formula verbatim: darkening a background
toward black is exactly what produces an invisible divider on a black terminal,
which is the shape of the bug T251 fixed. Whatever lands here should go through
`split_geometry.dividerPaint` like every other divider color, so the floor
catches it.

## Where

- `src/apprt/win32/Window.zig` — `paintDividers`, the `0x80` literal.
- `macos/Sources/Ghostty/Ghostty.Config.swift:535` — the Mac formula.
- `src/apprt/win32/split_geometry.zig` — `dividerPaint`, which the fallback
  must keep going through.

## Validation criteria

- [ ] With no `split-divider-color` set, the win32 divider is derived from the
      terminal background the same way Mac's is (or a recorded decision that
      the fixed gray is deliberate).
- [ ] The derived fallback still clears the 3:1 floor on a black background and
      on a white one — unit tests in `split_geometry.zig`.
- [ ] `test/win32/split-divider.ps1` run 2's fallback assertion updated to the
      new expectation rather than deleted.
