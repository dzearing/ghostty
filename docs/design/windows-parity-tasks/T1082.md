# T1082 - 40+ private copies of "which ghoztty processes are ours" - the enumeration half of the CleanSlate sweep

## In plain terms

Test scripts do not only close our app - they count it, to assert things like
"the background service survived" or "exactly one window is left". Every script
answers "which of these processes are ours?" in its own way, and the answers
disagree the same way the close-the-app copies did before T351. A script using a
loose answer can count a completely unrelated build the developer has running and
pass, or miss ours and fail for nothing.

## Summary

T351 hoisted the KILL onto one shared `Stop-RepoGhoztty`. The predicate underneath
it - *is this process ours?* - is still written out by hand in 40+ scripts, under
names like `Get-TestApps`, `App-Pids`, `Get-TestAgents`, `Get-RunAgents`,
`Count-TestProcs`, each with its own filter:

- `$_.ExecutablePath -eq $Exe` (exact, correct)
- `$_.ExecutablePath -like (Join-Path $repo 'zig-out*')` (also matches
  `zig-out-release`, the T53b divergence)
- `$_.CommandLine -like '*zig-out*'` (matches CLI invocations too)

`lib\CleanSlate.ps1` already derives both exact paths (`$Exe` and
`Get-GhozttyAgentPath`), so the shared predicate is a few lines away from
existing. It is the same T257 shape as T351, one step removed - and it matters
more than it looks, because an enumeration decides what a test ASSERTS on, not
just what it cleans up.

## What to do

- Add `Get-RepoGhozttyProcesses -Exe <exe> [-AppOnly|-AgentOnly]` to
  `lib\CleanSlate.ps1`, and express `Stop-RepoGhoztty` in terms of it so there is
  one filter, not two.
- Convert the private enumerations, keeping any script-specific extra predicate
  (this run's state root, `--pty-host` children, `-notmatch '\+'`) local and
  applied on top.
- Extend `lib\CleanSlateAudit.ps1` to report an unexplained private ENUMERATION
  the same way it reports a private kill, with the same
  `# cleanslate-exempt: <reason>` escape.

## Validation criteria

- [ ] `test\win32\cleanslate-audit.ps1` reports zero unexplained enumerations
- [ ] the shared predicate has unit-style fixtures for each filter it replaces
- [ ] the guards the edits make due are re-run green and re-stamped
