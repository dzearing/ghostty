# T922 - A pane restored after a reboot comes back empty instead of showing what was lost

## Summary

Under session-relaunch=restore the Windows client OPENs a brand-new session for a dead tombstone, and deliberately paints neither the agent ring replay nor the app's own WP-D3 screen snapshot above the fresh prompt (termio/Remote.zig excludes did_notify from both). Main's restore (c76b5c89d) keeps the dead session's scrollback so the user can read what the process left behind. So after a reboot a Mac pane shows the last output of the thing that died and a Windows pane shows only the notice and an empty prompt.
