# T397 - Viewer panes: hero-mode carousel tile for a viewer pane (Mac snapshots viewers now; win32 paints a hole)

## Summary

Split out of T90g (2026-08-02), and it is a **decision task before it is a
code task**: T90a §13 said viewer leaves are EXCLUDED from hero mode "Mac
parity — `compactMap(\.surfaceView)`". **Mac has since changed.**
`HeroModeView.swift:11` now reads "Every pane participates: terminals and
viewers alike. This must stay the full leaf list", and
`HeroCarouselView.swift:398` snapshots a viewer with
`WKWebView.takeSnapshot` (async, with an in-flight guard so the repeating
timer cannot stack captures). So the exclusion T90a pinned is now the
divergence.

## Details

Where win32 stands today (`HeroCarousel.zig`):

- `geometry()` counts EVERY leaf (line 90-93), so a viewer occupies a tile
  slot and is selectable.
- the paint loop does `const surface = entry.view.surface() orelse continue`
  (line 206), so that slot paints **nothing** — a hole in the strip, not an
  exclusion.

Either answer is coherent; the current state is neither. Decide and make the
code say it:

1. **Participate (Mac parity, preferred).** Windows analog of
   `takeSnapshot` is `ICoreWebView2::CapturePreview` (async, PNG/JPEG into a
   stream) → decode → DIB, with the same in-flight guard. Needs measuring:
   cost per capture, and whether `PrintWindow` with `PW_RENDERFULLCONTENT`
   over the WebView2 host is a cheaper path (T211's lesson says PrintWindow
   got chrome, not the GL surface, for a TERMINAL pane — a Chromium child
   may differ, so measure rather than assume).
2. **Exclude properly.** `geometry()` counts terminal leaves only, tile
   index maps through the filtered list, hero selection skips viewers, and
   entering hero in a viewers-only tab is a no-op (T90a §13's own words).

Whichever lands, the hole is the bug to close.

*Validation:* `test/win32/hero-mode.ps1` grown — a tab with a terminal and a
viewer: every carousel tile paints non-background pixels (the hole is what
this catches), and arrow navigation lands somewhere coherent. Pure half in
`hero_math`/the count derivation, asserted at 1.0/1.25/1.5/2.0.
