# T547 - Windows: 'Share this machine' toggle plus device enrollment in the machine chooser account row

## Summary

GUI half of T417 on Windows: the machine chooser's account row (RelayAccountRow.zig) gains a 'Share this machine' toggle. Toggling on runs device enrollment when %LOCALAPPDATA%\ghoztty\relay.env is absent (the existing browser OAuth from enroll.zig, driven off the UI thread like sign-in), writes the agent's persisted sharing state, and pokes the local agent to bring the uplink up; toggling off tears the uplink down (credential kept). No new CLI verb (T141 rule). See docs/design/one-installer-agent-consolidation.md.

## In plain terms

Ghoztty can show you your other computers and open terminals on them — but
there was no switch anywhere in the app to let THIS computer be one of those.
Turning sharing on meant hand-editing a hidden config file. Now the machine
chooser (Ctrl+Shift+N) has a "Share this machine" checkbox in its top row:
tick it and this PC joins your account (a browser page confirms it the first
time), and your other devices can open terminals here; untick it and they
can't, without losing the machine's registration. What the switch controls
takes effect within a few seconds, no restart needed.

## Goals

- [x] A "Share this machine" checkbox in the machine chooser's account row,
      off by default (sharing is opt-in, decision D22)
- [x] Ticking it with the machine already registered turns sharing on with a
      single config write the agent picks up within ~5s (T546 reconciler)
- [x] Ticking it on an unregistered machine first runs browser device
      enrollment (off the UI thread, like sign-in), then turns sharing on
- [x] Unticking turns sharing off but keeps the machine's credential
- [x] A failed enrollment reverts the checkbox — it never shows a state the
      work did not reach
- [x] No new CLI verb (T141 rule); the affordance is GUI-only
