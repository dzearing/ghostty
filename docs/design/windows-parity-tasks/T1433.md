# T1433 - A remote window that is reconnecting still says which machine it is

## Summary

D93 was answered o2: the remote connection pill must keep the machine name visible in every state, with the status after it, instead of swapping the name out for 'Reconnecting... n/5' / 'Reconnect'. Today src/apprt/win32/remote_pill.zig replaces the label wholesale while the link is degraded (the assumed o1 behaviour), which makes three dropping remote windows look identical in the titlebar. Ellipsize the name aggressively so the widened chip cannot eat the tab strip.

## In plain terms

You have three remote windows open and two of their connections wobble. Until
now the little chip in each titlebar stopped saying which machine it was and
started saying "Reconnecting... 3/5" instead, so the two dropping windows looked
exactly alike and you had to hover one to find out which was which. Now the chip
keeps the machine's name and puts the status after it -- "winbox -- Reconnecting
3/5" -- so you can still tell them apart at a glance. A long machine name gets
cut short with an ellipsis while the status is showing, so the wider chip cannot
crowd the tabs out of the titlebar.

## Goals

- [x] the machine name stays visible in every connection state, with the status after it
- [x] a window with no machine to name still says just "Reconnect", never "-- Reconnect"
- [x] the name is ellipsized aggressively while a status shares the chip, so the tab strip keeps its row
- [x] in a squeeze the name gives way before the status, but never disappears entirely

## Validation criteria

- [x] `label()` composes name + status in both degraded states, and stands the status alone when there is no machine to name -- unit tests in `remote_pill.zig` ("the machine is named in EVERY state", "no orphan dash"), green in the win32 lane.
- [x] the degraded name ceiling is real and tighter than the resting one -- `width: a degraded pill holds the name to a tighter ceiling (D93)`, asserted at 1.0/1.25/1.5/2.0.
- [x] the squeeze falls on the name first and stops at its floor -- `layout: the squeeze falls on the name first, and stops at its floor`.
- [x] on the box, a dropped link's pill oracle still carries the machine name with the status after it -- `test/win32/remote-pill.ps1` section 3.
- [x] standing floor green -- `scripts/floor-lane.ps1 -Lane all`.
