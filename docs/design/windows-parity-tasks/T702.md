# T702 - connection.zig tests spawn mock-agent threads that are never joined when the body returns early

## Summary

A test that spawns a mock-agent thread and joins it only at the end of the body leaks that thread on every 'try' in between; the thread then reads into a MockAgent the body's defers are about to free - the T693 use-after-free class reached by a different route, and it only fires when the test was already failing. T693 guarded the two sites it touched with a disarming errdefer; 21 spawn sites in the file were not audited.

## In plain terms

When one of these automated tests fails, it should tell you what went wrong.
Right now a failure can instead hang the run or take it down with a crash, so
the message you actually needed never gets printed. Nobody sees this on a good
day — it only bites on the day something is already broken, which is the worst
possible time for the test suite to stop making sense.

## Goals

- [ ] Every spawned mock-agent thread in `connection.zig`'s tests is joined on
      the failure path as well as the success path
- [ ] The guard is one line, not five, wherever it repeats

## Details

The shape T693 fixed twice:

```zig
const ath = try std.Thread.spawn(.{}, InboundAgentCtx.run, .{&ictx});
try conn.start();          // <- any failure here leaks `ath`
_ = try conn.waitHandshake();
ath.join();
```

The guard it used, which must disarm (a second join is UB) and must close the
stream first (the agent thread is parked on a read that nothing else unblocks):

```zig
var ath_joined = false;
errdefer if (!ath_joined) {
    conn.shutdown();
    ath.join();
};
```

Work: sweep the 21 `std.Thread.spawn` sites in `src/remote/connection.zig`,
guard each one whose join is not already unconditional, and factor the pattern
into a small test helper if the repetition earns it.

## Validation criteria

- [ ] Every spawn site is either guarded or documented as unconditionally
      joined (name each in the progress log)
- [ ] A deliberately-failed assertion in a guarded test reports the failure
      rather than hanging or crashing (teeth-check at least one site)
- [ ] All three zig lanes stay green via `scripts\floor-lane.ps1 -Lane all`
