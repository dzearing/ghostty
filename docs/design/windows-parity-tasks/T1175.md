# T1175 - One Windows installer, not two: retire the standalone agent MSI from the website, the relay download endpoint and install.ps1

## Summary

The download page offers a Ghoztty MSI AND a separate Remote Agent MSI (relay /dl/ghoztty-agent.msi + an irm|iex install.ps1 one-liner), so a new user can install half a product. The single Ghoztty MSI already carries ghoztty-agent.exe as a required sibling, so the second installer is pure divergence. Remove the agent download card, the one-liner, the agent-version JS and the relay /dl endpoints from dist/website + relay/deploy/ghpages; retire relay/deploy/msi and relay/deploy/install.ps1 and publish-agent.sh; strip standalone-agent install steps from the CI workflows that build or publish them. One installer is the only supported Windows install path.
