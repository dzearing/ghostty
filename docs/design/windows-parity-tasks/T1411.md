# T1411 - the host-floor test retries a refused WebView2 environment but not a refused controller

## Summary

T592 made the host-floor test in src/apprt/win32/ViewerPane.zig ask again when the ENVIRONMENT is refused transiently (Failure.isTransient), which is the shape all three recorded occurrences took (hr=0x80004005 out of onEnvironmentCompleted). The CONTROLLER half can fail the same way and is not retried: onControllerCompleted lands the pane in .failed with create_callback_failed, and the test then takes its skip branch - which is a PASS, so a transient controller refusal silently costs the whole ABI round trip the test exists for rather than going red. Retrying it means rebuilding the pane and its host window, not just re-initing the Host, which is why T592 scoped it out. Deliberate: the environment retry covers the observed failure and the skip branch now names which kind happened, so a recurrence on the controller side is readable in the lane log before anyone has to guess.
