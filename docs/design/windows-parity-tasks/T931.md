# T931 - The dashboard cannot tell you the box stopped signing itself in

## Summary

T829 measures every reboot's boot-to-desktop gap into temp\go-loop-boots.jsonl and shouts once at claim time when the box waited for a human. A watcher who missed that single line has nowhere to look it up, and the standing 'needs a human' state - the Windows auto-sign-in toggle that closes the last link - is invisible on the board. Wanted: the dashboard reads the boot ledger and go-loop-boot.ps1 check, and shows total loop downtime from reboots plus a persistent banner while unattended sign-in is off.
