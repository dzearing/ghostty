# T1389 - Nothing catches a ninth hand-written font size appearing outside the type ramp

## Summary

T310 counted seven copies of `px(15, scale)` and T313 retired them; T583 then found an EIGHTH that the sweep had walked straight past because it was spelled differently (`const FONT_H: f32 = 15.0`), and it sat on the most-looked-at surface in the app for three weeks. The lesson is not that the count was wrong, it is that the count was a one-time grep. Nothing today would notice a ninth. Add a check that fails when a win32 UI module names a font height that `type_ramp` does not - a source scan in the none lane over `src/apprt/win32/*.zig` for `CreateFontW` heights and float/int size constants, with an explicit allowlist for the deliberate exceptions (the terminal font, Consolas code spans) so an exception has to be declared rather than merely existing.
