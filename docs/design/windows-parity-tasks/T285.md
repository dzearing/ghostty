# T285 - T226b: ActivityMonitor.zig window + source registry + LOCAL metrics/proc table

## Summary

Second of the four-way split of **T226**. The window itself: an owner-drawn
win32 panel in the shape of `MachineChooser.zig`, painting the regions T284
computes, fed by the LOCAL source only.

- `ActivityMonitor.zig` - owner-drawn, sharing `icon_button.zig`,
  `banner_card.zig` rim constants and the T206 visual language, and obeying
  `docs/design/win32-design-system.md` (mandatory reading before any chrome
  change).
- A window **registry keyed by source** (`.local` / `.remote(machine)`), so a
  second open FOCUSES the existing panel instead of duplicating it, and close
  tears down exactly once. Mac:
  `macos/Sources/Features/Remote/RemoteActivityMonitor.swift`.
- LOCAL data plane, already cross-platform and Windows-implemented:
  `src/remote/agent/metrics.zig` (`sampleWindows`) and
  `src/remote/agent/proc.zig` (`sampleWindows`). Sample on a timer, keep the
  trend ring, paint the two gauges.
- The process table: header, selection (multi), sort by column, and the
  filter field narrowing on name or PID. Actions belong to T286.
- Entry point: the win32 command palette (T189 gave win32 one command list,
  so it is one row there). The chooser's Activity button is T287/T177.
