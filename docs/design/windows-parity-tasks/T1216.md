# T1216 - The MSI packaging harness has been due since the installer script changed, and needs Docker to clear

## In plain terms

Nobody has checked the Windows installer since the script that builds it was
last edited. The check exists and is red; it just cannot be run without Docker
running on this machine, and nothing was tracking that it had gone stale.

## Summary

`scripts\guard-due.ps1 check` reports:

```
GUARD DUE release-artifacts-packaging: test\win32\release-artifacts.ps1 has not
been run since these changed:
    changed  dist/windows-installer/build-msi.sh
  run: powershell -NoProfile -File test\win32\release-artifacts.ps1 -RequireDocker
```

The change is `e2a706dc4` ("Installing over a running Ghoztty no longer ends
your live terminal sessions") - an edit to the MSI build script from an earlier
turn. The guard has been due since, and T1147's turn is the first to be blocked
by it, which is the guard working: `parity-tasks.ps1 validate` fails on it.

It could not be cleared in that turn. The harness needs Docker (`msitools-local`
- see the notes on the MSI pipeline), and starting Docker Desktop unasked on
this box is ruled out by a standing user directive: its WSL2 backend has taken
the machine to 28GB of RAM and buried it, so Docker-down is a SKIP path, never
something to fix on the way past. T1147 committed under `validate -NoGuardDue`,
which prints that it was used.

So this task is the receipt: run the packaging harness with Docker up, confirm
the installer still builds and behaves after `e2a706dc4`, and let the clean run
re-stamp the guard. If it turns out red, the finding is about `e2a706dc4`, not
about this task.

## Where

- `test/win32/release-artifacts.ps1` (`-RequireDocker`)
- `dist/windows-installer/build-msi.sh` - the change that made it due
- `scripts/guard-due.ps1` - the `release-artifacts-packaging` coverage row

## Goals

- [ ] The packaging harness runs green against the current installer script.
- [ ] The guard is stamped, so `validate` stops needing a hatch for it.

## Validation criteria

- [ ] `test\win32\release-artifacts.ps1 -RequireDocker` is ALL PASS with no
      skipped sections
- [ ] `scripts\guard-due.ps1 check` no longer reports
      `release-artifacts-packaging` as due
- [ ] `scripts\parity-tasks.ps1 validate` passes without `-NoGuardDue`
