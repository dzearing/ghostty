# T606 - The Windows MSI build exports its tables into the repo root; main moved them to a scratch dir

## In plain terms

Building the Windows installer leaves generated files lying around in the repo,
including a near-megabyte binary blob that was committed by accident. After this,
a build cleans up after itself and `git status` stays quiet.

## Summary

Upstream: `e2d48ac08` "build(msi): export MSI tables from a scratch dir, not the
repo root" - `relay/deploy/msi/build-msi.sh` exports into a temp dir, six
`.gitignore` entries added, and `Binary/Binary.AgentCA` (848 KB) deleted.

Check whether `Binary/Binary.AgentCA` exists on this branch and remove it here
too if so.
