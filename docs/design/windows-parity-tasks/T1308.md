# T1308 - Work the stale-scan backlog: 75 open todos were named by a later commit and nobody checked

## In plain terms

Some cards in the queue describe problems that have already been fixed, or
half-fixed, by work done under a different card. Until now nobody found out
until an agent picked one up and spent a turn discovering there was nothing to
build. There is now a report that points at the likely ones; this is the work of
going through it.

## Summary

T404 shipped `parity-tasks.ps1 stale-scan`, which ranks every open todo by two
signals: whether a LATER commit's message NAMED the task (high precision - a
follow-up that fixed it in passing, a split that absorbed it, a duplicate that
closed it), and whether the files the card itself names have moved since it was
filed.

On 2026-09-03 it reported **75 of 407 open win-seat todos named by a later
commit**, and 264 whose named files have moved. T404 verified the top four and
that alone produced three different outcomes - which is why the report is a
prompt and not a verdict:

| Card | Outcome |
|---|---|
| T606 | **Already fixed** - by `e2d48ac08`, which arrived with a main intake and was never linked back. Closed. |
| T726 | **Partly fixed** - the four sites it named are declared now, but the audit drifted to 49 of 274 and grew a second, unrelated red. Summary rewritten to what is left. |
| T767 | **Still entirely real** - the stale caption arithmetic is untouched. |
| T670 | **Still entirely real** - no window-pick mode exists. |

## Details

The work: run

```
powershell -NoProfile -File scripts\parity-tasks.ps1 stale-scan -Top 75
```

and take the `named=` rows in order. For each, the T404 rule:

1. **Already fixed** - `set-status <id> -Status done -Commit <the sha that
   ACTUALLY fixed it>`, and land the validation the card was owed, because the
   deliverable of an already-fixed card is its missing test.
2. **Partly fixed** - rewrite the Summary to what is LEFT, so the next agent
   does not implement over a fix it never read. Tick what is already true in
   the validation criteria, with how it was verified.
3. **Still real** - leave it open and journal the re-verification against
   today's code, so the next agent does not re-derive it.

Split it if it does not fit one context: this is a report that can be re-run,
so a turn that works the top twenty and journals where it stopped loses
nothing.

## Validation criteria

- [ ] Every `named=` row in the report as of the day the work starts has one of
      the three outcomes recorded in its own file.
- [ ] Each already-fixed close names the commit that actually fixed it, not a
      new one, and lands the validation the card was missing.
- [ ] Each partly-fixed card's Summary describes what is left, not what was
      filed.
- [ ] `parity-tasks.ps1 validate` is green afterwards.
