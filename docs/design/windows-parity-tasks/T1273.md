# T1273 - caption-bar.ps1 ends on a UNIFORM capture of the maximized window, so its last section never scores

## Summary

Every run of test\win32\caption-bar.ps1 ends '1 FAILURE(S) - Get-TestWindowPixels: the capture is UNIFORM - 3858x2118'. The throw lands right after 'maximized: the caption row is on screen', so whatever the script asserts about the MAXIMIZED window's chrome is never reached. Reproduces byte for byte on the HEAD copy of the script (checked while T363 was rewriting its color checks), so it is not a regression from that work - it has simply been red and unread. Fix: find out why PrintWindow returns a uniform bitmap for the maximized window (a full-screen-sized capture of a window that repainted through DWM is the usual shape - see the CAPTURE LIMIT header in lib/TestDesktop.ps1) and either sync the capture the way T941 did elsewhere or score the maximized claim without a capture. Validation: caption-bar.ps1 ALL PASS.
