# T530 - Dragging a divider must not move OTHER dividers

## User report (2026-08-06, verbatim)

"resizing the 2nd sizer now works perfectly as expected and it does not
affect the 1st sizer. but resizing the 1st sizer moves the 2nd sizer. I
expect moving sizers compensates for the window sizes so that other panels
aren't affected - only the 2 panels being sized are."

(The first half is the user confirming T495 live. The second half is this
task.)

## Why it happens (VERIFIED - this is the data model, not a regression)

The split tree stores RATIOS: 3 columns are `split(r1) -> [pane1,
split(r2) -> [pane2, pane3]]`. Dragging divider 1 changes r1, which resizes
the whole right REGION; the nested split keeps r2 constant, so divider 2
moves proportionally with its region. T495 fixed the drag's coordinate frame
(the divider under the mouse now tracks it exactly); this task is about the
DOWNSTREAM dividers staying put.

## Direction

During a drag of a divider, compensate the ratios of the splits INSIDE the
two child regions so every other divider keeps its absolute pixel position:
for the 3-column case, when r1 changes, recompute r2' so that
`divider2_x = region_start' + r2' * region_width'` stays constant. General
form: on drag tick (or at drag start, capturing absolute positions), walk
the subtree on each side and re-derive each nested split's ratio from its
divider's captured absolute position against its NEW region. Pure math -
belongs in `split_geometry.zig` beside `dragRatio` with tests at
1.0/1.25/1.5/2.0 (deep nesting case included), per the design-system rule.

Check the Mac's behavior first (platform symmetry): if SplitView.swift also
lets nested dividers drift, this is a both-platform change - land win32 +
file the Mac half, per CLAUDE.md.

Clamping note: with compensation, dragging divider 1 far right must clamp
where a downstream pane hits its minimum, not just at [0.1, 0.9] of the
dragged split.

## Validation criteria

- [ ] Pure tests: dragging any divider in a 3+ column tree leaves every

- [ ] `split-divider.ps1` T495 section extended: drag divider 1 by +/-N px
