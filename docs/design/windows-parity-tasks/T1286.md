# T1286 - The capture-content floor has the same size blind spot the uniform guard just lost, so a big window's good capture reads as collapsed

## Summary

Get-TestCaptureContent samples a fixed 48x48 grid, so its step grows with the window exactly as Test-TestCaptureUniform's did before T1282. On a maximized 3858x2118 ghoztty window it steps 80x43 px, misses the 40 px caption band, and scores the capture 3 distinct / 0.90 top share - at or under hero-mode.ps1's collapse floor of 8 distinct / 0.90, i.e. it calls a healthy capture dead. Nothing measures a maximized window today, so this is latent; the next script that does inherits a false red. Give it the same MaxStep density bound, then re-derive the floor numbers the doc comment quotes.
