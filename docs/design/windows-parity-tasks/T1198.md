# T1198 - The watchdog still flashes a console when it re-execs itself or when -Install starts it by hand

## In plain terms

Two smaller versions of the console flash T1192 removed are still there: when
the background supervisor restarts itself after its own source changes, and when
somebody installs it by hand. Both happen with a person already at the keyboard,
so they are far less disruptive than the sign-in one - but they are the same
window appearing and stealing focus.

## Summary

T1192 moved the two AUTOSTART hooks - the `GhozttyGoLoopWatchdog` scheduled task
and the HKCU Run entry - onto the generated windowless launcher
(`wscript.exe //B //Nologo <watchdog>-launch.vbs`). Two `powershell.exe`
launches were left alone, deliberately and named in that task:

- `scripts/go-loop-watchdog.ps1`, the `-Install` path's
  `Start-Process powershell -WindowStyle Hidden ... -File $PSCommandPath`.
- the watchdog's own re-exec when it notices its source changed (the behavior
  `go-loop-guard.ps1` X8-X11 cover).

`-WindowStyle Hidden` does not prevent the flash: powershell reads the flag only
after its console already exists, and with Windows Terminal as the Windows 11
default terminal application that console is drawn as a real window that takes
focus. The launcher is already generated and already sitting next to the script,
so both sites can use it.

The re-exec one needs care: X9-X11 assert a NEW watchdog process is alive after
the re-exec, and `Get-WatchdogProcs` matches on `powershell.exe` command lines.
Going through wscript still ends in such a process, but the timing changes
(wscript returns immediately), so the harness's wait may need to be re-read
rather than assumed.

## Validation criteria

- [ ] Neither remaining site launches powershell.exe with a console; both go
      through the generated launcher.
- [ ] `test\win32\go-loop-guard.ps1` X8-X11 still pass, and the re-exec is
      still observed producing a live watchdog.
- [ ] The change is watched failing: a mutation back to the direct
      `Start-Process` is seen to go red.
