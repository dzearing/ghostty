## Done 2026-08-02

Landed as scoped, with two decisions worth naming and one thing the task's own
wording got wrong.

**"Golden Mac shape untouched" could not be honored literally, because the
golden was already wrong.** The task said to emit `"type":"terminal"` for
terminals *and* leave the golden shape alone; those are contradictory. Reading
the Swift settled it: `TerminalData.encode(to:)` encodes `pane_type` **and**
`url` with `encode`, not `encodeIfPresent` (`IPCMessage.swift:103-104`), so the
Mac has been sending `"type":"terminal","url":null` on every leaf since the
viewer work landed, and `apprt/ipc/list.zig`'s four golden tests had drifted
away from the encoder they claim to pin. Emitting both unconditionally, in
Mac's own field order (between `exit_code` and `banner`, with the win32-only
`background_tint` keeping its place immediately before `banner`), is what
*restores* the match. The goldens were corrected, not relaxed. The absence of
any mechanism behind "keep them in sync with any Mac change" is **T370**.

**The mutual-exclusion check runs BEFORE the interim error**, in both verbs, and
that ordering is asserted. It is not a detail: the conflict check is permanent
and shared with the Mac (`IPCServer.swift:387` / `:574`), while
`viewers are not yet supported on Windows` is deleted by T90d. An ambiguous
command line has to fail the same way on both platforms today and after T90d,
so the interim error must never shadow it. `--split-command` is deliberately
*not* a conflict (it configures the other pane of an inline split, which stays a
terminal) — Mac checks `config.command` only, and `-e` counts because Mac's
parser folds it into `config.command` before the same check.

**The `isAbsolute` fix was hoisted rather than applied twice.** `+new-window`
and `+split` carried byte-identical private copies of `resolveViewArgument`,
and both carried the same live bug — T257's lesson (copies of one datum, no way
to notice they disagree) in a second subsystem. One copy now lives in
`src/cli/view_args.zig`, with the classification split out as a pure
`needsResolution` so the `C:\…`, `C:/…` and `\\server\share` cases the retired
`rest[0] == '/'` test called *relative* are unit-testable without a window.
