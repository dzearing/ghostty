# T1388 - The banner draws markdown headings at weight 700 while the ramp's emphasis is 600

## Summary

T583 put the banner's heading SIZES on the type ramp (h1 = subtitle, h6 = body, even steps between). Its heading WEIGHT is still a bare literal 700 in `BannerOverlay.fontFor`, while `type_ramp.weight_semibold` is 600 and every dialog subtitle uses it. So a banner heading and a dialog title are now the same size and different weights, which is the same class of divergence T583 closed, one field over. Decide whether a markdown heading is an emphasis role (600, ramp) or genuinely bolder than the app's own headings (700, and then say why in the design system), and make it one or the other.
