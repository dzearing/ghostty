# T287 - T226d: Activity Monitor remote sources - card carousel switcher, dial/reuse, chooser Activity button

## Summary

Last of the four-way split of **T226**, and the task that closes **T177**
(the chooser detail row's missing Activity button - it is this panel's entry
point, and a button that opens nothing was never worth landing alone).

Mac's three entry styles
(`macos/Sources/Features/Remote/RemoteActivityMonitor.swift`) all have to
exist, because they differ in who OWNS the connection:

- `presentLocal` - in-process, no connection (landed in T285).
- `presentReusing` - rides a remote window's existing `RemoteConnection` and
  does **not** own it, so closing the panel must not tear that window's
  session down.
- `presentDialing` - dials a fresh connection off the UI thread and owns it.
  This is what the chooser's Activity button calls
  (`MachineChooserView.swift:1488`).

Plus the **in-panel machine switcher** (the card carousel, 160x56 cards,
Local first then every registered machine): once open, the panel moves to any
other source in one click, dialing and freeing owned connections, WITHOUT
opening a second window. The registry governs only the initial open. Keyboard:
left/right move a focus ring, Return/Space commits - so arrowing never dials.

The wire already carries it: `src/remote/protocol.zig` has `HostMetrics` and
the proc list, so a remote source works the moment the UI asks.
