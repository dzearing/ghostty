# T712 - The Windows machine chooser is modal; Mac's New Window picker is modeless

## Summary

win32 MachineChooser.zig disables its owner window (EnableWindow(owner, 0)) while it is up, so the terminal behind it is frozen for as long as the picker is open. Mac made the same picker modeless in 78a21daa8 precisely so a user can keep working while deciding. Relates to T603 (Ctrl+W over the chooser). Found by the T684 sweep.
