# T1282 - The caption-bar check cannot see the title bar on the background test desktop, so it reads as a chrome defect

## In plain terms

The check that proves the window's title bar is drawn correctly cannot take a
picture of it when it runs on the hidden test desktop, so it fails there every
time and looks like the title bar itself is broken. Nothing is wrong with the
title bar; the picture-taking helper reaches for a method that does not work on
that desktop. When this lands, the check either sees the title bar or says
plainly that it could not look.

## Goals

- [ ] `Get-TestWindowPixels` reaches the working capture route for chrome on a background desktop
- [ ] `caption-bar.ps1` is green there, or skips with a named capability
- [ ] the red is re-attributed in writing: harness, not product

## Summary

T1115 measured that chrome IS capturable on a background desktop via PrintWindow; Get-TestWindowPixels reaches for CopyFromScreen there, so caption-bar.ps1's UNIFORM capture is a harness defect wearing a caption regression's clothes. Fix the helper, re-run, and re-attribute the red.
