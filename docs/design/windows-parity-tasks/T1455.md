# T1455 - An acceptance script that wraps a comma-returning helper in @() loops once over the whole array, and nothing says so

## Summary

PowerShell's @() does NOT unroll the single-element wrapper that a `return , $arr` helper hands back: the loop runs once with the whole array as its item, and member enumeration then makes every property an Object[]. Measured 2026-09-08 in T655: one such call site in a manifest walker threw on a cast, the run scored 12 of 131 assertions, and the script still printed ALL PASS and stamped its guard. The shape is mechanical - a static audit can pair every 'return ,' helper with its call sites and flag the @() ones.
