# T593 - Viewer: no test covers leaving a document by an IN-PAGE link (syncCommitted file->web), only by navigate

## In plain terms

A viewer pane stops watching a file — and cancels any re-render it had queued
for it — when you leave that document. There are two ways to leave: type a new
address, or click a link in the page that goes to a website. Only the first is
covered by a test. Both behave correctly today; the second is one careless
refactor away from silently regressing, with nothing to catch it.

## Summary

Found while fixing T400. There are exactly two paths that leave a document:
`ViewerPane.navigate` → `syncWatcher`, and the in-page path
`syncCommitted`'s `viewMode(src) == .web` branch, which T400 rerouted from a
bare `watcher.stop()` to `syncWatcher` so both cancel the pending debounce.

The host-floor test exercises the first (T391's `navigate`-to-web assertions,
plus T400's timer probe) and never the second, because reaching it needs a real
in-page navigation — a link click or a scripted `location =` in a served page —
rather than a `pane.navigate` call. So the shared-function invariant is
asserted on one caller only.

## Details

Suggested shape: serve a page from the existing loopback test server whose body
navigates itself to a second URL (or a markdown fixture with a link the test
clicks), then assert against the pane the same two things T400 asserts on the
`navigate` path:

- `!pane.watcher.isRunning()` once the commit lands, and
- `w32.KillTimer(host, reload_timer_id) == 0` with the timer armed beforehand
  via `SendMessageW(host, WM_APP_VIEWER_RELOAD, …)`.

Note the T400 finding: a fetch-counting oracle cannot see a stale debounce
(mid-load it takes `reloadPlan`'s `full_load` branch, whose re-navigation is
cache-served). The timer probe is the oracle to reuse.

## Validation criteria

- [ ] Host-floor test drives a file → website transition through an IN-PAGE
      navigation (not `pane.navigate`) and reaches `syncCommitted`'s web branch.
- [ ] It asserts the watch is stopped AND no reload timer remains armed.
- [ ] Mutation: reverting that branch to a bare `watcher.stop()` turns the new
      assertion red.
