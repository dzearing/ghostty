# T820 - The sprite-face reference test writes its actual-image PNGs into the source tree and cannot find its reference data outside floor-lane

## In plain terms

Running the test suite the obvious way — `zig build test -Dapp-runtime=win32`
from the repo root — leaves 36 stray PNG files sitting in `src/apprt/win32/`
and reports a failure that has nothing to do with the code under test. It is
noise that makes a real failure harder to see, and it dirties `git status` for
whoever works next.

## Details

Found while running T467's floor. `test.sprite face render all sprites`
(`src/font/sprite/Face.zig`) opens its reference images by the RELATIVE path
`./src/font/sprite/testdata/…`, so it resolves against the test binary's cwd,
not the repo. Run through `scripts\floor-lane.ps1` it passes; run bare it logs

```
[font_sprite] (err): Can't open reference file ./src/font/sprite/testdata/U+2500...U+25FF-18x36+4.png: error.FileNotFound
```

for every page, fails, and writes its actual-image dumps as
`sprite_face_test-U+….png` into whatever the cwd is — which for a bare
`zig build test` is `src/apprt/win32/`. 36 untracked PNGs were left there by
this turn's runs; they are not in `.gitignore` either.

Two halves, both worth fixing: resolve the reference and output paths from a
build-time root (or an env var the build sets) rather than from cwd, so the
lane behaves the same however it is invoked; and make the failure path not
scatter artifacts into the source tree.

Windows-seat framing: this is upstream shared-core code, so a fix here should
be one both platforms want. Check whether the same test misbehaves on the Mac
seat before changing anything, and file the other half if not.

## Validation criteria

- [ ] `zig build test -Dapp-runtime=win32` from the repo root passes the sprite
      test and writes no files into the source tree
- [ ] The same run through `scripts\floor-lane.ps1 -Lane win32` still passes
- [ ] The 36 stray `src/apprt/win32/sprite_face_test-*.png` files are removed
      (user-gated deletion — offer it, do not delete unasked)
