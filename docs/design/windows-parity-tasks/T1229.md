# T1229 - Soak runs leave their sandbox directories in TEMP forever

## In plain terms

The long-running stress tests build a throwaway workspace on disk and then never
delete it. Ten of them are still sitting there, the oldest from mid-July, each a
full copy of a terminal's state directory. Nothing about a test run should still
be on the disk six weeks later.

## Summary

Ten ghoztty-soak sandbox trees dated back to 2026-07-16 are still on disk under %TEMP%\ghoztty-soak. Same class of litter as T1168 - a run's private state outliving the run - but on the filesystem, and no sweep looks for it either. The registry half is now guarded by harness-process-leak.ps1 section R; the file half has nothing. A soak run should remove its own sandbox on the way out, and the standing sweep should be able to name what is left.
