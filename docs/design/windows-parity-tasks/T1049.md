# T1049 - The task-file field table does not document milestone: or unblock:, the two fields the convergence number and the blocked gate run on

## Summary

windows-parity-tasks/README.md is where the frontmatter format is defined, and its field table stops at tags. T345 added priority/order/triage-reason to it after finding two files using an invented priority band nobody could look up. Two fields are still missing: milestone:, which go.md step 0.6 makes the M1 cutline the dashboard's completion number is computed from, and unblock:, which set-status asserts against on every un-block (T892). Both are described in prose elsewhere - milestone only in go.md, unblock only in this README's set-status section - so somebody writing a task file by hand has no single place that lists what a task file may contain. Same failure shape as the P3 one: a field that is not in the table gets invented or omitted, and nothing says so.
