# T1270 - The download page still says Windows is not code-signed 'yet', and nothing can publish a fix to it

## Summary

D87 chose to ship unsigned deliberately, so the download page's 'not code-signed yet' now implies a promise nobody is keeping - it should read as a standing statement. The word is a one-character fix in the in-repo mirror (relay/deploy/ghpages/index.html). The reason it did not land in T1246's turn is structural: nothing publishes that mirror's PROSE to gh-pages. dist/website/publish-windows-links.sh clones the DEPLOYED page and rewrites only the version anchors, and release.yml only touches appcast.xml, so a prose edit to the mirror breaks section F of test/win32/website-windows-download.ps1 (mirror == deployed) until somebody hand-pushes gh-pages. Either give the mirror a publisher, or say plainly in the mirror that it is a read-only copy and prose is edited on the branch.
