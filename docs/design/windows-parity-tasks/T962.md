# T962 - asserted-nothing.ps1 is red at HEAD: job-escape-startup scores a zero-assertion run green, and the uncounted-final ceiling is 2 over

## Summary

The audit that stops a run scoring itself green having measured nothing is itself red, so nothing is enforcing it. Two failures at HEAD: job-escape-startup.ps1:93 prints 'ALL PASS (0 assertions, skipped)' (zero-count), and the uncounted-final count is 41 against a ceiling of 39 - the T775 ratchet went the wrong way and nobody was obliged to notice. Found by T883 running the meta-audits; neither file is in T883's diff.

## In plain terms

We have a check whose whole job is to catch a test that reports "all pass"
without having actually tested anything. That check was itself broken: it was
letting one such test through, and its own count of "tests that don't say how
much they measured" had crept up without anyone noticing. Nobody sees this
directly, but everything downstream of it does - a green run that measured
nothing reads exactly like a green run that measured everything, and that is
how a broken feature ships looking fine.
