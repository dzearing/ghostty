# T754 - Mac: dragging a split divider should hold every other boundary's absolute position, as win32 does since T533

## Summary

Platform symmetry for T533. SplitView.swift is a nested per-node view whose split binding is relative to its own geometry, so dragging the first divider of a 3-column layout slides the second one - the exact behavior the user reported on Windows on 2026-08-06. Port the win32 rule: on drag start snapshot the tree, and on each tick re-solve every OTHER same-axis boundary back onto its pre-drag absolute position (walking through perpendicular splits, pruning unchanged ranges, clamping at the same min/max ratio a dragged divider obeys). The algorithm and its properties are src/apprt/win32/split_resize.zig, which is pure and portable in shape.
