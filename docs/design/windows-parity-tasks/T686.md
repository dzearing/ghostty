# T686 - 12 acceptance scripts read +list layout without --session-persistence=false

## In plain terms

Some automated tests start the terminal and then count its windows, tabs and
panes to decide whether a feature works. If the app restores the layout it had
last time, those counts are whatever an earlier test left behind, and the test
reports a failure that has nothing to do with the code being tested. Fixing
this means a red test can be believed.

## Summary

Audit finding from T157. A test that asserts on `+list` layout must launch with
`--session-persistence=false`, or the agent re-attaches a manifest whose
tab/split shape is exactly what the script is measuring (the batch-2 lesson;
same trap T131 hit with `pane-banner.ps1`, and the one T157 was originally
filed for).

Twelve scripts launch an app, do NOT pass the flag, and still read `.windows` /
`.tabs` / `Count-Leaves`:

```
auto-launch-cwd.ps1        color-contrast.ps1      conformance.ps1
gui-launch-command.ps1     ipc-command-keepalive.ps1  ipc-p1.ps1
ipc-read-race.ps1          ipc-startup-latency.ps1 soak.ps1
tab-tooltip.ps1            upgrade-no-fork.ps1     wheel-scroll.ps1
```

Reproduce the list with:

```powershell
foreach ($f in Get-ChildItem test\win32\*.ps1) {
  $t = Get-Content $f.FullName -Raw
  if ($t -match 'Start-OnTestDesktop|Start-Process' -and
      $t -notmatch 'session-persistence=false' -and
      $t -match '\.windows\b|\.tabs\b|Count-Leaves') { $f.Name }
}
```

## Details

Not a blanket edit. Each script needs a per-script call:

- **Genuinely vulnerable** — indexes a fixed slot or asserts a count
  (`windows.Count -eq 1`, `tabs[0]`): add the flag.
- **Tolerant by construction** — resolves its own named target and never
  counts: leave it, and say so in a comment so the next audit does not re-open
  it.
- **Persistence IS the subject** (none of the twelve, by construction — the
  `agent-*`/`session-*`/`chooser-*`/`*-restore` families were excluded from the
  sweep): never add the flag.

`ipc-p1.ps1` is the one to look at first: it is standing P1 regression floor,
so a layout it inherits from a previous run would land as a floor failure.

## Validation criteria

- [ ] Each of the twelve is classified (flag added / left with a comment
      saying why it is tolerant), with no script left unexamined.
- [ ] Every script that changed still passes on the box, run individually.
- [ ] P1-P3 stay ALL PASS.
- [ ] The reproduce snippet above returns only scripts carrying an explicit
      "tolerant because …" comment.
