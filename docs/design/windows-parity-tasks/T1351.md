# T1351 - Closed pre-T502 tasks carry no category, so the dashboard's tag filter hides 400 of them

## Summary

T503 tagged every OPEN task, and left the closed tail alone on purpose: 400 task files closed before T502 introduced tags carry none, and the Tasks view's tag filter drops an untagged task from every category (task-dashboard.page.html, the f.tag filter). Close by tagging every remaining file and extending section R of test\win32\parity-tasks-seat.ps1 to assert the whole tracker rather than only its open half.
