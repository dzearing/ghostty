# T548 - macOS: 'Share this machine' toggle plus app-managed relay serving

Mac half of T417: same 'Share this machine' toggle in the Mac machine chooser account row, same semantics as the Windows one (enroll via browser OAuth when ~/.config/ghoztty/relay.env is absent, persist sharing state, poke the LocalAgentManager-spawned agent to raise/lower the uplink).
