# T174 - Per-host remote defaults store + Host Settings dialog on Windows (T140 split 3/3)

## Summary

Split out of T140. Mac keeps per-host defaults (default working directory + default shell, keyed by relay device id or host:port) in UserDefaults, edits them from the chooser's row menu ('Host Settings...'), and applies them to new remote windows AND to new tabs/splits on a remote window. Windows has NO such store - Window.zig:849 says so in a comment ('No per-host default shell store on win32 (yet)'), so a remote tab/split always falls back to the machine default. Build the store (JSON under %LOCALAPPDATA%\\ghoztty), the native Host Settings dialog (working directory EDIT + editable shell combo with the cmd/powershell/pwsh/wsl/bash/zsh presets, empty = remote default), wire it into openRelayWindow / +new-remote-window / remote tab+split inheritance, and hang it off the chooser's '...' menu.
