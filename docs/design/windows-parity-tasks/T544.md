# T544 - macOS arm of the T429 foreground-command sample: queryForegroundCommand returns null on macOS, so a Mac plain-shell pane's restart notice still names nothing

## In plain terms

After a reboot, each restored terminal shows a note naming the program that was
running so the user can copy and restart it. On Windows (and Linux) the
background service now tracks that program (T429). On a Mac the tracking arm is
missing, so a Mac terminal where the user had typed a command still comes back
with a note that names nothing.

## Summary

T429 added the whole pipeline: `Session.fg_cmd`, the
`Child.queryForegroundCommand` vtable hook, `refreshForegroundCommands` on the
store's 10s tick, persistence in `sessions.json` (`fg_cmd`), the additive
`Attached.foreground_cmd` wire field, and the app-side preference
(`Remote.zig`: `fg_cmd orelse argv` for the notice). All of that is shared and
already compiled into the Mac build.

What is missing is only the macOS arm of the query in
`src/remote/agent/pty_child.zig` (`queryForegroundCommandFn`): the POSIX branch
already resolves the foreground pid via `tcgetpgrp` and answers `.none` when
the shell itself is foreground, but the cmdline read is Linux-only
(`/proc/<pid>/cmdline` in `src/remote/agent/foreground.zig`). macOS has no
procfs; the standard options are the `KERN_PROCARGS2` sysctl (full argv) or
libproc `proc_pidpath` (image path only — a weaker but simpler label).

Follow the tri-state contract documented on
`session.Child.VTable.queryForegroundCommand`: `.cmd` = record, `.none` =
clear (idle prompt), null = keep last known value.

## Validation criteria

- [ ] A Mac plain-shell agent pane running a user-typed long-lived command gets
      an `fg_cmd` in the agent's `sessions.json` within ~15s.
- [ ] After an agent kill + app relaunch, the session-interrupted notice names
      the typed command (scrollback and banner carriers).
- [ ] A pane idling at a bare prompt records nothing and its notice shows no
      "Previous command" line.
- [ ] `zig build test-agent` green on macOS.
