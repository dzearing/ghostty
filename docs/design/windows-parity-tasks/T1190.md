# T1190 - A startup that fails on the Mac says so too, instead of a bounced dock icon

## Summary

The Windows half of this landed as T1177: `ghoztty.exe` is a GUI-subsystem
binary with no console, so every startup error used to unwind out of `main`
into nothing at all - no window, no dialog, no message. It now raises a dark
error dialog naming the stage, the error and a remedy, and exits nonzero; a
startup that ends with zero windows mints `error.NoStartupWindow` so "nothing
happened" is a reportable failure rather than a silence. A missing session
agent is a separate, non-fatal notice.

This is the Mac seat's half. What has to be established there, and fixed if it
is not already true:

- A failure in `App.create` / the Swift app's launch path puts something on
  screen. An `.app` that fails to launch bounces in the dock and vanishes,
  which is the same silence in a different costume.
- A startup that finishes with no window is treated as a failure rather than
  as a running app with nothing to show.
- The local agent being absent or unspawnable produces a visible notice, not
  only a log line - the counterpart to `LocalAgent.resolveFailure()` and
  `App.showStartupWarningsIfAny` on the win32 side.
- A failed launch exits nonzero, so a launcher can tell.

Windows-side reference: `src/apprt/win32/startup_error.zig`, the
`startupFailed` helper in `src/main_ghostty.zig` (already cross-platform - it
falls back to stderr wherever no apprt declares `reportStartupFailure`, which
is what the Mac seat would replace with an `NSAlert`), and the acceptance
script `test/win32/startup-failure.ps1`.

## Validation criteria

- [ ] A forced startup failure on macOS puts a named alert on screen rather
      than exiting silently, with evidence of how it was forced.
- [ ] The alert names the stage, the error and a remedy (parity with the
      win32 wording in `startup_error.zig`).
- [ ] A failed launch exits nonzero.
- [ ] A missing local agent produces a visible notice while the terminal keeps
      working.
- [ ] Regression coverage on the Mac seat, in whatever form that seat's suite
      takes.
