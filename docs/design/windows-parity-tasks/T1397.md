# T1397 - resize-flicker has no coverage at 200% DPI or across a monitor change

## Summary

T1393 closed the non-modal whole-window resize paths (maximize, restore, snap, title-bar double-click) and proved them with the new 'window resize cause=.. sync=..' oracle - but only at this box's DPI (120) on a single monitor. A DPI change and a monitor move both resize every pane through the same layout pass, and neither is exercised by resize-flicker.ps1. Extend section D to drive a WM_DPICHANGED and a cross-monitor move where the harness can reach them, and say plainly in the script what it cannot.
