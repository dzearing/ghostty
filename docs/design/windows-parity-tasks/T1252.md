# T1252 - Ghoztty ships the fallback graphics driver it needs on a remote desktop

## In plain terms

[[T1251]] teaches Ghoztty to reach for a second graphics driver when the
machine's own is too old. This is the task that puts that second driver in the
box, so that installing Ghoztty on a remote machine is all a user has to do.

## Split from

[[T1250]].

## What to decide and do

- **Pick the implementation.** The two candidates T1250 weighed: Mesa's
  `opengl32.dll` (desktop GL 4.5 - the `d3d12` gallium driver reaches the GPU
  through Direct3D and therefore works over RDP, with `llvmpipe` as the pure-CPU
  floor), which needs no renderer change; or ANGLE, which is smaller and the
  conventional Windows answer but speaks GL ES 3.x, making it a shader and
  pipeline port rather than a drop-in. Record the choice and its reasoning in
  this file.
- Vendor the binary reproducibly: a pinned version, a recorded hash, a
  documented provenance, and a license file shipped beside it.
- Install it into a SUBDIRECTORY of the install, never beside `ghoztty.exe` -
  the loader in T1251 opens it by full path, and an adjacent `opengl32.dll`
  would be a hijack risk for every launch.
- Carry it through every delivery shape: the MSI/installer, the portable zip's
  explicit manifest, and `deliver-windows-build.ps1`'s entry-set diff (which
  FAILS on an unannounced shape change - the change here is announced, so it
  wants `-AcceptZipShape` and a manifest update in the same commit).
- Watch the download size: this is tens of MB on an installer users download.
  Note the before/after numbers here.

## Validation criteria

- [ ] The fallback files land in the install tree and the portable zip, in a
      subdirectory, with the license alongside.
- [ ] `deliver-windows-build.ps1` passes with the new shape rather than being
      excused, and its manifest names the new entries.
- [ ] The vendored binary's version and hash are recorded, and re-running the
      fetch reproduces the same hash.
- [ ] A launch on this box with the T1249 seam forcing the system context below
      the floor now reaches the SHIPPED fallback (no env override) and renders.
- [ ] Installer size before/after recorded here.
