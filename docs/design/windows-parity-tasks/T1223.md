# T1223 - The daily digest has no enforcement

## In plain terms

The loop is supposed to write a short summary of yesterday's work every morning
at 5am. On 2026-09-01 it just didn't, and nothing anywhere noticed. The user
asked for the digest at 05:18 and that is the only reason anyone found out.

## Summary

go.md step 0.5 says to write the day's digest into
`docs/design/windows-parity-digests/<date>.md`. There is no guard, no harness
row, and no health-line field that reports whether today's digest exists - so
skipping it is silent. `guard-due.ps1` has nothing for it (its "digest" matches
are SHA digests, unrelated).

This is the same shape as the failures the tracker keeps re-learning: T1219 was
"the loop pushes every turn and never looks at CI", T1191 was "a module's unit
tests can sit un-run forever because nothing checks the import list". A step
whose omission produces no signal will eventually be omitted.

Note the existing history here: digests exist for 08-21, 08-22, 08-23, then
jump to 08-30. That gap is a **week** of missed digests that nobody caught at
the time, and the standing rule is never to backfill them - which makes
detecting the miss *on the day* the only chance to have one at all.

## What to build

- Surface it where the loop and the supervisor already look: a
  `digest=` field on the `go-loop-health.ps1` line (present / due / missing),
  so a missed digest is visible in the same glance as a dead lock.
- Make the check honest about time: due only after 05:00 local, and only on a
  day the loop was actually alive - a loop that was legitimately stopped
  overnight (the T1179 handoff, for instance) owes nothing.
- Do NOT auto-generate one to satisfy the check. The digest is commentary and
  its value is that a reader wrote it; a generated placeholder would make the
  signal green while destroying the thing it measures.

## Validation criteria

- [ ] `go-loop-health.ps1` reports the digest state for today, and a missing
      one after 05:00 shows without `-Postmortem`.
- [ ] A day the loop spent stopped does not report a missing digest.
- [ ] A test proves the missing case actually goes red (a teeth-check), not
      just that the green path is green.
- [ ] go.md step 0.5 points at the check, so the step and its enforcement are
      not two separate ideas.
- [ ] Backfill stays forbidden: the check reports a miss, and never writes one.
