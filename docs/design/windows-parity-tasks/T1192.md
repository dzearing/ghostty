# T1192 - The go-loop watchdog task and its HKCU Run entry launch powershell.exe on the desktop, so a restart flashes a focus-stealing console

## Summary

Same defect class as the dashboard keep-alive fixed on 2026-08-30, in the loop supervisor. go-loop-boot.ps1 registers GhozttyGoLoopWatchdog with New-ScheduledTaskAction -Execute powershell.exe under an Interactive principal, and go-loop-watchdog.ps1 adds an HKCU Run value of the same shape. -WindowStyle Hidden does not prevent the flash (powershell reads it only after its console exists). It is not the every-5-minutes flasher the user reported, because the watchdog is a long-running process whose 10-minute relaunch is refused (0x800710E0) while it is alive - so it only steals focus when it actually restarts, and at every sign-in via the Run entry. Move both to the argument-free wscript launcher pattern (scripts/dashboard-keepalive.vbs), which needs no elevation. Do it deliberately with the watchdog stopped rather than by hand-editing the supervisor while it supervises: S4U was tried for the dashboard and its failure DELETED the task, which is exactly the accident to avoid on the process that revives the loop.
