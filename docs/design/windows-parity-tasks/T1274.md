# T1274 - The debug marker can flip the chrome band to the other side of the light dark line, reversing every wash above it

## Summary

A debug build tints the chrome band amber. On roughly a quarter of terminal backgrounds - the mid-luminance ones - that tint carries the band across the threshold color_math.wash reads to decide which way to travel, so the marked band washes toward black where the release band washes toward white. Every surface above it (inactive tab, hover, icon-button fill) then separates in the opposite direction from what ships. T364 measured it while restoring the marked band's wash headroom, and deliberately left it alone: its restore steps aside on exactly these backgrounds rather than push a band further onto the wrong side. Debug-only, and the band still marks itself and still holds every contrast floor.
