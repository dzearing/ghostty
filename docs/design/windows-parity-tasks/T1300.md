# T1300 - Apps and Features offers no Repair for Ghoztty

## In plain terms

Ghoztty can now repair itself - if you still have the installer file and run it
again, it offers to. But the place people actually go when an app is misbehaving
is Settings > Apps, and there Ghoztty shows only "Uninstall". The repair exists
and is hidden behind having kept a download.

## Where it comes from

The package sets `ARPNOMODIFY=1`, which tells Windows to hide the Modify (and,
depending on the surface, Repair) entry in Apps & Features. That was the right
call when there was nothing to modify and no repair worth offering: a Modify
button that opens a wizard the product does not have is worse than no button.

T1291 changed the premise. The package now arms `REINSTALL=ALL` with
`REINSTALLMODE=amus` and asks Repair / Cancel, so there IS a repair, and it is
the one thing a user in trouble would want from that page.

## What to think about before changing it

- `ARPNOMODIFY` and `ARPNOREPAIR` are separate switches. The wanted end state
  is almost certainly "no Modify, yes Repair" - there are no optional features
  to change - which means dropping `ARPNOMODIFY` is the wrong move on its own.
- Whatever Windows launches from that page runs the CACHED package, not the
  file the user downloaded, and it runs it in the maintenance path T1291
  authored. Check what UILevel it uses: if it is below 4, the Repair / Cancel
  dialog is correctly suppressed and the repair should just happen - which is
  the right behaviour for a button already labelled Repair, but it wants
  confirming rather than assuming.
- Mac has no analog to check against; this is a Windows-convention call.

## Validation criteria

- [ ] Ghoztty's entry in Settings > Apps offers Repair, and choosing it
      reinstalls this version's files without asking a second time.
- [ ] It still does NOT offer Modify - there is nothing to modify.
- [ ] The package's read-back in `build-msi.sh` asserts whichever ARP
      properties are the intended pair, so the setting cannot drift back.
- [ ] `test\win32\install-maintenance.ps1` covers the new arrangement.
