# T711 - The Windows machine chooser has no warm/seeded device list: it opens empty and blocks on the network

## Summary

Mac persists the device list and seeds the chooser instantly (66012e2ee), warms it with a quiet refresh at launch (b0028112a), presents cache-seeded rows as 'checking' (55dd70978), and polls the directory live while the chooser is open (27e639ae6). The win32 chooser fetches on open with nothing cached, so Ctrl+Shift+N shows an empty list until the relay answers and never updates while it is open. Found by the T684 sweep.
