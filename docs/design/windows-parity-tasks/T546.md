# T546 - Agent serves the local transport and the relay uplink from one process over one session store

## Summary

Core of the T417 one-installer plan: the session-persistence agent grows an optional relay uplink in the SAME process, so the one persisted SessionStore (sessions.json, layouts.json, rings) is reachable over the local pipe/unix socket AND, when sharing is enabled, over the relay. Uplink state comes from persisted sharing config in the agent state dir (hot enable/disable via the existing relay.env watcher pattern); the single-instance guard stays the local one; self-update and the tray stay OUT of this mode (the app owns the binary, the GUI owns the UI). See docs/design/one-installer-agent-consolidation.md.
