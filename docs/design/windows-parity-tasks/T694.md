# T694 - Acceptance scripts still bind fixed TCP ports, and several collide with each other

## Summary

T171 removed the fixed 47921/47922/47912 ports from `relay-account.ps1` (a
port the OS just handed out, asserted free before it is bound, and a readiness
check that only the run's own nonce satisfies). Eleven other acceptance scripts
still guess a number, and some guess the SAME number as each other:

| Port | Scripts |
|---|---|
| 47931 | `chooser-menu.ps1`, `ipc-machine-chooser.ps1` |
| 47941 / 47942 | `host-settings.ps1`, `chooser-sessions-remote.ps1` |
| 47911 | `ipc-relay.ps1`, `remote-inherit.ps1` |

Plus singletons: `chooser-restore-all-remote.ps1` (47951/47952),
`close-confirm-idle.ps1` (47741), `ipc-remote.ps1` (47901),
`remote-pill.ps1` (47913).

Two failure shapes, both of which read as a product bug rather than a harness
one. A back-to-back run of the same script can meet its own previous listener
still dying in the port (a TCP connect then "succeeds" against a socket that
will never answer). Two DIFFERENT scripts sharing a number cannot run near each
other at all, which is a standing constraint nobody has written down.

## In plain terms

Several tests reserve a network port by picking a number and hoping it is free.
Sometimes it is not -- the previous test is still letting go of it, or another
test in the suite wants the very same one -- and the test then fails in a way
that looks like the terminal is broken. This makes each test take a port the
system just handed it, so tests stop colliding with each other and with
themselves.

## Details

The pattern to copy is in `test/win32/relay-account.ps1` (T171):

- `Get-FreePort` (bind :0, read the port, release it) and a `0` default on the
  parameter so a caller can still pin one.
- `Test-PortFree` asserted immediately before each bind.
- A readiness probe the run's OWN server answers with a per-run nonce, instead
  of a bare `TcpClient.Connect`.

`test/win32/lib/FakeRelay.ps1` and `lib/PipeBridge.ps1` take the port from
their caller, so fixing the callers covers them.

## Validation criteria

- [ ] No `test/win32/*.ps1` carries a fixed non-zero default TCP port (grep is
      the check).
- [ ] Every converted script prints the ports it drew and asserts each free
      before binding.
- [ ] Each converted script passes on its own, and the pairs that used to share
      a number pass when run back to back.
