# T959 - src/os/env.zig has no upstream home after Zig 0.16, and 13 of our files call into it

## Summary

Upstream DELETED src/os/env.zig in the Zig 0.16.0 commit (e8525c0fd) - the inventory records it as M-vs-D, our modify against their delete, which git presents as a conflict rather than resolving. We extended that file by 41 lines, and 13 files across the tree call its helpers via internal_os.getenv / setenv / unsetenv / getEnvMap / appendEnv / prependEnv - including src/apprt/win32/App.zig and src/apprt/win32/Surface.zig, plus src/global.zig, src/Surface.zig, src/termio/Exec.zig, src/termio/shell_integration.zig, src/cli/Pager.zig, src/cli/edit_config.zig, src/os/locale.zig, src/os/resourcesdir.zig, src/apprt/embedded.zig and the two gtk callers. Decide whether the file survives as ours or its callers move to whatever 0.16 std offers, and do it as part of the S4 stage rather than discovering it mid-merge.
