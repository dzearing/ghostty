# T165 - Banner links have no hover affordance and no action menu on Windows

## In plain terms

A link in a pane banner is clickable, but it does not look like one and it
does not tell you what a click will do — no underline that reacts to the
pointer, and no right-click menu. So you either click and hope, or you never
find out that the link can also open beside the pane instead of jumping out to
the browser.

After this, a link is underlined with a dotted rule that fills in solid the
moment you point at it, and a right-click offers everything a click could have
done — open in the browser, open in a side pane, open in a new window, copy —
with the plain-click action at the top of the list. Holding Ctrl while you
click opens it in a side pane; Ctrl+Shift gives it a window of its own. It is
the same set the Mac has had since July.

## Goals

- [x] A banner link carries a dotted underline at rest and a solid one while
      hovered, per link, at every DPI scale
- [x] Right-clicking a link opens an action menu whose first row is the
      left-click default
- [x] Ctrl / Ctrl+Shift click reach the side-pane and new-window actions
- [x] File links get the Windows verbs (Reveal in File Explorer, Copy Path)
      rather than the Mac ones
- [x] Unit tests in the none lane; an on-box acceptance section in
      `pane-banner.ps1`

## Details

Windows already renders clickable banner links (`[text](url)` in
`banner_markdown.zig` + `BannerOverlay.zig`), so this is an affordance gap on
top of a shipped feature, not a new subsystem:

- hover affordance on a banner link (the Mac commit's first half)
- an action menu for the link (the second half) -- on Windows the natural
  surface is the existing win32 context menu (`context_menu.zig`), which T129
  already taught to label rows `Title\tChord` from the live keybind set.

Read the merged Mac implementation before designing: the two halves may share
one hit-test path, and the win32 overlay already has a hit-test for link
activation to extend rather than duplicate.

Related: the same 12-commit band adds CLIENT-scoped "What's New" (pre-update
dialog + tabbed menu window, `68d9299a9`), which belongs to the existing T125
rather than a new row -- noted there.

*Validation:* `pane-banner.ps1` grown -- hovering a banner link changes its
rendering (pixel probe, per the T131/T155 pattern, and launch with
`--session-persistence=false`), and the action menu opens with the expected
rows. Both lanes + P1-P3 green.
