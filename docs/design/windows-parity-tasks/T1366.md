# T1366 - The Mac machine chooser lists sessions whose program already exited

## In plain terms

The list of sessions you pick from when opening a window should be the work
that is still running and has no window on it — nothing else. On Windows a
finished session is no longer offered (T1364). On the Mac the same list still
keeps them, so it grows with things that are over and the useful rows get
buried.

## Summary

The user answered D91 on 2026-09-05:

> the list represents the processes still alive. If we don't have a ghoztty
> window for something still running in the agent, we should list it,
> otherwise if it's a dead process and not working we don't.

T1364 landed that on Windows: `chooser_sessions.isConnectable` is now
`alive`-only, `RowAction.relaunch` and the `can relaunch` badge are gone, and
`resumeTarget` refuses a tombstone again. Mac's predicate is still the T466
reading —

```swift
// SessionBrowserProbe.swift:56
var isConnectable: Bool { alive || relaunchable }
```

— and `MachineChooserView.swift:1122` filters the rows on it. The divergence is
partly masked today because the C API omits `relaunchable` (T322), which
collapses the expression to `alive` at runtime: fixing T322 without fixing this
would silently re-introduce the behavior D91 rejected, on the seat that has no
acceptance script for it.

Scope: make the Mac predicate say what the rule is, drop the dead-row backstop
copy that only exists to explain the refusal, and check the surrounding
comments (they describe a tombstone as "worth showing").

## Goals

- [ ] Mac's `isConnectable` is `alive` only, so a tombstone is not a row
- [ ] `MachineChooserView`'s row filter and its comments agree with it
- [ ] Nothing about launch-time restore changes: it still revives a tombstone
      leaf from a saved layout

## Validation criteria

- [ ] A session whose program has exited does not appear in the Mac chooser's
      session list (checked with a real local agent holding tombstones).
- [ ] A session still running with no window on it does appear.
- [ ] Launch-time restore still revives a tombstone leaf from a saved layout.
- [ ] The Mac build is green.
