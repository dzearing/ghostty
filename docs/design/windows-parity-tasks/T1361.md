# T1361 - The agent's --headless flag no longer selects anything on the listen paths

## Summary

T550 removed the Windows system tray, which is the only thing --headless ever suppressed in --listen/--listen-unix/--listen-pipe mode. The flag is still parsed, still carried through the three Listen structs, and now discarded with a _ = headless in each. It is NOT inert everywhere: in --relay mode it still forbids the interactive browser self-enroll (decideRelayCred), so it cannot simply be deleted from the CLI. Decide whether the listen paths should drop the field entirely (and what a --headless on a listen command line should then do - accepted silently, or refused) or whether keeping it for symmetry is right. Purely cosmetic; nothing behaves wrongly today.
