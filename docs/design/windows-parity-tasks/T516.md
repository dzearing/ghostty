# T516 - Mechanical divergence inventory against upstream ghostty for merge-back planning

## Summary

Merging this fork back into main (and eventually tracking upstream ghostty)
is currently an unknown: nothing enumerates what this fork touches that
upstream also moved. Before a merge can be planned, we need a mechanical
inventory — files changed here since the fork point vs files changed
upstream in the same span — so the overlap (the real merge risk) is a list,
not a guess. Named as a merge-back gap in the 2026-08-05 and 2026-08-06
digests.

## In plain terms

We forked from the original Ghostty project and both sides have kept
changing. Before our work can ever be merged back or updated from upstream,
someone has to know exactly which files both sides touched — that overlap is
where merges go wrong. This task builds that list automatically instead of
discovering conflicts one at a time during a merge.

## Goals

- [x] A script that finds the fork point and computes the three lists
      (changed-only-here, changed-only-upstream, changed-both) mechanically
- [x] A committed report the dashboard and digests can cite
- [x] Counts verified against plain `git log` so the report can be trusted
- [x] An acceptance test so the computation cannot drift silently

## Where

- A script (e.g. `scripts/divergence-inventory.ps1` or cross-platform) that:
  fetches upstream ghostty, finds the fork point (`git merge-base`), and
  emits three lists: changed-only-here, changed-only-upstream,
  changed-both (the risk set), with per-file commit counts.
- Output as a committed report under `docs/design/` so the dashboard/digests
  can cite it.

## Validation criteria

- [x] Running the script produces the three lists and identifies the fork point.
      (Live run: fork point `063ac3ecc` 2026-05-07; ours 1780 commits / 2104
      files, upstream 1116 / 747, risk set 131. Also proven end-to-end by
      `test\win32\divergence-inventory.ps1`, 15 assertions ALL PASS, whose
      synthetic repo has an exactly-known three-way split.)
- [x] The changed-both list is spot-checked against `git log` for at least 3 files.
      (`build.zig` 15/3, `CLAUDE.md` 137/1, `include/ghostty.h` 42/11 — all
      exact matches of `git log --full-history --no-merges -- <path>` over the
      same range, which is the count definition the report documents.)
- [x] Report committed and referenced from the tracker narrative doc.
      (`docs/design/windows-parity-divergence.md`; cited in
      `windows-parity-tasks.md` "Related docs".)
