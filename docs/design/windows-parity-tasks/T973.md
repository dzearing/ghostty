# T973 - A half-written build cache reads as a code failure when the compiler blames a source file

## Summary

After the 2026-08-18 reboot the win32 and agent lanes failed with 'root source file struct options has no member named app_version' pointing at src/build/Config.zig - intact source. The torn artifact was a ZIR entry under .zig-cache/z, named only in the compiler's 'note: struct declared here' line, so Get-TornCacheEntry (which matches the FILE LOCATION of an 'error:' line) could not name it and floor-lane reported a code failure. The corroborating 'Invalid timestamp in cache entry' warning was present in the same log. Teach the heal to read the note: line (and the /z ZIR store) so a torn cache heals itself instead of costing a turn a diagnosis.
