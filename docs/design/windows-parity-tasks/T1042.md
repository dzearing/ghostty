watches changed?" - and right now it is answering "no" for 32 of them, so every
commit has to switch it off to get past. Nobody is doing anything wrong; a single
mechanical edit touched all those test files at once and none has been re-run
since. Until they are, the alarm is permanently muted, which is the one state it
was built to prevent.
