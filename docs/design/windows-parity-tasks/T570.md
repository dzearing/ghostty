# T570 - The Activity Monitor acceptance suite has no spawn-a-victim fixture for the REMOTE panel's Kill button

## Summary

Port it, so Kill's own conditional-Tab-stop and key path can be asserted against a process the test created. Only becomes required work if D29 is answered with its second option.
