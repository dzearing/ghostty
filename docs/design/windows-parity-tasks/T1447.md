# T1447 - Does the Mac app go deaf on startup against a wedged agent, the way Windows did before T630?

## Summary

T630 closed this on Windows: `LocalAgent.dialExisting` spent its whole 1200 ms
HELLO-handshake budget in one blocking wait, so an app starting up against a
WEDGED agent (suspended across a relaunch, still holding the endpoint) answered
no IPC for the duration. The fix was `tcp_dial.WaitTick` - a shapeless
`{ctx, func, interval_ns}` the shared dial runs while it waits, slicing the same
budget - filled on win32 by a message pump.

The Mac side is a SEPARATE implementation and does not go through `tcp_dial`:
`macos/Sources/Features/Remote/LocalAgentManager.swift` has its own
`dialExisting` (line ~978), called from the startup path at ~141. Nobody has
measured whether that dial blocks the run loop the same way, so this is a
question before it is a defect.

The measurement is the deliverable. Stand up the Mac equivalent of
`test\win32\ipc-startup-latency.ps1` arm C - suspend the agent (SIGSTOP), relaunch
the app, and poll `ghoztty +list` from the moment the process starts - and
compare the first answer against a healthy restore. If the two are within noise
of each other, close this with the measurement as the evidence and no code
change. If Mac shows the same second of silence, the shape of the fix is
already decided by T630: slice the wait, do not shorten it.

## In plain terms

On Windows, if the background process that keeps your sessions alive got stuck,
Ghoztty used to ignore commands for about a second while starting up. That is
fixed there. Nobody has checked whether the Mac build does the same thing.

## Validation criteria

- [ ] The Mac startup-latency measurement exists and is repeatable: first `+list`
      answer against a SUSPENDED agent, beside the same figure for a healthy
      restore
- [ ] A verdict is recorded either way - "within noise, no defect" with the two
      numbers, or the gap with the numbers that show it
- [ ] If a fix is needed, it slices the handshake wait rather than shortening it
      (the T630 shape), and the measurement's ceiling is tightened so a
      regression fails it
