# T604 - src/cli/send_keys.zig has diverged from main: main rewrote prompt submission while this branch built bracketed-paste framing

## User directive (2026-08-09, verbatim)

"In the latest mac builds we updated the enter logic recently. Make sure we
have 100% parity with the changes, that should be a priority."

100% parity means: read main's `a7f7476e1` as the spec for submission
semantics, and this branch's implementation must give every guarantee it
gives - not a merge of convenience, an equivalence. The reconciliation
below stands, with main's design as the reference point where the two
sides disagree.

## In plain terms

Both seats independently fixed the same problem - an agent's prompt arriving in
a pane but never actually submitting - and both rewrote the same file to do it.
Whichever way that gets merged, one of the two fixes could be lost silently, and
the symptom (a prompt sitting unsent in a composer) is the exact failure that
kills the automation loop. This reconciles them into one implementation before
the merge, rather than during it.
