# T803 - Carry T739's resume-offset fix onto the Mac seat and measure it there

## Summary

T739 fixed the re-attach resume offset in SHARED core (protocol.data_repaint 0x15 + capability.repaint_data, connection.Pane.stream_pos/streamPosAfter, client_mux/agent mux lane fold, termio/Remote adoption), so macOS gets the code for free - but nothing has measured it there. The Mac seat needs the equivalent of test/win32/session-resume-offset.ps1: three kill/restore cycles of a quiet pane whose recorded offset equals the agent head, with GHOZTTY_RESUME_COUNT_BYTES=1 as the teeth and GHOSTTY_AGENT_SUPPRESS_CAPS=repaint_data as the skew arm. Note the win32 measurement showed the client-side half self-corrects on Windows because ConPTY repaints after every attach; a POSIX pty may not, which makes the labeled framing load-bearing there rather than belt-and-braces.
