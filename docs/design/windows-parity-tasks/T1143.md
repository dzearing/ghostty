# T1143 - An acceptance marker the shell echoes can score before the command has run

## Summary

T1116's harness typed a unique end marker into a command line and then waited for it to appear in the pane. The shell ECHOES the command line, so the marker was on screen the instant the keys landed - the assertion scored a flood that had not started (and in one run was still printing a minute later). Sweep test/win32 for Wait-PaneHas-style waits whose needle is typed verbatim in the same command, and split the marker across a concatenation the way holder-volume.ps1 now does, so matching it proves the command RAN.
