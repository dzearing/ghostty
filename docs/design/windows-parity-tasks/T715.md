# T715 - Windows exposes no assistive-tech attribute for a remote window's link state (Mac's AXGhosttyLinkState)

## Summary

Mac publishes AXGhosttyLinkState on terminal windows (97530c9ac) so external tools can read whether a remote window is connected/reconnecting/disconnected without parsing the title, the same contract AXWindowActivityState has for activity. win32 tracks the state (connection.LinkState, the T367 pill) but publishes nothing to UI Automation. Found by the T684 sweep.
