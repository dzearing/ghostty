# T716 - The widened parity sweep reveals 81 shared-core commits since June that no Windows work item cites

## In plain terms

We keep a list of every change the Mac side makes, so nothing a Mac user got
silently never arrives on Windows. Until now that list only watched the Mac
app's own folder, so changes to the shared machinery underneath both apps were
never checked. With the watch widened, 81 changes made since June turn out to
have no Windows work item naming them. Most of them are almost certainly
already covered - they built the shared agent that Windows runs today - but
"almost certainly" is exactly what this list exists to replace.

## Summary

T685 widened `scripts\parity-sweep.ps1` from `macos/` + `src/viewer/` to
`macos/` + `src/` (minus `src/apprt/win32/` and `src/apprt/gtk/`). The daily
intake range is clean, so the gate is usable from today forward - but sweeping
back to 2026-06-01 (`680a07ed3..origin/main`) now reports **81 unmapped of 349**
(39 in June, 40 in July, 2 in August). Reconciling them is deliberately NOT part
of T685: the tool change and the historical audit are different jobs, and mixing
them would have made neither reviewable.

The set is dominated by `src/remote/` (173 file touches across the 81) - the
WP1-WP4 remote/agent build-out, whose Windows half is what `ghoztty-agent.exe`
already is. So most of these are expected to resolve as **no-parity-owed**
citations rather than new tasks. The ones to look at hardest are the shared
non-agent commits: `src/termio/` (19), `src/apprt/` (14), `src/Surface.zig` (8),
`src/cli/` (6), `src/config/` (3) - that is the class that produced T604.

Method: work the list from the sweep's `-Format markdown` output; for each
commit either file a Windows task or write a one-line no-parity-owed reason
into a citation section (any `docs/design/windows-parity*` file makes it mapped,
since the reference index is keyed on the sha). Note that this supersedes
T684's "every Mac change merged since June is accounted for" claim under the
wider definition - say so where that claim lives.

## Goals
