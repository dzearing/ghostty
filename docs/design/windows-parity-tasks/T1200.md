# T1200 - The relay still hands out the retired standalone agent installer

## Summary

T1175 retired the standalone Windows agent installer and T1186 removed it from the download page, but the relay VM has never been republished, so its own copies are still live: https://<relay>/dl/install.ps1 is the old MSI-downloading installer, /dl/ghoztty-agent.msi still answers 200, and the versioned Ghoztty-Agent-*.msi files plus the stable-URL alias still sit in /var/www/ghoztty-dl/. The publish script no longer writes or prunes them, so nothing removes them unless someone does. Nothing links to these URLs any more, but a bookmark, a cached page or an old note still walks a new user into installing half a product. Needs relay/deploy/publish-agent.sh, which needs ssh to the VM as a sudo-capable user - this Windows box has no key material for it (no ~/.ssh key, no ssh-agent, no az CLI), so it is the Mac seat's to run.

## In plain terms

There is a second, older way to install Ghoztty's remote agent still sitting on
our server. The download page no longer points at it, but the URL still works,
so anyone with an old link or a bookmark can still install the wrong thing.
Running one publish script on the server retires it for good.

## Goals

- [ ] The hosted one-liner installs nothing; it points at the product site.
- [ ] The standalone agent MSI is gone from the server.
- [ ] The `--relay` agent's self-updater keeps working (T550 retires it, not this).

## How

From the Mac seat, with ssh to the relay VM:

```bash
relay/deploy/publish-agent.sh --dry-run     # read what it will replace
relay/deploy/publish-agent.sh
```

Then remove by hand what the script no longer prunes (it stopped writing these
in T1175, so it also stopped cleaning them up):

```bash
ssh azureuser@ghoztty-relay-dz17575.westus2.cloudapp.azure.com     'sudo rm -f /var/www/ghoztty-dl/Ghoztty-Agent-*.msi /var/www/ghoztty-dl/ghoztty-agent.msi'
```

Leave `/dl/ghoztty-agent.exe` and `/dl/version.json` alone. The standalone
`--relay` agent's self-updater reads both (`src/remote/agent/self_update.zig`);
they retire with it in T550, not here.

## Validation criteria

- [ ] `curl -fsS https://<relay>/dl/install.ps1` returns the signpost, not an installer.
- [ ] `curl -fsSI https://<relay>/dl/ghoztty-agent.msi` no longer answers 200, and no
      `Ghoztty-Agent-*.msi` remains in `/dl/`.
- [ ] `curl -fsS https://<relay>/dl/version.json` still answers, and
      `curl -fsSI https://<relay>/dl/ghoztty-agent.exe` is still 200.
- [ ] `curl -fsS https://<relay>/` shows the Remote Agent section pointing at the
      single Windows installer, matching `relay/deploy/www/index.html`.
