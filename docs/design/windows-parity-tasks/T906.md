# T906 - A starting agent re-adopts live holder sessions with scrollback gap-filled

## Summary

Increment 3 of the T705 split (design:
`docs/design/agent-nondestructive-handoff.md`). On startup the agent reads
`sessions.json`, finds holder-backed sessions whose holder still answers its
pipe, and RE-ADOPTS them: reconnects as owner, gap-fills the output ring from
the holder's offset-acked replay buffer, and serves the session as if it never
left. A holder that does not answer follows the existing dead-session
tombstone path.

This makes the upgrade path and the crash path the same path: the app-side
in-place recovery (T145/T723) already re-dials a replacement agent and
re-attaches panes — with adoption, those panes land on LIVING shells instead
of tombstones.

Skew rule: adoption honors the holder's versioned HELLO. A holder speaking a
newer protocol than this agent degrades additively (unknown fields ignored); a
holder this agent cannot serve at all is left running and reported, never
killed or garbled.

## In plain terms

The previous task lets a session's shell outlive the background manager; this
one teaches a freshly started manager to find those surviving shells and plug
them back in, with no gap in the output history. After this, the manager
crashing or being replaced costs you nothing — your panes reconnect to the
same running programs.

## Goals

- [ ] Startup discovery + adoption of live holders; dead holders take the
      existing tombstone path.
- [ ] Ring reconciliation via the holder's replay buffer — no lost or
      duplicated bytes across the restart.
- [ ] Pure adoption/reconciliation rules unit-tested in `test-agent`.
- [ ] Acceptance proves continuity end to end through an agent kill.

## Validation criteria

- [ ] Acceptance: open a pane, type a marker, kill the agent, let recovery
      re-dial (or start a new agent), `Test-PaneLive` types into the SAME pane
      and the shell answers — same shell pid, marker still in scrollback.
- [ ] A holder killed while the agent is down produces the normal
      relaunch/tombstone notice, not a wedge or a silent blank pane.
- [ ] `zig build test-agent` + both zig lanes green;
      `test/win32/agent-recovery.ps1` and `test/win32/session-persistence.ps1`
      stay ALL PASS.
