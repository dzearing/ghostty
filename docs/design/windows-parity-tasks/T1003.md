# T1003 - After a late restore the empty terminal the launch opened is still sitting there

## Summary

When the launch restores nothing it opens one blank terminal; T976's deferred pass then rebuilds the real windows around it, so the user ends up with an extra empty window they did not ask for. T976 deliberately left it alone - closing a pane the user may already have typed into is worse than an extra window - but the polished behaviour is to close it when it is still PRISTINE (one pane, nothing typed, no child output, no viewer) at the moment the deferred restore succeeds. Needs a pristine test that cannot be fooled by a shell prompt banner, and an acceptance arm that types into the blank window first and proves it is kept.
