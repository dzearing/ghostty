# T549 - Windows: adopt and retire an existing standalone agent install

## Summary

Migration half of T417: on a box that has the standalone 'Ghoztty Agent' MSI (install dir %LOCALAPPDATA%\Programs\Ghoztty Agent, ARP entry, HKCU Run key GhozttyAgent carrying --relay), the app adopts it: preserve relay.env, mark sharing enabled (the box was already serving), wait for the standalone relay agent to have zero live sessions (its store is in-memory - stopping it mid-session kills real shells), stop it, uninstall the product, and let the app-owned Run key be the only GhozttyAgent value. Also resolves the standing Run-key collision where the app and the MSI overwrite each other's value. CAUTION on this dev box: never msiexec /x the registered 26.7.502 ghost product (see memory); match the real product by UpgradeCode 7143BA66-FD7B-4D45-8555-E946D2141912. See docs/design/one-installer-agent-consolidation.md.

## In plain terms

Some PCs still have the old separate "Ghoztty Agent" program installed from
before the terminal learned to do machine sharing itself. Leaving both around
causes real trouble: two programs fight over the same sign-in and the same
"start at login" setting, and uninstalling the old one carelessly would cut
off anyone remotely connected to this PC — and, worse, its uninstaller
force-kills every agent it can see, which would also kill the terminals the
user has open locally. After this lands, the terminal quietly notices the old
program, keeps machine sharing on, waits until nobody is connected through
the old agent, removes it safely, and repairs the login setting it takes with
it. The user notices nothing except that everything keeps working.

## Goals

- [x] The consolidated agent detects a standalone 'Ghoztty Agent' MSI install and adopts it automatically
- [x] Sharing stays on across the handover (sharing.json marked enabled once; a user opt-out is respected)
- [x] The standalone agent is stopped only when it has zero live sessions (descendant-based idle gate)
- [x] The MSI product is uninstalled by UpgradeCode, never by name (the 26.7.502 ghost is untouchable)
- [x] The adopting agent survives the MSI's kill-every-agent custom action (deny-terminate shield)
- [x] The contested HKCU Run 'GhozttyAgent' value the uninstall deletes is restored/repointed
- [x] Debug/test agents can never act on the real install (both env overrides required in debug)
