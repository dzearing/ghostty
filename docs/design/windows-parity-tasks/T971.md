# T971 - mac: the POSIX holder must release output on DURABILITY, not on delivery

## In plain terms

The Mac's version of the per-session holder process has not been built yet
(T908). When it is, it has to carry the rule Windows just learned: the session
manager may only tell a holder to let go of output once that output is saved to
disk — not the moment it arrives. Without it, a manager crash on a Mac loses
whatever was printed since the last save, exactly as it did on Windows.

## Summary

T911 made an ACK to a holder mean DURABLE rather than DELIVERED on Windows. The
mechanism is platform-neutral and already lives in shared code:

- `session.Child.VTable.releaseTo(offset)` — the contract, in `session.zig`.
- `SessionStore.snapshotRings` calls it after a successful ring-snapshot write,
  outside the store lock, and only when `rings_dir` and `durable_ack` are set.
- The store arms the gate at OPEN, RELAUNCH and startup adoption.

So the POSIX holder's owner-side child only has to implement `releaseTo` the way
`pty_holder_child.HolderChild` does: hold `durable` + `durable_gate`, and ACK
`pty_holder_child.ackTarget(gate, received, durable)`. Everything above it is
already written and already tested.

The acceptance shape is portable too: `test\win32\holder-durable.ps1` measures
the ring snapshot FILE rather than the pane, which is the part that makes the
bug visible at all, and its negative control is `GHOZTTY_AGENT_DURABLE_ACK=0`.

## Goals

- [ ] The POSIX holder's child implements `releaseTo` with the same arithmetic.
- [ ] A manager crash on macOS loses nothing a fresh viewer would have seen.

## Validation criteria

- [ ] Unit: the POSIX child's ack target matches `ackTarget`, including
      `durable == 0` releasing nothing.
- [ ] Acceptance: the macOS equivalent of `holder-durable.ps1` — marker printed,
      confirmed absent from the on-disk snapshot, manager hard-killed, marker
      present after adoption. Negative control with the gate off loses it.
- [ ] Both zig test lanes + `zig build test-agent` green on the Mac seat.
