# T584 - The tab strip and window title draw at 16px, a size the type ramp does not have

## Summary

`Window.zig:686` sizes the tab strip and window title with a bare literal:

```zig
const font_height: i32 = -@as(i32, @intFromFloat(16.0 * self.scale));
```

16 is not on the type ramp. After T313 every dialog reads at 14, and the tab
titles — the text a user looks at more than any other chrome in the app — read
at 16. Unlike the dialogs before T313, this is not seven copies of one number;
it is one copy of a number that is not in the system at all.

## In plain terms

Ghoztty's tab titles are set slightly larger than every other piece of text in
its own interface. It is not obviously wrong on its own, which is why it has
survived — but it is a size nobody chose, and the app now has a rule about
sizes that this one number sits outside.

## Details

- This one needs a DECISION before a patch, and it is not the same decision as
  the dialogs. Two things make it different:
  1. **The face is user-configurable** (`window-title-font-family` feeds
     `title_font.faceName`), so this text is already partly the user's, not
     purely ours. Whether the SIZE should follow the ramp when the FACE does
     not is a real question.
  2. **A tab title is the app's primary chrome**, not dialog body text. Fluent
     ships tab labels at the body size, which argues for 14 — but check a
     current Win11 app (Terminal, Edge, File Explorer) and measure rather than
     asserting it from memory.
- If the answer is "the ramp", the change is small and the acceptance surface
  is `tab_strip_layout.zig`, which already asserts its geometry at
  1.0/1.25/1.5/2.0 — the tab height and the title's measured extent both move,
  so re-assert them rather than letting them drift.
- If the answer is "chrome has its own size", say so in
  `win32-design-system.md` §2.4 with the reason, and name the constant instead
  of leaving a literal in `Window.zig`. An off-ramp number that is WRITTEN DOWN
  as off-ramp is fine; an undocumented one is the defect.
