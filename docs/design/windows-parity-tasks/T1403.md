# T1403 - Clear-screen and click-to-move trust ConPTY's prompt marks, which lie mid-command

## Summary

P2: the same ConPTY OSC 133 unreliability T1398 fixed for the close confirmation, in two smaller behaviors. ConPTY brackets a cmd.exe prompt with 133;B and never emits 133;C, so cursorIsAtPrompt() reads TRUE all through a running command. Two other consumers key on it: Termio.clearScreen (src/termio/Termio.zig ~743) sends a form-feed to the shell as if it were at a prompt, and Surface.processMousePressPrompt (src/Surface.zig ~5165) enables cursor-click-to-move mid-command. Neither is destructive, but both are visibly wrong on Windows. Found while root-causing T1398.
