# T665 - the ViewerPane host-floor test fails the win32 lane when the WebView2 runtime is replaced under it

## Summary

2026-08-09: 'apprt.win32.ViewerPane.test.host floor: a real controller on a real window, on this box' failed with [webview2] (warn): environment creation failed hr=0x80004005 env=null, and the same lane passed on an immediate re-run. Two WebView2 runtime versions were resident on the box at the time (151.0.4129.59 and .72), i.e. the runtime was being replaced mid-run. A live-runtime test that cannot tell 'the feature is broken' from 'the OS component was mid-upgrade' spends a whole floor run to say nothing - it should retry the environment creation (or skip with a named reason) rather than report a red lane. Found while validating T562, whose change touched no Zig at all.
