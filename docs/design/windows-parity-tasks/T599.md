# T599 - Windows has no Agent Integrations panel: no way to see, update or remove the integrations the app installed

## In plain terms

Once Ghoztty writes files into your agent's config, you should be able to see
that it did, update it when Ghoztty ships a newer version, and take it back out.
On the Mac there is a panel that lists each agent runtime with its state and a
button. Windows will have nothing until this lands, which makes the install a
one-way door.

## Summary

Upstream on `origin/main`: `d1873ec63` + `e9e001cfc` (design + plan),
`0c5a502a3` (uninstall + `.uninstalled` outcome), `2583fec38` (`AgentStatus` +
`allAgentStatuses()`), `e617eeb16`/`576d4ddfd` (view model, per-row busy state
preserved across refresh), `42b4b2dbe` (the panel), `aac819634` (window
lifetime), `9d599cbb2` (autosize + per-agent confirm copy), `5db844a9a` (hide
gated Copilot rows), `26f4ea625` (rows and uninstall copy tell the truth).

The Windows surface must follow `docs/design/win32-design-system.md` - it is a
new dialog, so spacing scale, one icon-button size, contrast floors and the
1.0/1.25/1.5/2.0 geometry assertions all apply.
