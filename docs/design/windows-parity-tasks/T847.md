## Summary

Found incidentally while committing T477 (2026-08-14 21:5x). The working tree
holds a large, coherent, **entirely uncommitted** restructure:

- `CLAUDE.md`: **-2626 lines**, replaced by the progressive-disclosure core
  plus a routing table.
- `docs/claude/` — **untracked**: `build.md`, `cli.md`, `remote.md`,
  `sessions.md`, `testing.md`, `viewers.md`, `win32-ui.md` (~186 KB total),
  which is where those 2626 lines went.
- ~19 one-line follow-ups retargeting `CLAUDE.md's "…" section` references to
  `docs/claude/<file>.md` across `src/apprt/win32/*.zig`, `src/os/ipc_client.zig`,
  `macos/Sources/.../LocalAgentManager.swift`, `scripts/*.ps1` and
  `test/win32/*.ps1`, plus small edits to `D53.md` and `T149.md`.

The `docs/claude/` files are dated **2026-08-12**, so this has been sitting in
the tree for two days; `testing.md` was last written 2026-08-14 20:30, half an
hour before this turn started. Meanwhile several task commits landed on both
those days and excluded all of it.

Two things are wrong with that. It violates the standing sync directive
("push immediately after EVERY commit … an unpushed commit is invisible to the
other seat and every parallel session, and dies with a crashed box") — and this
is worse than an unpushed commit, because it is not even committed. And the
local repo is in a state where `CLAUDE.md` routes every reader to seven files
that do not exist in git, so the Mac seat pulling this branch gets neither the
old instructions nor the new ones.

Deliberately **not** swept into the T477 commit: it is ~2600 lines of someone
else's in-flight work, and a file was being edited 30 minutes earlier. It needs
its own commit and its own read-through, not a ride on an unrelated fix.

## In plain terms

Two days ago the project's main instruction file was split into seven smaller
ones. That work was never saved to the shared repository — it only exists on
this machine. Anyone else working on this project sees an instruction file
pointing at files they do not have, and if this box died the whole reorganisation
would be gone.
