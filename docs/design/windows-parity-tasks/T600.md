# T600 - The Windows first-launch setup dialog does not disclose that Ghoztty writes agent config files

## In plain terms

Ghoztty will be modifying files that belong to your coding agent - its settings
and its hooks. The first time it offers to do that, it should say so plainly and
let you decline. On the Mac it does. Windows must not quietly write into someone
else's config.

## Summary

Upstream: `d839b3f4a` ("macos: disclose agent-config writes in the first-launch
setup dialog"). Depends on T598 existing at all - there is nothing to disclose
until Windows installs something.

Also in scope: `de290d93a` bounded and throttled the Stop-hook PR staleness
check, because a hook that runs on every stop and reaches the network is a cost
the user pays without being told. Whatever the Windows hook does on stop gets
the same bound.

## Validation criteria

- [ ] The first-launch dialog names the files that will be written, in plain
      language, before anything is written.
- [ ] Declining leaves every agent config file untouched, and the app still runs.
- [ ] The stop-path hook work is bounded and throttled - no unbounded network
      call on every agent stop.
- [ ] Acceptance script covers accept and decline paths.
