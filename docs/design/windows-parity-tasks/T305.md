# T305 - T203b: wire every win32 chrome surface to chrome_theme + repaint on accent/theme change

## Summary

The wiring half of **T203**. T304 lands the module; this task makes every
win32 chrome surface consume it, retires the invented literals, and makes the
chrome repaint when the user changes their accent or flips light/dark —
without a restart.

## Call sites to convert (VERIFIED by reading at HEAD)

- `Window.paintTabBar` — `bar_r/g/b = bg + 20`, `hover = +15`, text
  `RGB(230,230,230)` / `RGB(150,150,150)`, close hover `RGB(232,65,65)`.
- `Window.paintCaption` — `SetTextColor(RGB(230,230,230))`, glyph
  `RGB(230,230,230)` / `RGB(255,255,255)`.
- `chooser_rows.zig:232` — `pub const accent = #3D8EF8`, feeding
  `selectionFill` (accent at 0.25) and `selectionBorder` (0.7).
- `ActivityMonitor.zig:214` — `COLOR_ACCENT = RGB(80,160,235)`, a second
  invented blue, used for the active card fill and its ring.
- `HeroCarousel.zig` — hover/selected accent blue.
- `Window.zig:5029` — `SetTextColor(220,220,220)` / `SetBkColor(45,45,45)` on
  a static control, hardcoded dark.

## Live updates

- `WM_SETTINGCHANGE` already reaches `App.zig:4189` and `Window.zig:4965`
  (which calls `applyChromeTheme`). Extend, do not add a second path.
- Accent changes arrive as `WM_DWMCOLORIZATIONCOLORCHANGED` — add it, and
  invalidate the chrome rather than re-reading per paint.

## Validation

- `test/win32/tab-strip.ps1`: sample the active-tab indicator and assert it
  TRACKS a change — set the accent, capture, set a different accent, capture,
  and assert the sampled pixel MOVED to the new value. A test that matches
  whatever the box is already set to proves nothing (the T174 rule).
- A light-theme pass: strip, hover and active mutually distinguishable, and
  text contrast >= 4.5:1 in BOTH themes, computed from captured pixels.
- Teardown restores the box's original accent AND apps theme (T179: a probe
  that leaves system state behind manufactures phantom bugs). Restore in a
  `finally`, so a mid-script failure cannot leave the box repainted.
- `-NegativeControl` inverts a load-bearing pixel claim and FAILS.
- Both test lanes, `test-agent`, P1-P3, and the T202 regression set.
