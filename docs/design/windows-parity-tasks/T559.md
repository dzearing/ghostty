# T559 - Mac viewer panes get no unfocused-split dim overlay (the win32 T380 gap, Mac half)

## In plain terms

In a split with a terminal and a viewer (a document, website, or diff pane),
the pane you are NOT using is supposed to darken slightly so your eye can find
the active one. On macOS the terminal half darkens correctly, but a viewer
never does — it always reads as the pane you are working in. Windows had the
identical gap and fixed it as T380; this is the Mac half of the same feature.

## Summary

The `unfocused-split-opacity` dim rectangle is implemented inside the
terminal-only SwiftUI surface wrapper (`SurfaceView.swift` ~line 307:
`isSplit && !isFocusedSurface` → a `Rectangle` filled with
`unfocusedSplitFill` at `unfocusedSplitOpacity`). `ViewerView.swift` and the
shared split containers (`macos/Sources/Features/Splits/*` — `PaneView.swift`,
`SplitView.swift`, `SplitTree.swift`) contain no unfocused-dim logic at all
(grep for `unfocused`/`dim`, 2026-08-07), so a viewer pane in a split never
dims. win32 closed its half in T380 by giving `ViewerPane` the same
`DimOverlay` popup a terminal `Surface` owns.

## Details

The Mac fix likely wants the dim at the PANE level rather than copied into
`ViewerView`: the SwiftUI overlay in `SurfaceView` keys on
`isSplit && !isFocusedSurface`, and an equivalent overlay (an
`allowsHitTesting(false)` rectangle in `unfocusedSplitFill` at
`unfocusedSplitOpacity`) needs to cover the viewer's content — including the
WKWebView — when the pane is in a split and not focused. Watch for the same
two win32 edge cases: no dim while zoomed or in a single-pane tab, and the
overlay must not intercept the click that focuses the pane.

Validation is Mac-seat: a split with one terminal and one viewer, focus each
in turn — both halves must dim by the same visual delta when unfocused, and
no stale dim after zoom or tab switches.

## Validation criteria

- [ ] In a terminal+viewer split, the viewer dims when the terminal is
      focused, with the same fill/opacity a terminal shows.
- [ ] Focusing the viewer undims it and dims the terminal.
- [ ] `unfocused-split-opacity = 1` disables the viewer dim too.
- [ ] No dim on a zoomed pane or a single-pane tab; no stale dim after a tab
      switch; a click on the dimmed viewer still focuses it.
