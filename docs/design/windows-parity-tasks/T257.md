# T257 - Chrome geometry datum is re-derived per acceptance script; hoist caption/strip/tab-run measurement into TestDesktop.ps1

## Summary

**T256 is the second time one chrome geometry change broke acceptance scripts
that each re-derived the same datum privately.** T254 moved the tab strip off
client `y = 0` and cost 7 failures in `tab-strip.ps1` and 19 in `menu-bar.ps1`;
T235 changed what sizes a tab and cost 4 more in `menu-bar.ps1` alone. In both
cases the app change was one number in one place.

After T256 the two scripts each carry their own copy of:

- the caption band's height (`2 * round(4 * scale) + round(28 * scale)`),
- the strip's height (`3 * round(4 * scale) + round(28 * scale)`),
- the strip's top as a window-relative y,
- the right-anchored button band (`padR` + the 28 DIP painted square),
- and — in different forms — a pixel scan that finds the tab run's right edge.

`tab-strip.ps1` finds it as the longest content-black run at `barH - 2`;
`menu-bar.ps1` scans leftward from the menu button for the first non-strip
pixel. Same measurement, two implementations, two chances to be wrong.

`pane-banner.ps1`, `context-menu.ps1` and the other capture-based scripts have
their own variants of the same y math and should be audited in the same pass.

## The fix

Hoist it into `test/win32/lib/TestDesktop.ps1` next to `Get-TestWindowDpi`:

- `Get-TestChromeMetrics -Window <hwnd>` → `{ Scale, CaptionH, BarH, StripTop,
  PadL, PadR, Gap, BtnPaint, MenuLeft }`, all derived from the window's own DPI
  by the same construction the layout modules use.
- `Get-TestTabRunRight -Window <hwnd> [-Shot <shot>]` → the last tab's painted
  right edge, measured once, the way `Strip-Geometry` does it now.

Then T205 — which moves the strip INTO the caption row and will invalidate
`StripTop` again — is one edit in the library plus whatever assertions genuinely
change, instead of a script-by-script hunt.

## Validation

- `tab-strip.ps1`, `menu-bar.ps1`, `caption-bar.ps1`, `pane-banner.ps1` and
  `context-menu.ps1` ALL PASS with their negative controls still failing, with
  no private copy of the datum left in any of them.
- P1-P3 ALL PASS.
