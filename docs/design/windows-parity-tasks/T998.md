# T998 - A torn build cache still reads as a code failure everywhere except floor-lane

## Summary

The cache heal (T494, extended by T973) lives in floor-lane's lane loop, so only the four floor lanes get the recognize-delete-retry treatment. A staging build under launch-upgrade.ps1, an acceptance script that builds, or a bare 'zig build' hits exactly the same half-written cache entry with no recognition and no retry, and reports it as red code. Lift the detection into something every build path can call (a wrapper, or a pre-build sweep) so the diagnosis is never paid twice.
