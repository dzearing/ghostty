# T573 - Read-only badge disables the mode differently on each seat: Mac needs a popover, Windows one click

## Summary

The read-only badge exists on both platforms now (T445 built the win32 half), but the gesture differs: clicking Mac's badge opens a popover with a Disable button, while clicking the Windows badge leaves read-only outright. Pick one and make both do it. The Windows side deliberately chose the one-step version - a chip that small with exactly one possible action does not need a confirmation step - so the likely fix is on the Mac. See D30 for why the badge is per-pane at all.
