# T987 - The menu test still expects a Help row the app renamed months ago, so menu-bar.ps1 has been one assertion red on every run

## Summary

menu-bar.ps1's menu model still names '&Help/Install &Claude Code Integration'; T871 (c5e3318e2) renamed that row to 'Set Up Agent &Integrations...'. Section B ('every submenu, row and separator matches the model, in order') has failed on every run since. Measured three consecutive runs on 2026-08-19: 1 FAILED / 77 passed each time, always that one row. The app is correct; the model is stale. Fix the model, then confirm the script is ALL PASS.

## In plain terms

One of the checks that guards the app's menus was still looking for a menu row
we renamed months ago, so the check reported a failure on every single run even
though the app was perfectly fine. A suite that is always a little bit red is a
suite nobody reads, so a real breakage could have hidden behind it. The check
now matches the app, and it is wired to complain the next time the menus change
without anybody re-running it.
