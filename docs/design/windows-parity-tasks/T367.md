# T367 - T56c: win32 remote connection status affordance (green/yellow/red pill + Reconnect)

## Summary

Split out of T56 (WP-D1 remote reconnect on win32), 2026-08-02. The user-facing
half: a Windows-native equivalent of Mac's machine status pill.

## Details

Mac's `MachinePillView.swift` renders the WP-D1 state as a coloured dot in the
titlebar - green connected, **yellow reconnecting (with the attempt number)**,
red disconnected - and once retries are exhausted the pill grows a prominent
**Reconnect** button wired to `manualRemoteReconnect()`. Windows has nothing:
a dropped remote window looks the same as a live one until you type into it.

Build the win32 equivalent against
`docs/design/win32-design-system.md` (mandatory): the caption/tab band already
hosts the menu "..." button since T234/T205, so the affordance has a home that
costs no terminal rows. Colour alone must not carry state (design-system rule)
and the contrast floor for chrome glyphs is 3:1.

*Validation:* geometry asserted in the pure layout module at 1.0/1.25/1.5/2.0,
plus an on-box pixel/behaviour script driving the state through T365's policy.
