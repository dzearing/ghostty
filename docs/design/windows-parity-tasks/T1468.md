# T1468 - Narrator says nothing about the feedback composer's owner-drawn chrome

## Summary

The composer's two circular actions and (since T668) its strip of pictures are painted by the band itself rather than being child controls, so they have no accessibility object at all: a screen reader moving through the composer hears the text box and then silence, even though Tab now stops on all three. Windows exposes owner-drawn parts through UI Automation providers (IRawElementProviderFragment per part, WM_GETOBJECT on the band); until then the keyboard walk T640 and T668 built is reachable but unannounced. Scope: name each stop, report which one has focus, and give each tile its picture number.
