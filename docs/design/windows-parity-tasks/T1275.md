# T1275 - Mac: report a remote window's connection state in +list --json (T609's other half)

## Summary

T609 added a `connection` object to a remote window's `+list --json` entry on
Windows. The Mac holds the same ladder state and its `+list` has the same gap.
Filed as the Mac seat's half under the standing platform-symmetry rule, because
this seat cannot build or validate Swift.

## In plain terms

Ask a Mac Ghoztty which of its windows are connected to another machine and how
those connections are doing, and it cannot tell you — the answer only exists in
the log. Windows can now answer. This makes the two agree.

## Details

The Windows shape, which the Mac half should match exactly (the CLI's own
formatter and every script parse ONE schema, so a divergence here is a divergence
in the contract, not a detail):

```json
"connection": { "state": "connected" }
"connection": { "state": "reconnecting", "attempt": 2 }
"connection": { "state": "disconnected", "self_healable": true }
```

- The `connection` key is ABSENT for a local window. Absence is what
  distinguishes local from remote; there is no `"state": "local"`.
- A field a state does not carry is omitted rather than emitted empty:
  `attempt` only while `reconnecting`, `self_healable` only while
  `disconnected`. `self_healable: false` is the terminal verdict that needs the
  user; `true` means the fast ladder is spent but a slow background re-dial is
  still armed.

Where it comes from on each side:

- Windows: `Window.reconnect.ladder` (`remote_reconnect.WindowState`), mapped by
  `WindowState.listConnection` and emitted by `IpcHandlers.handleList` for any
  window with `hasRemotePill()`.
- Mac: the same ladder state on `BaseTerminalController` (`MARK: Remote
  Reconnect`), emitted from the `+list` encoder in `IPCMessage.swift`.

`src/apprt/ipc/list.zig` already carries the `List.Connection` model and its
serializer, so the Zig side of the wire needs nothing; this is the Swift
encoder alone. `src/cli/list.zig` already prints `[connection: …]` on the
window line for both platforms once the server sends the field.

## Validation criteria

- [ ] `+list --json` on a Mac reports `connection` for a cross-machine window
      and omits it for a local one
- [ ] The three states and their conditional fields serialize exactly as the
      Windows shape above (a golden test beside the existing Mac `+list` shape
      tests)
- [ ] `+list` human output shows the `[connection: …]` suffix on a remote
      window, driven by the shared `src/cli/list.zig` formatter
- [ ] The Mac regression build is green
