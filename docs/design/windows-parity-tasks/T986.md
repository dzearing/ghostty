# T986 - Show the picture itself in the composer's image chip, the way Mac's attachment does

## Summary

Mac's chip is an NSTextAttachment that renders the picture inline; the win32 composer's chip reads [Image #N] with the thumbnail only in the carousel below. T936 made the chip a DOM node, so it can now hold a small preview of the PNG it names - a data: URL built from the store's bytes, sized to the line box - which closes the last visible difference in the attachment experience.
