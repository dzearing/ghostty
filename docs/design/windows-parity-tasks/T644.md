# T644 - Viewer feedback composer: Ctrl+Z undoes a formatting record instead of the edit

## In plain terms

Press Ctrl+Z in the feedback box on Windows and nothing appears to happen —
the text you just typed or pasted is still there. Undo is not broken so much
as aimed at the wrong thing: it is undoing an invisible styling step the box
performs on every keystroke, so it takes one press per character (and looks
dead) instead of undoing the edit.

## Goals

- [x] Ctrl+Z in the feedback box undoes the last edit (the paste, the typed
      word), never an invisible styling step.
- [x] Repeated Ctrl+Z keeps stepping back through the edits rather than idling.
- [x] Typing after deleting a quote still comes out plain (the T641 rule keeps
      holding).

## Summary

Found while landing T636 (the report writer). `test\win32\viewer-feedback.ps1`
arm J fails:

```
FAIL  Ctrl+Z undoes the last edit (got 'copymecopyme', want 'copyme')
```

It is **not** T636's: the same arm fails with T636's whole send path compiled
out (`if (false and result.ok)`), which was run on the box on 2026-08-09.

## Details

The likely cause is `ViewerFeedbackBar.ensurePlainAtCaret` (T641), which sends
`EM_SETCHARFORMAT`/`EM_SETPARAFORMAT` before every `WM_CHAR`, paste and Enter to
keep typing from inheriting a quote's styling. RichEdit records formatting
changes as **undoable actions**, so the undo stack interleaves
`[format, char, format, char, …]` and one Ctrl+Z pops a format record that
changes no text.

Two candidate fixes, both to be measured rather than assumed:

- **Set the format only when it actually differs.** Read the current
  `CHARFORMAT2`/`PARAFORMAT2` at the caret first and skip the message when it
  already says what we would set. Most keystrokes then push no record at all.
- **Group the format with the edit** (`EM_STOPGROUPTYPING` / an undo group
  around the pair) so one Ctrl+Z takes both.

Whichever lands, the invariant to keep from T641 is the one its test names:
select-all + delete + type must not leave the user writing inside a quote that
no longer exists.
