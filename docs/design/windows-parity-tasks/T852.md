# T852 - The forwarding CLI verbs (+close, +split, +rename, ...) still pass unknown flags to the server, which silently drops them

## In plain terms

Mistype a flag on `ghoztty +split` or `+close` and the command still runs -
the part you typed wrong just doesn't happen, with no message. T489 fixed
this for the verbs that parse their own flags; the ones that hand their
whole command line to the running terminal still have the gap.

## Summary

Follow-up carved out of T489. The verbs built on `parseManuallyHook` -
`+close`, `+rename`, `+rearrange`, `+read`, `+set-banner`, `+set-state`,
`+split`, `+reload`, `+new-window`, `+new-remote-window` - collect every
argument into `_arguments` and forward them over IPC. The server parses them
with `src/apprt/ipc/args.zig parseVerbArgs`, which deliberately ignores
unknown flags: that tolerance is the app<->agent/CLI compatibility contract
(an older server must not hard-fail on a newer client's flag, see
`cwd_implicit`), so the SERVER must stay tolerant.

The fix therefore belongs in the CLIENT: "hard error on an unknown flag is
the CLI's rule, not the server's" (`src/apprt/win32/pane_capture.zig:74`).
`+send-keys` is the pattern-setter - its `checkArg` enumerates the flags the
verb accepts, errors on any other `--flag`, and lets non-flag text through
(T489's `unknown_flag` field there). Each forwarding verb needs the same:
an explicit allowlist of the flags it supports, kept in sync with what the
handlers actually read (`VerbArgs` is the superset; each verb uses a
subset), erroring through the T489 message shape
(`cli/args.zig reportCliDiagnostics` or the same wording).

Watch out for:

- **The Mac seat's server must not be the excuse.** The allowlist lives in
  the shared CLI (`src/cli/*.zig`), so it lands for both platforms at once;
  the servers stay untouched.
- **`+new-window` forwards config-style args on purpose** (its `-e` tail,
  `--working-directory`, `--color`...); its allowlist question is the
  fuzziest - decide whether unknown `--flags` before `-e` are errors, and
  record the call.
- **Do not break `--` and positional semantics** where a verb has them
  (`+send-keys` text, `+read --lines`).
