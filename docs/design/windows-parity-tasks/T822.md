# T822 - The CLAUDE.md progressive-disclosure split is sitting uncommitted in the working tree

## In plain terms

A big reorganisation of the instructions this project runs on was done and never
saved to the repository. It only exists on one machine's disk right now, so a
crash, a bad `git checkout`, or a clean clone loses it — and nobody else can see
it. It needs to be reviewed and committed, or deliberately thrown away.

## Summary

Found while committing T471 on 2026-08-12. `git status` shows a whole
progressive-disclosure split of the root `CLAUDE.md` in the working tree, with no
commit and no task behind it:

- **New, untracked:** `docs/claude/` — `build.md`, `cli.md`, `remote.md`,
  `sessions.md`, `testing.md`, `viewers.md`, `win32-ui.md`.
- **Modified:** `CLAUDE.md` itself (net ~2500 lines removed — it is now a routing
  table plus the standing rules), plus 18 files whose `CLAUDE.md "<section>"`
  references were repointed at the new partitions:
  `macos/Sources/Features/Remote/LocalAgentManager.swift`,
  `scripts/delivery-manifest.ps1`, `scripts/loop-session.ps1`,
  `scripts/publish-windows-release.ps1`, `src/os/ipc_client.zig`, six files under
  `src/apprt/win32/`, and seven `test/win32/*.ps1`.

The content is real and coherent — the go-loop has been reading the split
`CLAUDE.md` all day, since the harness loads the working-tree file — which is
exactly why it is easy to miss: everything behaves as though it were committed.

Why P1: this is the standing-instructions file for every session on both seats,
it is unpushed AND uncommitted (worse than the unpushed-commit case go.md's sync
discipline is written about), and nothing in the tracker owns it.

## What to do

Establish whose work it is before touching it (a `git log`/reflog check and the
other seat), then either commit and push it as one `docs:` change with a message
that explains the routing model, or discard it deliberately. Do NOT fold it into
an unrelated task's commit, and do not revert it without asking — the sessions
running right now are reading it.

## Validation criteria

- [ ] `git status` is clean of the split (either committed and pushed, or
      deliberately discarded with the reason recorded here)
- [ ] If committed: every `docs/claude/*.md` referenced by the root `CLAUDE.md`
      routing table exists, and no file left in the tree still points at a
      `CLAUDE.md` section that moved
- [ ] The other seat can see it (pushed), since half the repointed references
      are in `macos/` and the test suite
