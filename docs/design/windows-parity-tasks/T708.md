# T708 - toggle_tab_overview does nothing on win32 while hero mode is exactly the overview it should show

## Summary

App.zig's .toggle_tab_overview arm returns true and does nothing (details.md records the same on Mac; only the GTK apprt has an overview). T682 made the chord reachable from a focused viewer pane and confirmed the app CLAIMS it - which is now a dead key: a user who binds toggle_tab_overview gets silence from every pane. Meanwhile win32 already ships hero mode, a full-window carousel of every pane with its own thumbnail per tile - which is what a tab/pane overview IS. Wanted: decide whether toggle_tab_overview should drive toggleHeroMode() on win32 (making the bound action mean something, with the palette/menu entry to match), or be documented as deliberately unsupported and dropped from the palette rather than acknowledged. Either answer is better than returning true. Note the seat question: if it maps to hero mode here, Mac should map it to whatever its equivalent is, or the divergence is the defect.
