Ghoztty Remote Agent

Connect this machine to your Ghoztty terminal from anywhere.

It comes with Ghoztty

Windows · per-user install, no admin required
↓ Get Ghoztty for Windows
  1. Install Ghoztty on this machine. There is one installer and it carries the agent.
  2. Open the machine chooser with Ctrl+Shift+N and sign in with Google.
  3. Turn on Share this machine to make it reachable from your other machines.

There used to be a separate Remote Agent installer here. There is not any more — a machine with Ghoztty on it already has everything it needs, and one install cannot leave you with half a product. To remove it, use Settings → Apps → Ghoztty → Uninstall.

What it does

  • Outbound-only connection — the agent dials out over WSS (port 443); nothing listens on your machine and no inbound firewall rules are needed.
  • Google sign-in enrollment — a browser window opens once, from the machine chooser, to approve this machine on your account.
  • Sharing is opt-in — signing in connects you outward; this machine is only reachable once you turn on Share this machine, and the same switch turns it off.
  • Updated with the app — the agent is part of the Ghoztty install, so updating Ghoztty updates it — there is no second thing to keep current.
